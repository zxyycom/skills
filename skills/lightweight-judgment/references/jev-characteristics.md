# JEV 特点与实测依据

本文件按任务表现、语言、表示、上下文和结果可靠性保存 JEV 的观察依据，供适用性判断、输入调整与异常分析按需查阅。

## 证据口径

- 产品资料调查于 2026-09-19 至 09-22；价格、限额和别名均为当时快照。
- 实验主要形成于 2026-09-26，走 OpenRouter，返回 `typesafe/jev-1.13-20260917`；以单题 Choice、串行请求为主。其他原语、多题、并发及生产表现另行验证。
- 调用数包含同一原实例的语言、格式或复测变体；各项保留分母，分别解释，不合成总体准确率。
- 来源用调查标题或稳定 Investigation ID 标识；更新时核对完整报告及实验条件。行为实验未确认内部架构、分词、位置编码、缓存或波动机制。

## 产品形态、成本和输入边界

JEV 是托管的结构化决策模型：输入 state 和 typed questions，输出已知选项、等级位置或命题概率。选择预先提供的片段或值属于其能力；开放文本生成与推理解释由其他能力承接。

形成时资料记录：

| 项目 | 记录内容 | 使用边界 |
| --- | --- | --- |
| 计费 | 输入 `$0.042 / 百万 token`，输出免费 | 当前预算核对实际报价，账单以实际 usage 为准 |
| 官方上下文 | 每请求总计 64k token；state 加最长单题为 32k token | 不是 64k state；问题和选项也占输入 |
| 网关上下文 | OpenRouter 模型页标为 32K | 与官方总请求口径分别保留，按实际通道限额调用 |
| 模态 | 文本、JSON 对象或数组；不直接支持图像、音频和视频 | URL 或文件路径作为字符串不表示服务会替你读取其内容 |
| 版本 | latest／preview 等别名可移动 | 保存实际返回模型，阈值敏感应用核对版本 |

结构合法与语义正确是独立的验证责任。

来源：《Jev 官方文档参考：输入、语言、原语与失败模式》（`260922-jev-official-docs`）、《Jev 性能、价格与部署证据提取》（`260922-jev-evidence`），以及《Jev 节省贵模型 Token 与工作流提效玩法调查》（`260919-jev-token-efficiency-patterns`）。现行接口查 [官方 API](https://docs.typesafe.ai/api) 与 [Models](https://docs.typesafe.ai/models)。

## 速度与长尾

7,648 次已落库串行 Choice 请求的客户端耗时为：p50 340.10 ms、p95 483.37 ms、p99 751.72 ms、最大 9,942.58 ms。17 个批次的首请求全部超过 500 ms，首请求 p50 为 884.17 ms；短输入也出现接近十秒的正常响应。

统计包含网络和服务等待，不含后续数据库写入；仅描述该批串行客户端耗时。一秒超时会截断其中已有的成功响应。

用法：计入 CLI 启动、网络和回退成本；同 state 独立问题可合并，具体提速收益仍待多题验证。

来源：《Jev 历史请求延迟：SQLite 日志回顾》（`260926-jev-log-latency`）。

## 具体弱项与任务差异

| 任务及条件 | 观察结果 | 错误特征与用途边界 |
| --- | --- | --- |
| 装箱与向上取整 | hard 模板 7/32 | 常错成正确值减一；由代码计算 |
| 六笔带符号账目 | 扩样各表示合计 26/64；自然短文也仅 7/16 | 同批成对抵消层为 64/64，结构差异显著，短输入也会错 |
| 异或／奇偶求值 | 新 24 个赋值的双语题：肯定 29/48、等义否定 26/48 | 充分证据也会错，优先确定性布尔求值 |
| 五人部分座位约束 | 两个实例的格式／语言／复测变体 0/32 | 特定模板跨表示持续失败 |
| 对象追踪规则迁移 | 基线 10/32，重命名后 2/32 | 对这套任务和名称敏感 |
| Shell 命令替换尾部换行 | 0/32 | 错误保留应被移除的尾部换行 |
| Shell 变量作用域 | 圆括号子 Shell 0/32，花括号同 Shell 32/32 | 反复把子 Shell 的赋值当作能回到父 Shell |
| Shell 混合引号 | 18/64 | 表示方式影响很大，不能作为精确 Shell 语义判定器 |
| 因果／意图归因 | BBH 小批 10/18；新增独立题 29/40 | 相较同批电影和讽刺任务仍弱；金标含人类因果判断，分歧不全是形式逻辑错误 |

对照中，嵌套 Shell 基准位置、分支可达性等模板各 64/64；电影相似推荐与讽刺识别扩样分别 35/40、38/40。适用性按具体模板与目标任务验证。

外部 MMLU-Pro 600 题中有效正确 505/600，另有一个无效响应；business 32/43，chemistry／engineering／other 各 33/43，math 39/43。每科约 43 题，仅供发现薄弱方向；知识题成绩与精确运算能力分别验证。

来源：`260926-jev-format-order-expanded`、`260926-jev-signed-receipts-expanded`、`260926-jev-xor-expanded`、`260926-jev-rule-transfer-controls`、`260926-jev-bbh-small-tasks-expanded`、`260926-jev-mmlu-pro-domain-screen`。

## 语言差异

Global-MMLU-Lite 排除 10 个已知源题错配后，390 对中英文题：英文 363/390，93.08%，中文 346/390，88.72%，配对差为 −4.36 个百分点。这支持当前外部知识题英文更稳，不证明语言本身是唯一原因。

合成格式面板则是英文 594/768、中文 575/768；其中约束题反而中文 147/192 高于英文 135/192，检索／逻辑对照两种语言都接近全对。具体译法、题型和字段会影响结果。

用法：保留任务语言，针对歧义澄清；生产中文任务使用实际中文材料验证。

来源：`260926-jev-global-mmlu-language-pairs`、`260926-jev-format-order-expanded`。

## 表示与类型

合成格式面板中，自然语言 316/384，82.29%，JSON 文本 288/384，75.00%，HTML 文本 284/384，73.96%，XML 文本 281/384，73.18%。比较的是含层级、转义和措辞差异的特定文本表示，与 API 原生对象对照有别。

原生对象的独立类型匹配扩样中，自然文本 48/48，JSON 字符串 47/48，混合原文 48/48；原生对象为 18/47 个有效响应正确，全部计划口径为 18/48，另一个响应无效。失败集中在外观相同的数字与字符串，内部原因未知。

后续同结构、开发／留出分开的表示实验中，64 个双语留出调用（32 个原实例）分别为：原生对象 36/64、JSON 字符串 51/64、显式类型 63/64、冗余原文 46/64。显式类型是在开发集选出的策略；唯一留出错误仍把一个字符串错认成带前导零的另一个字符串。

用法：精确匹配用代码；类型相关语义可显式标注类型或保留必要原文，再用目标数据验证。冗余原文按需提供；JSON 文件传输与 state 字符串化是不同操作。

来源：`260926-jev-format-order-expanded`、`260926-jev-typed-key-expanded`、`260926-jev-representation-remedies`。

## 顺序与命名

同一嵌套 Shell 实例的四种候选循环位移，正确数分别为 12/12、12/12、11/12、0/12；一组位置更新题在三种条件块排列下为 0/16、0/16、11/16。事件执行顺序仍由原有阶段编号决定，改的是呈现顺序。

规则迁移中，对象追踪从基线 10/32 降到重命名 2/32，相同事实与关系仍出现答案变化。

用法：保留稳定候选 ID 与语义映射，按语义答案比较；重要任务可用重排／等义变体验证稳定性，而非挑选有利布局。

来源：`260926-jev-format-order-expanded`、`260926-jev-rule-transfer-controls`。

## 长干扰与否定

20 个原实例的双语、七组上下文对照中，短基线 36/40；约 2k 字符头／中／尾为 36/40、37/40、38/40，约 8k 字符为 35/40、37/40、38/40。各相对差值的描述性区间都跨零；23 个错误中 20 个来自短基线本就较弱的账目任务。

肯定与等义否定的另一组对照均为 45/50，但逐题仍有翻转；XOR 扩样否定相对肯定差 −6.25 个百分点，区间 −14.58 至 +2.08，方向尚不稳定。

官方提示无关长 state、间接推理与否定理解风险。这批实验限于显式证据与特定无关散文，相似实体、对抗指令、真实长合同及窗口边缘仍未覆盖。用法以输入相关、条件清晰为准，位置与改写收益按目标任务验证。

来源：`260926-jev-context-interference-controls`、`260926-jev-negation-uncertainty-controls`、`260926-jev-xor-expanded`，以及[官方局限说明](https://docs.typesafe.ai/model-jaggedness/jev-1.13)。

## Confidence 与接受风险

在开发集选阈值、原样用于留出集的实验中：

| 题库与阈值 | 留出接受／计划 | 接受项错误 | 含义 |
| --- | --- | --- | --- |
| BBH，0.89 | 216/294 | 1/216，0.46% | 接受子集风险较低，拒绝项仍需处理 |
| MMLU-Pro，0.95 | 157/294 | 9/157，5.73% | 高 confidence 中仍有错误 |
| Global 双语，0.98 | 218/400 | 8/218，3.67% | confidence 与正确率分别解释 |

同样以开发集 80% 覆盖为目标，三库所需阈值分别为 0.89、0.65、0.82，且留出覆盖率会漂移。BBH 阈值 0.99 下 146 个接受项零错误，也不是总体零风险证明。合成扩展轮的 1,560 次 confidence ≥ 0.8 响应中仍有 158 次错误。

用法：按任务与错误代价验证阈值，记录覆盖率与接受风险；模型、候选、表示或领域变化后重新验证。Score／Noul 需要各自校准证据。

来源：`260926-jev-confidence-selective-risk`、`260926-jev-format-order-expanded`；概率语义见[官方 Confidence](https://docs.typesafe.ai/confidence)。

## 复测与协议异常

1,296 个完全相同的请求体各运行两次：64/1,296（4.94%） 改变语义选择；概率分布改变 797/1,296。两次都错的 281 个请求体中，268 对重复同一个错误选项。外部题库的有限复测翻转率较低，也不证明确定性或多数投票收益。

MMLU-Pro 曾返回 choice C，却给 C 为 0.14、D 为 0.15000000000000002；类型题也出现过非最大概率项被选为 choice。实验按预先规则记为无效响应，保留原始答案，没有改选最大项后冒充正确。

用法：CLI 检查协议，agent 复核语义；异常保留原始状态，不通过投票或改写响应掩盖。控制参数以实际接口为准。

来源：`260926-jev-format-order-expanded`、`260926-jev-mmlu-pro-domain-screen`、`260926-jev-typed-key-expanded`。
