# 参考与编辑诊断

用于参考融合、编辑、局部回填及重复偏差。输入职责是本次约定，不是模型天生能硬隔离的通道；每次都以实际传图和输出验证。

## 先核实图，再说明分工

按需在任务中保留这样一份短清单；简单单图只需一句话：

| 实际图序／身份 | 本次职责与优先依据 | 不应继承 |
| --- | --- | --- |
| 图1，当前可用全身图 | 编辑基底、身份与大构图；手势按本次修改要求 | 待修的手势 |
| 图2，姿态草图 | 大致动作走向与重心；身份和材料沿用图1 | 草图配色、简化关节、错误连线 |
| 图3，材料近景 | 局部材料层次；服从目标身体的透视与遮挡 | 近景的正面透视与局部尺寸 |

这不是固定三图模板。缺少角色图时，文字描述可以辅助，但不能声称身份图已传入；没有职责的参考可不使用。反推提示只能描述观察到的内容，不恢复唯一原提示，也不自动携带位图条件。

核对最终选择的图确为对应版本；图号以实际调用顺序为准。中间环节若裁剪、缩放、统一尺寸、拼板或只传文字，应核对传递的是什么、关键内容是否仍可见。预览网格不证明实际传入一张拼图；上游提示助手收到图，也不证明最终生图节点收到同一批图。

## 根据保留与改动选择控制

| 条件 | 优先考虑 | 需要验收的风险 |
| --- | --- | --- |
| 基底大体成立，只改一个局部 | 从该基底编辑，写变化、承载位置及关键保留项 | 邻域变形、身份和非目标细节漂移 |
| 风格或材料参考带入无关主体 | 缩小借用属性；有条件时使用对应参考通道或有效裁切 | 内容污染与风格外溢分别检查 |
| 关系仍模糊，文字难定位 | 当前工具支持的涂画、布局图、区域或结构输入 | 辅助图的多余结构被继承 |
| 局部修改要求严格隔离 | 能兑现保护范围的区域工具／原生合成 | 蒙版实际语义、柔边、外部区域是否真的保留 |
| 旧结构反复压过新目标 | 审计旧图及“保留”要求，再考虑换底或重建候选 | 身份、尺度与构图重置，不能无损承诺 |

蒙版可能控制重绘、参考注意力或文字作用区域，不是同一种契约；先读实际工具说明。参考权重、结构控制、降噪等不按旧教程猜参数。若工具无法精确保留而任务确实要求精确，说明缺口并选择合适流程，不把“只改这里”当像素锁。

## 局部设计、回填与整图分别过关

局部不清楚时，区分三种失败：

1. **设计未成立**：近景也看不出需要的结构／材料。先让局部设计可读；标清它是生成样稿还是原图裁剪。
2. **最终尺度不足**：近景可读，但目标全图中太小、被遮挡或亮效淹没。调整取景、画面组织或可见特征；不要凭指定像素数就认定模型执行。
3. **回填未落实**：全图空间足够，却没有转移局部特征，或透视、连接不合。以整图为目标重新明确位置、结构与保留项；局部正例不是回填证明。

回填后同时验局部可读性、整图身份／比例／透视和非目标区域。多图重建可能比局部编辑改变更多；不能单凭参考更多推断更好。用户只需自然可信的大关系时，不引入无依据的骨长、角度或投影阈值；精确重建任务则另按其精度验收。

## 反复偏差先查什么

- **重复多出结构**：检查输入是否本来含该填面、连线或轮廓，提示是否要求保留它；分别修连接关系、轮廓曲率、材料和效果，不把所有问题写成“更准确”。
- **姿态改了，角色换了**：检查身份位图是否真实附入、姿态图是否越权提供外观、重建是否换了基底。
- **局部图案对了，全图风格变了**：分别限定对象位置与风格作用范围；检查保留的媒介、脸和背景，不只检查图案出现。
- **输出没有要求的状态**：对照本次最终原词，排除旧静息／无特效要求；指令本身错状态和模型未执行是不同原因。
- **一处修好，其他面板变了**：退回较好基准，核对受损区域，考虑拆页／区域保护／合成。不得以本轮目标区改善覆盖回归失败。

这些是诊断方向，不是已证实的唯一因果。工具限制、输入冲突和随机差异都可能参与；没有受控对照时保留不确定性。
