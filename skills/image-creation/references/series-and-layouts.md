# 系列与版面

当要多张、宫格、角色表、过程板、独立方案或图标套系时，先读关系分型，再取对应例，形成公共规范、每图／每格变量与可执行 prompt。例子是表达示意，效果需另行验证。

## 先确定图与图是什么关系

| 关系类型 | 跨图稳定／变化 | 验收重点 |
| --- | --- | --- |
| 同一时刻多视角 | 固定身份、服装、状态和场景；变机位或景别 | 没有顺手推进剧情；各视图结构／属性一致 |
| 时间推进故事 | 固定身份、媒介和空间依据；动作与环境随事件合理演进 | 每格是下一有意义时刻，而不只是同场景换角度 |
| 独立方案集合 | 只共享用户指定规范；各方案可有不同主体／风格 | 各格独立成立，不强加同一角色或叙事 |
| 状态／过程板 | 固定对象和识别点；每步呈现已完成状态及正在发生的操作 | 顺序、状态增量与前置关系正确，步骤不跳跃 |

先从用途恢复分型；“九宫格”本身不能回答是九个机位还是九个时刻。格数、行列和总数明确，单格画幅与整板画幅分别核对。已明确时无需再让用户选菜单。

## 公共项、变量与容量

1. 先建立可辨认基准；身份信息不够时，可先生成缺少的正面等候选，对回原依据再选择，并在后续真实重附。新补的背面／正面是推设，不冒充原设定真值；参考已足够时无需多加一次生成。
2. 公共项按任务选择身份／产品轮廓标签、媒介、色盘、场景或品牌方向；本图变量单列姿态、机位、事件、状态或文案。角色表换装应说明所有格都换，含肖像小格，不只换全身格。
3. 故事可由场景意图自动展开成事件与机位，再逐格回验，无需用户手写每格。需要精确对白、固定步骤或关键镜头时逐格明确；自由项可以继续由模型组织。
4. 按最终阅读尺度检查“格数 × 文字量 × 主体细节”的容量。先保事件、识别点与必要文字，减装饰、简化背景；仍不可读时按交付要求拆张，不靠声称更高分辨率解决一切。
5. 项目／多轮可沿已有记录保留“场景／格号 → 事件与角色 → 本图 prompt → 选定资产”；按[生成记录](generation-records.md)关联实际调用，逐图内容通过后再并排查套系。

单张拼板不自动等于分别可用文件。需要原样提格时用确定性裁切；把“第几行第几列”交生成器重画仍可能改变内容。多视图不能证明三维精确一致，静态故事也不能证明视频连续性。

## 完整例一：让九格讲述事件，而不只换机位

**用户目标**：把“小狐狸雨后捡起落在路边的小铃铛，挂回站牌，等车离开”做成无字九格故事。**必要输入**：图1为已选狐狸身份参考。场景意图已给定，本例让执行端展开九个时刻；不要求用户补九份分镜。

```text
根据图1狐狸身份，创作一张三行三列、总共九格的无字儿童故事板，按从左到右、从上到下阅读。每格是同一事件接续的下一个有意义时刻，不是同一瞬间的九种机位。
故事从雨后小狐狸来到公交站开始：它发现路边的小铃铛，捡起它，挂回站牌，最后等到车并离开。把这段意图自然展开为九格，允许选择能讲清行为的远近景与观察角度；每格只突出一个主要动作，不新增支线、其他主角或额外失物。
全程保持图1的头型、毛色、耳尖和衣着识别点，统一柔和水彩媒介与雨后冷暖关系；铃铛始终是同一个物件，位置按发现、拿起、挂回的动作推进，不在手中与地上同时重复出现。
站牌、道路和候车位置保持可追踪的空间关系。雨已停，地面残留少量反光；时间随事件推进，不在相邻格无理由切换晴昼和暴雨夜。
九格清楚分隔，画内不加入标题、旁白、数字或对白。优先让动作、铃铛去向和狐狸身份在最终阅读尺度可读，背景简洁；车只在故事后段到来，不遮住关键动作。
```

**检查**：正好九格；事件从开始到结束推进；铃铛去向、角色身份、站牌位置连贯；没有用九个眼睛／背影特写替代剧情。若自动展开漏了挂回这一硬事件，下一轮明确该事件落在哪格，保留其他成立部分。

## 完整例二：同一时刻的多视角角色表

**用户目标**：给同一角色统一换成蓝T恤、牛仔裤后制作观察表，不讲故事。**必要输入**：图1为身份参考；用户需要正、侧、背全身和一格肖像，未知背部细节属于拟设。

```text
以图1为身份依据制作四格角色观察表：从左到右依次为正面全身、左侧面全身、背面全身、正面肩部肖像，各格清楚分离，不互相重叠。
所有四格都将角色换成同一件蓝色短袖T恤和同一条牛仔裤，肖像格也必须能看见蓝色短袖T恤的领口与肩袖；不沿用图1旧衣服。保持头型、脸部、发型、身体比例与身份识别点，背面未见细节用朴素一致的设定补足，不增加饰品。
这是同一时刻、静立状态的四个观察，不发生新剧情或状态变化。三个全身视图保持可比较的尺度与同一姿势，脚完整入画；肖像只按近景范围裁切。
各格共用中性浅灰背景、柔和照明与图1媒介，不加入文字或标签。让视角差异清楚，衣服的结构与配色跨格一致。
```

**检查**：四格及顺序、所有格换装、身份、背面拟设；单格细节漂亮不能抵消另一格漏换衣。需要更可靠的大结构时按[结构引导](structure-guidance.md)，不为普通角色表强制搭3D。

## 独立方案与过程板的写法

以下仍是完整示意，可按用户目标直接改写；必要输入分别列在各例中，文案是本例明确的演示内容。

**独立方案目标**：同一活动的两种海报方向。**必要输入**：已确认上图标题“周末阅读”，无参考图；本例仅借两格比较方向，不作为两份成品文件。

```text
创作一张左右两格的海报方向比较板，主题均为“周末阅读”，两格不是连续故事，也不共享同一个人物。
左格以打开的书为唯一主体，暖米色、柔和纸张纹理、安静留白；右格以抽象书页几何为主体，蓝白限定色、硬边平涂、大块负空间。两格各自只写准确标题“周末阅读”，标题在各格上方，使用清晰中文无衬线字样，不出现其他文字。
共享的是标题、标题主次和等大边界；主体造型、色盘与媒介按左右各自方案，不互相渗透。每格独立可读，标题不压住主体。
```

**检查**：共同规范未变；两个方向确实不同且无叙事串联；逐格标题正确、无额外串。

**过程板目标**：三步折纸船视觉说明。**必要输入**：用户确认过的三步状态草图，作为图1；真实折法正确性由此依据而非模型猜测。

```text
将图1已确认的三个状态整理为从左到右的三格折纸过程板，一格对应图1一个步骤，保持纸张同一颜色与识别边，不增删步骤。
每格保留该步已折成的结构与本步要折的边，动作箭头只标图1给定的方向和目标边；前一步完成后的形状要能接到下一步，不为了美观跳成最终船形。
全图共用干净平涂、白背景、可比较的观察角度和尺度。每格下方分别只写“1”“2”“3”，纸边与箭头清楚，不加入装饰或其他文字。
```

**检查**：状态递进、折边／箭头对源、编号顺序；图像清楚不等于操作真的可行。

## 图标套系：共同规范 + 对象变量

公共规范写媒介、视角、视觉体量／留边、色盘职责、材质、光照阴影与背景／透明；变量写对象名、识别结构及必要细节。色值可按主体、强调、次要细节和阴影角色给定，但文本色值不证明输出像素精确。先审代表图再扩套，并排查体量、视角和阴影，不强制 JSON 或某种3D风格。

### 完整例：一套桌面工具图标中的鼠标

**用户目标**：为已有柔和玩具感图标套系补一个鼠标。**必要输入**：图1已认可套系样本，只供视觉规范；交付要求为单个透明背景位图，真实尺寸按当前接口另设。本例配色为演示，可由用户覆盖。

```text
为图1图标套系补一个独立鼠标图标。图1只提供圆润玩具感材质、统一的略俯视侧前机位、视觉体量与柔和光照，不复制其具体对象或背景。
主体是一只可辨认的电脑鼠标：圆润外壳、清楚的左右键分界与一个滚轮，结构简洁，无线，不添加字母或商标。
主体外壳浅黄，滚轮薄荷绿，侧边细节浅蓝，较暗青灰只用于结构阴影；颜色职责与图1协调，不让次要细节比主体更抢眼。
图标居中，四周留出与套系相近的呼吸空间，不贴边、不切掉轮廓；小尺寸下仍能辨认鼠标而不是一块普通圆石。光从左上来，材质柔和、不做镜面金属，阴影方向与套系一致。
背景透明，不绘制棋盘格、地面、底座或外围光晕；只保留鼠标自身与结构内的柔和阴影，不加外部投影。
```

**检查**：对象语义与滚轮、套系视角／体量／色盘／材质分别成立，实际alpha和文件规格另验。依次替换对象变量即可继续套系，但每张的识别结构须重新适配，不把鼠标按键照搬到记事本。
