# 视觉简报与表达

当“感觉不对”还不能定位、需求较抽象或视觉词互相打架时使用。下列维度用于发现缺口，不是每张图都要填满的字段，也不是已验证的跨模型配方。

## 从用途倒推画面

先说图要让人看见、理解或感受到什么，再决定视觉手段：

| 目的或偏差 | 可以明确的视觉选择 | 看图时检查 |
| --- | --- | --- |
| 情绪不可读 | 表情、视线、手势、人物间距离，取景能否看清这些信号 | 情绪来自主体表现，还是只剩背景色 |
| 动作像摆拍 | 重心、躯干倾斜、四肢收展、接触与受力、动作发生的瞬间 | 姿态是否服务正在做的事，而非展示全部部件 |
| 产品不突出 | 主体占比、近景、留白、背景层次、轮廓／材质光 | 产品是否清楚，外形与标签是否保留 |
| 空间关系混乱 | 每个对象的位置、朝向、视线、高低、前后景与遮挡 | 对象存在和关系正确分别检查 |
| 氛围空泛 | 光源方向、软硬、明暗分区、冷暖关系、环境痕迹 | 光色是否服务主体与用途，没有吞掉细节 |
| 风格只有滤镜 | 线条／笔触、边缘、形体概括、纹理、媒介载体、色块组织 | 水彩是否有渗染与纸感，玩偶是否有材质与关节等可见特征 |

不把近景、横幅、某组色盘等升级为题材硬默认。需要环境叙事时保留环境尺度；需要全身动作时不为了面部细节改为脸部特写。两个核心目标不能同时容纳时，明确冲突再选取舍。

## 写可见关系，不堆独立属性

- **身份与归属**：写“左侧戴红帽的人把蓝杯递给右侧的人”，而非“两个角色、红帽、蓝杯”。只给应拥有属性的主体，不让颜色、衣饰和风格越界。
- **空间与连接**：写清谁连接到哪里、什么在前、哪些被遮挡；负空间或开口也是结构要求。删除某个填面与删除支撑它的杆件是不同变化。
- **状态与效果**：区分静息、蓄力、启动和持续作用；用可见的开合、内透光、流动、尾迹等表达本次状态。效果应有来源、方向、前后遮挡和取景空间，不能用强光遮住待验收的器官。
- **程度**：必须、禁止、弱化和自由项分开；“少强调”不等于删除。夸张程度由当前用途和用户偏好决定，不从旧图反推通用数值。

## 材料应有结构，不只有颜色

区分表面发光、透过半透明层的内部发光、真实凹腔和画在表面的暗纹。按需要描述：

1. 里面是什么：体积、层次、连续性与可见范围。
2. 外面如何覆盖：厚薄、硬唇／壳片、透明度、粗糙度和反射。
3. 边界如何相接：附着、遮挡、缝隙、开口及随身体转向的变化。

局部材料图只能提供材料依据。回到全身时，它仍须服从躯体朝向、曲面、自然遮挡与最终显示尺度，不能把正面近景平贴到侧转对象上。静息与激活对照若需突出状态差异，可保持近似机位和光照，但不假定其他细节会自动完全一致。

## 把镜头拆成四个轴，再分配入镜信息

先按用途组合，不把“构图”当作一个开关：

| 轴 | 要决定什么 | 组合检查 |
| --- | --- | --- |
| 景别／范围 | 环境全景、全身、半身、面部还是材料局部 | 要展示完整动作，就为肢体与效果留空间 |
| 俯仰／视点 | 平视、略俯、略仰或顶视 | 顶视不等于所有高角度；视点须支持待看的结构 |
| 主体朝向 | 正面、侧前、侧面、背面及面向画内哪里 | 只见背部却要双眼清楚，先改取舍 |
| 局部焦点 | 眼神、手与杯柄、标签、凹腔等 | 焦点应在选定范围内可见且足够大 |

“全身入画、机位略低、角色侧前方、眼部仍可辨”分别约束四轴，不互相替代；需要眼部微表情时可能须改变景别，而不是继续加“清楚”。

**入镜预算**：把描述给画内必须读到的东西。“肩部以上、略俯视”可写脸、衣领、肩线和身后小片地面；房间有窗、有家具不等于都应入镜。把“人物在带窗和整套家具的房间，穿裤子和鞋，面部近景”压为“肩部以上近景，略俯看人物，衣领与身后小片灰地可见”，删除的是争抢取景的画外要求，不是删掉必需环境。若目标是手握剑的局部，让手、剑柄与刃部成为主语，战场只留支持关系的线索。

## 光色三问与对比选择

1. **光从哪里到哪里**：哪侧光源照到哪个表面，投影落在哪里；柔硬由边缘与过渡表达。
2. **哪里亮、哪里暗**：主体与背景如何分离，哪些暗部必须仍可读，高光是否保留材质。
3. **冷暖承担什么**：主光与环境光怎样支持用途，而不只是给全图套色。

| 目的 | 可以直接改写的关系 | 检查 |
| --- | --- | --- |
| 暗背景中突出人物 | 后侧柔和轮廓亮边勾出肩与发丝，脸由较弱侧光照亮，背景低对比 | 头发颜色、肤色与暗部体积没被一起改坏 |
| 显示一束光 | 光从左上进入，背景空气中少量薄雾显出光路，主体面部保持清楚 | 光路方向成立；雾不是挡住主体的白墙 |
| 减轻皮肤油亮 | 先辨是大片镜面高光还是纹理缺失；可试让面部受柔漫射补光，缩小额鼻高光，同时保留毛孔与脸部明暗 | 高光减弱不等于全脸磨皮；背景与立体感另验 |

从少量对比中选服务观看重点的一种，必要时再组合：明暗对比用于主体分离；小面积强调色对低饱和环境用于定位；动静对比可让静止主体与既有雨线形成关系；情境对比可由人物视线与空座位表达等待。既定内容的画面不为“故事感”擅加道具；直视镜头也能正确服务时尚或肖像。

## 从动机落到静态表情

先判断“人物面对谁，希望对方怎样回应，显露还是掩饰”，再选两三项可见信号，而非把所有表情器官填满。例如“想请求帮助又怕打扰”可落为视线朝向听者、上眼睑略紧、嘴唇轻抿、肩稍收；“故作轻松地告别”可落为小幅嘴角上扬但视线避开、下颌微收。信号是表现候选，不是心理诊断；取景应能读到它们。静图只写一个瞬间，不借用说话、呼吸、停顿的整条时间链。

### 完整例：把“电影感、克制”落成低光人像

**用户目标**：一张成年人在室内等候、想开口又克制的叙事肖像。**必要输入**：无参考；本例保持具体身份开放，光色与机位是可覆盖的设计选择。

```text
创作一张成年人物在安静室内等候的叙事肖像。取肩部以上近景，机位略高，人物朝向画面右侧的画外听者；画内只见脸、衣领、肩线与少量冷灰背景，不加入完整房间陈设或文字。
人物想开口请求帮助却怕打扰：目光朝向听者，眼睑略紧，嘴唇轻抿，下颌微收、肩稍内收；表情克制，不张嘴大哭或夸张皱眉。
暖色柔侧光从画面左侧照到近侧面颊，另一侧留较冷的暗部；亮部柔和过渡，暗部仍能看见脸部体积和衣领纹理。背景比脸暗且低对比，不用强光晕、烟雾或密集光斑遮住五官。
保持自然皮肤纹理与低饱和色彩，少量细颗粒只作为观感，画面的重点是目光与欲言又止的关系，而不是美妆磨皮。
```

**检查**：四轴相容、面部信号可见；主光方向与阴影自洽；暖高光／冷暗部服务人物；皮肤没有过曝或平滑成塑料。以上是示意提示及待验点，不是已生成结果。

## 镜头与风格词是表达候选

先描述观众视点、主体占比、前后层次和细节尺度，再选镜头词：广角可表达贴近／夸张的空间关系，远距观察可强调层次，微距可揭示材料局部。数值焦距不保证生成器遵守真实相机几何；“长焦”也不能脱离机位与取景解释。

用少量协调的媒介、光色和构图选择形成方向。参考某种电影、胶片或摄影观感时，展开为受控高光、颗粒、黑位、混合光或几何调度等可见特征，不把名称当物理流程或固定效果保证。现有词表、社区提示和反推文本只是候选材料；剔除带入无关主体、装饰和矛盾媒介的词块。

## 提示压缩检查

先保住用途、核心关系和硬约束，再删重复词。压缩后的文字若丢了姿态、色盘、位置、状态或保留项，即使更短也不是等价版本。详细原需求以归一化为主，不为“专业感”增加新要求；宽泛需求只补有助于落地的细节。
