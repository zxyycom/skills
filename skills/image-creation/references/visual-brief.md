# 视觉简报与表达

当“感觉不对”还不能定位、需求较抽象或视觉词互相打架时使用。下列维度用于发现缺口，不是每张图都要填满的字段，也不是已验证的跨模型配方。

## 从用途倒推画面

先说图要让人看见、理解或感受到什么，再决定视觉手段：

| 目的或偏差 | 可以明确的视觉选择 | 看图时检查 |
| --- | --- | --- |
| 情绪不可读 | 表情、视线、手势、人物间距离，取景能否看清这些信号 | 情绪来自主体表现，还是只剩背景色 |
| 动作像摆拍 | 重心、躯干倾斜、四肢收展、接触与受力、动作发生的瞬间 | 姿态是否服务正在做的事，而非展示全部部件 |
| 产品不突出 | 主体占比、近景、留白、背景层次、轮廓／材质光 | 产品是否清楚，外形与标签是否保留 |
| 空间关系混乱 | 每个对象的位置、朝向、视线、高低、前后景与遮挡 | 对象存在和关系正确分别检查 |
| 氛围空泛 | 光源方向、软硬、明暗分区、冷暖关系、环境痕迹 | 光色是否服务主体与用途，没有吞掉细节 |
| 风格只有滤镜 | 线条／笔触、边缘、形体概括、纹理、媒介载体、色块组织 | 水彩是否有渗染与纸感，玩偶是否有材质与关节等可见特征 |

不把近景、横幅、某组色盘等升级为题材硬默认。需要环境叙事时保留环境尺度；需要全身动作时不为了面部细节改为脸部特写。两个核心目标不能同时容纳时，明确冲突再选取舍。

## 写可见关系，不堆独立属性

- **身份与归属**：写“左侧戴红帽的人把蓝杯递给右侧的人”，而非“两个角色、红帽、蓝杯”。只给应拥有属性的主体，不让颜色、衣饰和风格越界。
- **空间与连接**：写清谁连接到哪里、什么在前、哪些被遮挡；负空间或开口也是结构要求。删除某个填面与删除支撑它的杆件是不同变化。
- **状态与效果**：区分静息、蓄力、启动和持续作用；用可见的开合、内透光、流动、尾迹等表达本次状态。效果应有来源、方向、前后遮挡和取景空间，不能用强光遮住待验收的器官。
- **程度**：必须、禁止、弱化和自由项分开；“少强调”不等于删除。夸张程度由当前用途和用户偏好决定，不从旧图反推通用数值。

## 材料应有结构，不只有颜色

区分表面发光、透过半透明层的内部发光、真实凹腔和画在表面的暗纹。按需要描述：

1. 里面是什么：体积、层次、连续性与可见范围。
2. 外面如何覆盖：厚薄、硬唇／壳片、透明度、粗糙度和反射。
3. 边界如何相接：附着、遮挡、缝隙、开口及随身体转向的变化。

局部材料图只能提供材料依据。回到全身时，它仍须服从躯体朝向、曲面、自然遮挡与最终显示尺度，不能把正面近景平贴到侧转对象上。静息与激活对照若需突出状态差异，可保持近似机位和光照，但不假定其他细节会自动完全一致。

## 镜头与风格词是表达候选

先描述观众视点、主体占比、前后层次和细节尺度，再选镜头词：广角可表达贴近／夸张的空间关系，远距观察可强调层次，微距可揭示材料局部。数值焦距不保证生成器遵守真实相机几何；“长焦”也不能脱离机位与取景解释。

用少量协调的媒介、光色和构图选择形成方向。参考某种电影、胶片或摄影观感时，展开为受控高光、颗粒、黑位、混合光或几何调度等可见特征，不把名称当物理流程或固定效果保证。现有词表、社区提示和反推文本只是候选材料；剔除带入无关主体、装饰和矛盾媒介的词块。

## 提示压缩检查

先保住用途、核心关系和硬约束，再删重复词。压缩后的文字若丢了姿态、色盘、位置、状态或保留项，即使更短也不是等价版本。详细原需求以归一化为主，不为“专业感”增加新要求；宽泛需求只补有助于落地的细节。
