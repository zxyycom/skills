# 提示词工程指南

构建或改写提示词时，先用本文件的核心流程，再按任务读取下方专题。示例用于改写，效果需另行验证。

## 从需求到实际 prompt

1. **提取硬要求与自由项**：确认用途、产物、主体与数量、身份、动作／状态、准确文字／事实、必须保留和输出规格。区分用户要求、自己构思的主体／情境／文案等设计候选，以及需有依据的真实事实。精确改色、换字、格数和位置先规范化并冻结；创意扩写只补自由项，不能增加业务事实或改掉保留项。
2. **确定主事件或本轮差异**：新图写这次发生什么，编辑写从哪张基底的何处变成什么，系列图区分公共项与每图变量。用两三项可见结果排优先级；低优先级硬要求仍须保留。
3. **写画面骨干**：“谁／什么，以何状态／动作，在什么关系中，被怎样观看。”例如“机械兽向右奔跑，躯干前倾、前足落地、后足蹬起，以侧前方全身机位呈现”，比“机械兽、速度、震撼”更可检查。
4. **补足有效的视觉表达**：只补能改变结果的信息。明确属性属于谁、谁连接／遮挡谁、效果从哪里来；选择可兼容的取景、材料、光色与媒介。先保证本次要看的内容有入镜空间，不为画外存在的物件争夺构图。
5. **绑定真实输入**：写明编辑目标，逐图说明身份、姿态、布局、风格或材料职责，以及不继承什么。图号必须对应实际附件；结构图只约束需要的大关系，不能用一句“参照图2”代替实际传图。预设和可见扩写均展开检查，最终生成器的图像输入另行核对。
6. **做语义回查**：对回原需求，查数量、字串、格数、位置、状态与保持项；清除静息／启动、近景／全身、正面／背面、旧姿态／新姿态及互斥媒介等冲突。删重复质量词，不删识别点、归属、关系和保留项。
7. **编译到当前入口**：提示文本、支持的控制字段与实际附件分别填写。自然语言一段或分段均可，不强制 JSON、英文、固定词数、比例或参考数。实际原词与可见改写词分存；调用与回看按[生成记录](generation-records.md)执行。

## 写什么才有用

下面是组织、冲突处理与压缩优先级，不声称词序有固定模型权重。

| 内容义务 | 可执行写法 | 检查重点 |
| --- | --- | --- |
| 目的与变化 | “以图1为编辑目标，只将上排左人物的红围巾改成蓝色” | 新创作、重设计和保留后局改没有混淆 |
| 身份与归属 | “左侧戴红帽的人把蓝杯递给右侧穿灰外套的人” | 数量、服饰、道具与动作各自绑定；未知背面仍属拟设 |
| 空间与结构 | 写位置、朝向、视线、接触、连接、前后遮挡、留空与相对尺度 | 对象出现不等于关系正确；区分画面左右与角色自身左右 |
| 材料与状态 | 壳片覆盖半透内层，内部有体积流光；聚能但不外喷 | 表面亮线、内部发光、凹腔与暗纹不同；强光不遮待验结构 |
| 观看与表达 | 用需要看见的范围、焦点、光源、明暗、冷暖、边缘和媒介替代空泛风格词 | “4K”、相机／胶片名等观感词不保证真实尺寸、物理成像、色彩处理或身份保真 |

“弱化背景”不等于删除背景，“允许自然遮挡”不等于允许器官缺失。按用途允许自然透视、遮挡与曲率调整；精确规格仅在用户或下游用途确实依赖时作为硬要求。动作先写行为、重心和肢体关系，再写速度氛围；材料近景回填仍服从全图朝向、曲面和尺度。细化这些表达及完整低光示例时读[视觉简报与表达](visual-brief.md)。

## 编辑：差异 + 载体 + 不变量

编辑提示先说哪里变成什么，再说新属性附着于哪个对象、表面或面板，最后保留真正重要的不变量。每轮重申仍有效的关键要求，不依赖长对话隐含记忆。

属性范围和画面范围分别写：只改上排一条围巾，与“所有视图的橙色外壳都改黄”不是同一范围；后者仍要保留每格的眼部颜色、锈迹、材料、光照和布局，并逐格核对。自然语言保持项不是像素锁。

需要回填、多主体、删除／替换的完整原词时读[编辑提示实例](editing-prompts.md)；判断该修输入、换基底、用区域还是先修损坏时读[参考与编辑诊断](references-and-edits.md)。

## 用具体差异驱动改写

对照原依据、当前图和前版实际 prompt，先写**看到的差异 → 对用途的影响 → 有依据的正确关系 → 保持项 → 回验点**，再改原词对应部分。未知或遮挡处标不确定，不靠“更准确”“修好手脚”猜全局。

例如看见杯柄与手掌穿插，影响“正在端杯”的可读性，可改为“右手从外侧握住杯柄，手指围绕柄部，杯体在手掌前方；保留杯型、手臂动作、人物身份和构图”，随后同时检查接触与身份。若实际错在参考没传入、旧词仍要求静息或基底结构错误，先修输入／任务，不把全部问题归为模型不服从。

一次优先解决最重要且相关的一组变化；已经有效的部分保留。多轮结果不收敛时回到[诊断](references-and-edits.md)选路线；要研究短语收益或交互才进入[授权实验](task-patterns.md#需要验证方法收益时)，普通成图不额外生成对照。

## 最小完整例：从需求到可提交提示

**用户目标**：给儿童故事画一只雨夜等车的小狐狸，安静、有些孤单。**必要输入**：无参考图；本例采用水彩与冷暖分离作为可覆盖的美术选择，不是用户硬要求。

```text
创作一张儿童故事单页插画：只有一只小狐狸独自在雨夜公交站等车。
用中景同时看见它的表情、空站台和一小段空道路。狐狸身体微缩、双爪靠近胸前，目光朝向道路来车方向，画内没有其他角色。
暖色站灯照亮脸和潮湿毛发，站外是冷蓝雨幕；湿地只有少量柔和反光，反光亮度低于狐狸面部，视觉焦点保留在狐狸身上。保留纸面纹理、轻微水彩渗染与柔软边缘，不做塑料质感。
让狐狸与空道路的视线关系、周围留白共同传达安静和孤单；不加入文字、标志或额外剧情道具。
```

**检查**：一只狐狸；身体和视线可读；空路与留白服务情绪；暖光未吞掉毛发。尚未调用时只交付提示，不把检查计划写成已经通过。

## 按任务深入

| 本次缺口 | 读什么 | 得到什么 |
| --- | --- | --- |
| 镜头、光色、情绪、材料说不具体 | [视觉简报与表达](visual-brief.md) | 可见表达与入镜预算、完整低光例 |
| 借风格换主体、复用偏好、产品／海报 | [风格与设计提示](style-and-design.md)的对应节 | 提取／适配后的原词、可覆盖配方、文案版式例 |
| 多主体归属、局部回填或现图修改 | [编辑提示实例](editing-prompts.md)的对应例 | 差异、载体和保持项完整的编辑 prompt |
| 连续故事、多视角、方案板、过程板、图标套系 | [系列与版面](series-and-layouts.md)的对应节 | 关系类型、公共项／变量、容量与完整示例 |
| 连接／遮挡需结构图辅助 | [结构引导](structure-guidance.md) | 最小草图／3D基准与实际附图示例 |

通用层保留意图、关系、范围与验收。权重、seed、蒙版、负向槽、参考强度、专用分隔符与扩写预算按[当前接口](image-interfaces.md)核对；JSON 中写一个 `negative_prompt` 字段不自动形成控制通道。模型更换时保留语义，重新核对控制能力。
