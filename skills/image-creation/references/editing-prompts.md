# 编辑提示实例

当已确定本轮编辑目标或多参考职责，需要组织可提交的完整 prompt 时，仅读对应例。本文件拥有提示写法；修复路线、控制选择、损坏分类与范围语义由[参考与编辑诊断](references-and-edits.md)拥有。先用[提示词指南](prompting-guide.md)确定差异、载体与不变量，再按本例改写。

例子是表达示意，检查项为待验计划。图序按实际附件替换，已查看图像后才写可见事实；实际调用按[生成记录](generation-records.md)保存原词与回看结果。

## 局部材料回填：内部而非表面发光

**用户目标**：把已选材料样稿落实回全身，不改变姿态和身份。**必要输入**：图1为已选全身候选；图2为生成的胸部材料样稿，不是原图裁剪。图1保持整体侧转姿态。

```text
以图1为编辑目标，仅改造胸部壳层的材料表现，保持头、四肢、全身姿态、构图与背景。
图2只提供胸部材料层次：不透明覆壳之下有连续半透内层，再向内可见有体积的金红流动。把这种层次落实到图1胸廓，不复制图2近景的正面朝向或放大比例。
外壳沿图1躯干侧转，近侧壳缘有厚度，远侧自然遮挡；亮光从壳隙内透，不是只在外表画发光线，也不让光晕淹没壳缘和暗缝。
这是一张聚能状态候选，内部流动可见但不向外喷射。其余身体仍用图1原有材料和配色，不改变角色识别点。
```

**检查**：局部层次、全图尺度／透视、非目标身体分别回看。样稿成功不代替回填通过；状态仍是聚能，不能被“更有冲击力”扩成启动喷流。

## 多面板局部修改：回归不能被局部成功掩盖

**用户目标**：只改上排一条围巾颜色。**必要输入**：图1为两排人物海报。若下排要求像素完全相同，先确认区域／合成工具能兑现，不只依赖下列文字。

```text
以图1整张海报为编辑目标，仅将上排左侧人物颈部的红围巾改为蓝色。
围巾保持原有褶皱、织物纹理、形状和受光，只改变其颜色；蓝色只作用在这条围巾上。
保留上排人物的脸、发型、衣服、姿态，以及所有文字和版式。整个下排保持原样，不重绘其中的人物、四肢、道具或背景。
维持原照片媒介、光照和海报整体色彩，不新增内容，不调整面板位置。
```

**检查**：目标围巾、邻域肤色／衣服、文字和下排逐项对照；下排被重绘仍是失败候选，不因围巾合格就替换较好基准。

## 删除：写清补全依据

**用户目标**：去掉右侧路人，使主角更突出，街道仍自然。**必要输入**：图1为当前街景照片；先确认路人与主角的边界、被遮背景能否依据周边推设。重建遮挡内容是拟补，不声称恢复原现场。

```text
以图1为编辑目标，移除画面右侧靠近路缘的那一位路人，不移除前景主角。
沿相邻道路的透视方向与铺装纹理连续补齐空出的区域，接续路缘线及周围阴影；补出内容只用于自然延续现有街道，不新增人物、车、招牌或道具。
保留前景主角的脸、头发、身体、姿态和衣着，保留现有车辆、店铺文字及镜头构图。维持照片原有光色、景深与边缘清晰度，移除后不留下人形残影或重复纹理。
```

**检查**：目标消失，铺装／路缘／阴影连续，主角和文字未退化；删除不等于把整片背景涂成一色。

## 换背景：让替换与保留能兼容

**用户目标**：白底产品移到窗边桌面，保持真实商品。**必要输入**：图1为有把手杯子的白底照片；本例假定原商品柔光方向与左侧窗光可兼容。方向不兼容时先决定允许重打光还是改背景方案。

```text
以图1杯子为主体，将白底替换为窗边浅木桌面环境。保留杯身形状、把手连接、杯口、材质、配色和原标识，不重新设计商品。
桌面视点匹配图1观察杯子的高度与透视；杯底确实接触桌面，阴影紧贴接触处并向右侧柔和延伸。左侧窗外自然光与杯子原有柔光方向相接，不另加反向硬光或第二个重影。
背景仅有低对比的明亮窗边虚影，不为交代场景增加完整家具、人物、文字或其他商品。杯缘干净自然，不留白底光边、裁切锯齿或把手孔内的旧背景。
保持图1产品的画面大小与主要构图，让环境服务材质展示而不夺走主体。
```

**检查**：视点、接触、光向、边缘与把手孔；环境合理与产品保真分别验。人物换背景还须查细发、半透边缘与运动模糊；这些要求依实际输入选择，不机械套进产品例。

## 共享画风与局部属性：两个人仍在同一空间

**用户目标**：用两张角色参考画一次递杯互动，帽子与衣服不串到对方身上。**必要输入**：图1左侧人物身份，图2右侧人物身份；本例假定图1戴红帽、图2穿灰外套，两者均为可用角色图。不是编辑某张双人底图，而是新场景候选。

```text
创作一张两人递杯的插画，全图统一使用柔和手绘边缘、低饱和色彩与左上侧光，两人处在同一桌边与连续空间，不画成两个割裂拼贴面板。
画面左侧人物使用图1的脸型、发型与红帽，身体朝右，伸出空手接杯；图1只提供这位人物身份，不复制其原背景或姿态。
画面右侧人物使用图2的脸型、发型与灰外套，身体朝左，用靠近桌面的手将一只蓝杯递向左侧人物。图2只提供右侧身份，不把灰外套或发型移到左侧。
画内只有这两人、一只蓝杯；仅左侧人物戴红帽。蓝杯在右侧人物手中靠近两人之间，左侧手正在接近杯子，还未握住；手、杯柄与桌边关系清楚。
中景保留两人脸部、前臂和桌面，背景简洁无文字；共享的是画风和光照，各自身份、帽子与衣服按左右绑定。
```

**检查**：内容出现、属性绑定、左右位置、接触细节分开查；共享画风不意味着共享帽子。工具有区域条件才将相应段落编入通道；仅自然语言不宣称硬分区。

## 具体错误 → 正确关系 → 保持项

**用户目标**：修正端杯手部，不动已认可人物。**必要输入**：图1当前候选；已查看并确认右手指穿过杯壁，杯型和脸获认可。本例不把遮挡处未知指节当已知解剖。

```text
以图1为编辑目标，只修正画面中端杯的右手与杯柄接触关系。当前可见手指穿入杯壁，应改成右手从杯柄外侧自然握住柄部，手指围绕杯柄、杯体位于手掌前方，指节连接可信；不要增加另一只手或第二个杯子。
保留杯子的轮廓、把手形状、颜色与标识，保留原手腕朝向和前臂动作。人物脸、发型、衣着、另一只手、背景及构图保持图1；修正处的肤色、明暗和边缘接续原图。
让持杯动作读起来成立，不为了展示每根手指而改变动作；被杯柄自然遮挡的部分仍可遮挡。
```

**检查**：穿插是否消除、连接／接触是否成立、杯子与身份是否回归；仅手变漂亮不等于正确持杯。后续若换路线，仍回查原依据、实际旧词和非目标区域。
