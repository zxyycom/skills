# 生成记录与存储

本文件规定每次实际生成／编辑的证据、回看结果与图像保留策略，用于恢复目的、判断下一轮和区分事实。未调用时只记提示草稿。

## 每次调用都留什么

1. **调用前**：保存本次 ID／时间、目的、相对基准想解决什么、主要验收点，以及实际将提交的完整提示词。模板名、占位模板或目的摘要不能代替实际词；重试、失败、局部试作也分别可辨认，不事后覆盖旧词。
2. **实际输入**：记录工具／模式、可见参数，附图的实际顺序、身份／路径及职责。区分原件、裁剪、缩小、有损代理、程序渲染、AI局部样稿；未传入的图只记为阅读依据，不能列成实际输入。可见的自动扩写或返回改写词另存；未暴露的内部词／模型／设置保持未知。
3. **返回后**：关联输出 ID、实际可访问路径／资源引用与调用状态；有多张输出时逐张对应。超时、拒绝、取图失败和保存失败各记实际阶段，不把HTTP成功、入队或文本回复当成已拿到图。
4. **回看后**：保存看了哪张／哪些区域、目标是否兑现、身份／结构／材料／状态问题、非目标回归、规格检查及不确定项。用户反馈另记原意与认可范围，未反馈不是默认认可。
5. **下一步**：本图当前用途、保留／退选／待验原因、下一轮拟改什么或为什么停止。历史观察保留，后续结论追加更新；当前基准指向明确资产，不让最新图自动取代更好的旧图。

精确请求文本含敏感信息时先脱敏或取得必要授权；不把凭据、认证头、私有下载链接中的秘密或未授权素材写入记录。必须隐去的部分说明缺失及可复现限制，而非为了“完整”泄露秘密。

## 记录放在哪里

- **一次性预览**：可由同一对话内的目的说明、精确工具调用、实际附图、输出和明确回看结论共同承接；确认这些信息实际可回读，不仅存在于不可恢复的心中推理。无需另建项目目录，但回看结果仍须留下。
- **项目／多轮／系列**：使用项目已有生成索引、Markdown或JSON记录；没有现成入口时，在授权项目输出位置建立一份轻量调用记录，按call ID追加或逐次保存，与图像路径关联。不要把项目素材放进skill安装目录；不要每轮重写同一文件而丢失旧调用。
- **界面限制结束消息时**：优先在允许的工具／文件记录内补齐回看证据，遵守当前展示契约，不为附文字日志破坏要求。实际看图或记录仍无法完成时标为未完成，不伪造检查。

## 返回后的回看

拿到图后实际查看，可复用当前已显示结果；必要时看关键区域或原尺寸。对照本次验收点，依次检查任务／状态、身份／关系／连接、材料／透视／文字、目标邻域与非目标区域，最后核实需要的尺寸／透明度／裁切与数量。每个问题应能指向图或区域，避免只有“还行”“不错”。

无法取图、内容过小或被遮挡时记录“未检查／无法判断”及原因，再决定补看、改变取景、再调用或请用户选择；未查看输出不能成为通过候选。局部成功与整图回填、多视图之间也分别检查。不要求每张图填写所有无关指标，但所有实际检查结论都要保留，重要验收点不能沉默跳过。

## 存储：保留关系，不无条件复制全部素材

- 对既有源图可只记稳定来源／资产ID／版本及实际输入身份，不额外复制；项目已有hash约定则沿用。原路径不可长期访问时说明引用风险，按授权保存必要副本或请用户保管。
- 存储有限时可用有损缩小图保留大致结构，清楚标为派生结构代理，记录原来源、裁剪／缩放等变换及当前文件。实际上传代理时，记录的实际输入应是代理，不冒充原图。
- 原件、工具输出与缩略图不能互相覆盖。压缩、少复制或记录一条引用，都不等于获准删除原件、清理缓存或移除退选图；删除另核对精确目标和授权。
- 角色轮廓、姿态和大构图可用结构缩略图辅助回查，但不能以它证明像素一致、精确颜色、透明通道、标签小字或微结构保真。需要这类检查时查看足够质量的依据；原件已不可访问则明确未证明。
- 文字目的、完整实际词与检查结果优先稳定保留。历史淘汰图或非关键参考可在授权保留策略下仅留结构缩略图；当前编辑基底、用户选定成品，以及精确文字／alpha／微结构验收依赖的图，不轻率仅留有损缩略。最终选用资产和后续基准应在授权位置可恢复；是否另存全部退选输出按项目要求和存储预算决定。未保留原图的调用仍保留目的、原词、结果观察与去向，并说明回查精度下降或无法精确重跑，不承诺可重现。

## 可复制记录示例

以下是虚构的文件记录示例，演示一次编辑的全链路；不是已经发生的调用或通过证据。路径仅为项目相对示意，真实记录替换为实际身份。相同字段可写入既有JSON结构，不要求采用这个格式。

```markdown
## CALL-007
- 时间：2026-10-24T08:00:00Z
- 目的：将当前两排海报上排左人物的红围巾改成蓝色，验证其余内容能否保留。
- 基准：ASSET-006，outputs/poster-006.png；不覆盖它。
- 重点：围巾改色；人物身份；下排与文字无误改。
- 工具／模式：本次实际工具名称，编辑；底层模型与seed未暴露。
- 实际附图：
  1. outputs/poster-006.png：ASSET-006原基底，编辑目标；未另存输入副本。
- 实际提交提示词：
  以图1整张海报为编辑目标，仅将上排左侧人物颈部的红围巾改为蓝色。
  保留围巾褶皱、织物纹理与受光；保留脸、衣服、文字、版式和整个下排，不让蓝色扩散。
- 可见改写词：接口未提供。
- 返回：成功返回ASSET-007，outputs/poster-007.png；非代理原件。
- 回查派生图：previews/poster-007-structure.jpg，由ASSET-007有损缩小生成，只保留结构概览；未用于精细验收，也不是本次输入。
- 回看：已查看ASSET-007全图及上排围巾、下排人物区域。
  - 围巾变蓝且褶皱可辨；上排脸未见明显变化。
  - 下排右人物的手部被重绘，违反本次保留要求。
  - 当前显示分辨率不足以逐字核对小字，尚未原尺寸核对；未做像素级比较。
- 用户反馈：尚无；不能称用户认可。
- 当前用途：编辑失败候选，保留调用记录，不替换ASSET-006。
- 下一步：回到ASSET-006，核对区域保护／合成能力，再决定是否重试。
```

实际上传缩小／裁剪代理时，将代理自身身份与变换列在“实际附图”中，原件只作为来源引用，并说明由此降低的精细保留和复现能力；不要套用示例中原基底的输入声明。

若同一次请求分几次调用，保存各自实际原词与结果；若只是查看已有输出而未重新生成，追加检查记录即可，不编造新生成ID。失败调用可没有输出路径，但须保留实际失败阶段与下一步。
