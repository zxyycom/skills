# 风格与设计提示

借风格换主体、复用审美偏好或规划产品／文字海报时，读本文件对应节。通用流程见[提示词指南](prompting-guide.md)，实际调用按[生成记录](generation-records.md)。例子是表达示意，效果需另行验证；引用图须先查看并实际附入。

## 借风格，换成自己的主体

输出应是**适合新主体的完整画面提示**，不是参考图内容清单。

1. 看参考后提取可迁移的组织：构图与空间层次、媒介／边缘、光色、形体概括、纹理、密度与留白。仅当任务需要才提符号或排字结构；不凭风格名称推定所有特征。
2. 把具体角色、原文案、地名、商品、事件与表现方式分开；说明本次不继承什么。参考的姿态、色盘或背景只有被选中才迁移。
3. 换入新主体，重排承载关系。主体尺寸、轮廓和用途变了，留白、视角或装饰也应适配，不做名字替换后原句照抄。
4. 做残留检查：旧角色／文字／剧情是否仍在，参考独有道具是否被误当风格；密集颗粒与干净平涂、摄影体积与纯线刻等选择是否打架。

结果分三项验：新内容正确；所选参考特征忠实；多图之间一致。两张都偏青只能说明相似，不能证明忠实原参考。文字反推也不能恢复唯一原 prompt，或代替实际位图条件。

### 完整例：人物风格参考换成鲸鱼

**用户目标**：保留参考的平面拼贴感，把人物换成一只鲸鱼，不要参考上的文字。**必要输入**：图1为已查看的参考；本例假设看到硬边蓝白几何、大片留白、少量平面阴影，参考有站立人物与标题。实际图不符合时重新提取，不照套本描述。

```text
创作一张只有一只鲸鱼的平面拼贴插画。图1只供视觉组织：蓝白限定色、硬边几何切分、大片留白和少量清晰平面阴影；不复制图1人物、衣服、标题、标志或其事件。
鲸鱼在画面中下部向右上方缓缓游动，完整轮廓与尾鳍可见。按鲸鱼横向体形重新安排几何块与留白，不沿用站立人物的身体比例或姿势。
鲸鱼以平涂色面概括体积，边缘利落；背景用少量蓝白块面形成前后层次，主体周围有呼吸空间。整个画面保持干净无颗粒，不混入摄影皮肤、半调噪点或发光消散。
画内不出现任何文字、字母、条码或原参考装饰角色。重点是鲸鱼内容正确，以及几何切分、留白和蓝白关系延续参考。
```

**检查**：只有鲸鱼，无人物／标题残留；鳍与尾完整；风格不是仅换蓝色滤镜；留白适应横向新主体。

## 从认可样本提炼可覆盖的视觉配方

用户希望后续复用偏好时，从已认可图、对应完整实际 prompt 和具体反馈提炼，不把所有输出自动当偏好。缺认可样本只称暂定方向；保存隐私素材、修改用户长期配置或安装 skill 另需授权。

配方保留：**适用用途／对象、稳定视觉关系、主体变量、冲突项、样本与实际 prompt 来源、用户认可范围及未验证部分**。复用前展开预设，核对当前请求覆盖了哪些项，再清理隐藏正负词的冲突；不要把若干风格库拼成统一前缀。

### 配方条目与一次实际展开

**用户目标**：复用喜欢的生活纪实人像方向，但这次明确改成黑白全身。**必要输入**：能回查的认可样本及实际 prompt；本例假定认可仅限“人物与生活空间互动、自然光、保留纹理”，不扩为用户喜欢所有衣着和地点。

**轻量配方示意**：生活纪实候选；平视中景、人物与现有生活空间有互动，柔和自然光、自然肤质；主体／衣物／地点可变；不自动加棚拍美妆、光斑或时尚姿态。样本／prompt 关联到项目记录，标清认可范围；本条不是新任务硬默认。

本次请求优先，全身替换中景，黑白替换原色盘。展开后的完整 prompt：

```text
创作一张黑白生活纪实人像：一位成年人在自家门前整理雨伞，平视全身取景，头、鞋与脚下接触关系完整入画。
人物注意力在手中的伞柄，身体轻微前倾，门框与台阶只提供生活空间线索，不摆棚拍姿势。采用柔和自然光，脸、手与衣物保留真实纹理，亮部不过曝，暗部仍有层次。
整张使用黑白影调，以明暗区分人物与背景，不继承样本原有色盘。不要加入美妆磨皮、装饰光斑、时尚布景或未经要求的其他人物与文字。
```

**检查**：黑白、全身这两项本次覆盖生效；生活互动、自然光与纹理仍在；没有把样本人物／地点带入。强弱变化用可见差别描述，如更淡颗粒或更低背景对比，不套固定强度数值。

## 产品效果参考 → 真实产品适配 → 实际重附

先分概念产品与真实产品任务；后者需要可读产品依据，不能只凭产品名重建标识。

1. 从效果参考只取用户想借的机位、摆位、光线、材质呈现、场景层次与留白，排除原商品、价格、标语等未授权内容。
2. 查看真实产品，按轮廓、部件、材质与展示重点调整方案；原参考的反光、支撑物和取景不一定适合新产品。先写能展示哪些真实特征，而非给不存在的卖点补道具。
3. 最终调用重新确认真实产品位图实际附入；上游分析看过图不算。效果图可只作为阅读依据或按职责附入，不强制三次调用或固定图数。

## 海报的五项规划与完整例

输出前共同核对：**主体／场景／动作、美学方向、精确字串、字样／位置、全图层级**。字样包括字体观感、大小主次与行列关系，不只说“有文字”。描述语言可翻译，用户已给定的上图字串保持原字、大小写和标点；用户请你创作文案时可提出设计候选，并在最终 prompt 中明确所选字串。需要呈现的真实价格、销量、认证、科研事实等仍须有依据，不能由文案创作代填。

### 完整例：效果参考适配杯子海报

**用户目标**：用真实杯子做极简海报，借效果参考的柔侧光与留白；文案已确认。**必要输入**：图1为真实杯子，图2为已查看效果参考。本例假定图1是有把手的釉面杯；图2只供布光与空间，不提供产品身份。文案为本例演示内容，不是商业事实。

```text
为图1的杯子制作极简产品海报视觉稿。图1提供实际产品：保留杯身轮廓、把手连接、釉面材质与原有标识，不新增配件或产品功能。
图2只借柔和侧光、简洁前后层次与一侧留白，不继承其商品、支撑道具、价格、标语或标签。按图1杯子的体形调整摆位和反射，让把手连接与釉面都可读。
杯子在画面右侧完整可见，置于浅暖灰承托面上，有自然接触阴影。柔光从左上侧照亮杯身，少量轮廓高光区分杯口与背景，不过曝，不把杯子变成金属。
左侧为标题区，标题准确写“把日常握在手心”，使用清楚简洁的中文无衬线字样；下方以较小字号准确写“陶瓷马克杯”。只出现这两行海报文案，不生成价格、销量、认证或额外小字；产品自身原有标识保持原样。
标题与杯子不遮挡，阅读顺序先标题再产品、最后副标题；保留充足留白，不加入人物或装饰场景。
```

**检查**：实际附入图1；产品轮廓／把手／标识及釉面保真；两行文案逐字正确且无额外串；字样、位置和阅读层级成立。产品与美术分别验，必要时用获授权的后期排字保证成品。复杂内容按最终阅读尺度删装饰或拆张，不用增加字量填满空白。
