# 三视图与简易3D结构引导

结构引导用于锁定大致框架，减少姿态、连接、体块和机位歧义；它不等于已经证明的生图收益，也不替代最终图像。工具、素材和执行权限沿用当前环境，不因选择本策略自动安装3D软件或建立通用骨架系统。

## 什么时候主动采用

- 同一角色／产品需要多个机位、三视图或系列动作，身份和结构容易随视角改变。
- 文字与单图难以说清相接、前后遮挡、开口、折返或体块朝向；连续修改出现相同结构漂移。
- 用户明确希望先统一大致形体／姿态，再生图完成材料与造型。

只有简单单图、已有清楚目标姿态且无需结构重建时，不必先做3D。结构问题可由一张清楚草图解决时，先用草图；需要统一多机位关系时再考虑简单3D。选择最小能说明问题的手段，不以几何精度挤占成图。

输入精度跟随设计阶段：探索意向可留大轮廓自由；已确定体量时用粗体块／关键连接；表达既定方案才需要更完整白模。草图太含混时可补关键结构，拼贴过杂时则降低无关纹理杂色、清理多余边缘；两者都为结构可读，不是细节越多越好。处理派生图而不覆盖源图，检查清理没有删掉重要轮廓、标签和识别点。候选也可明确作为待合成局部材料；最终仍验整图，不把素材库数量算成成品数量。

## 从基准到真实输入

1. **选择基准**：找到明确用途的身份图／当前选用版本，列关键识别点和未确定部分。正、侧、背图互相冲突时不能直接合并成“正确三维”；先指出冲突，按本次任务和用户已认可范围取舍。未见背面属于拟设，不伪称原设定事实。
2. **确定约束粒度**：列必须保持的大关系，如头躯尾的体量关系、肢体连接、开口、折返方向及动作重心；列可自然调整的曲率、细节和遮挡。不从一张投影反算并强制真实骨长，不沿用无依据的角度限位或固定比例。
3. **建立简单结构**：用球／盒／椭球等体块表示主要体积，节点与连线表示连接和大致姿态；需要轮廓／覆面时再增加少量体块或面。线段、实体杆、膜／壳填面分开，避免辅助线被误读为新增器官，开口被错误封闭。只实现当前视图／姿态所需控制，不制作完整解剖、动力学或绑定系统。
4. **安排相机**：记录上／前方向、机位与观察对象，区分结构对照机位与最终画面机位。三视图可采用便于比较的正交正、侧、背观察与一致姿态／尺度；最终图若需透视，用任务机位另渲染，允许透视缩短。不是所有项目都必须正侧背，俯视、斜视或局部剖视按待解决问题选择。
5. **渲染并先检查辅助图**：输出干净、可读的大形与必要连接；可分开线架和体块，避免无关文字、材质和残边。逐图检查相机、同源姿态、留空、遮挡、左右及多余填面。程序计算成功只证明辅助物产生，不证明输入正确。
6. **选择实际附图**：将需要的渲染位图真实提交给生成端；按当前接口使用独立图或明确标注的拼板，核对顺序和职责。身份／材料图实际附入，不能仅在旁边人工看过。提示说明结构图只供什么、不要继承什么，参考数量服从任务与接口而不是固定三张。
7. **生成并分层回看**：先核大方向、重心、连接、遮挡和机位，再核身份、自然形态、材料及整体完成度。多视图逐张检查后交叉看关键特征位置；不要求未经授权的像素／骨长／投影硬阈值。辅助图正确与最终图正确分别记录。

结构源、相机／姿态版本、渲染图、实际附图关系按[生成记录](generation-records.md)保存。模型内部未公开的结构控制保持未知；普通图像参考不冒充显式骨架控制通道。

## 两种可复用路径

### A. 三视图整理基准

从一张身份图出发，先生成或绘制正／侧／背候选，用统一姿态、尺度和主要识别点帮助对照。分别标明原图可见事实和补设部分；核对头型、部件位置、连接与轮廓，不以三张放在一页就称一致。选择可用基准后，再供具体动作／场景；若任务只需静态三视图，到这一交付即可，不继续搭骨架。

### B. 简单3D统一动作与机位

用已选基准建立简易体块／骨架，摆出当前动作，渲染任务机位；需要对照时同时渲染少量正侧背。先修辅助图中的错连／多余面，再与身份参考共同生图。结果若方向对但身份丢失，审计身份图与参考职责；若重复出现辅助结构错误，回修源模型，不仅追加否定词。

### 完整例：身份 + 简易3D姿态的机械兽奔跑

**用户目标**：保持机械兽身份，换成清楚的前冲动作。**必要输入**：图1身份图；图2为已检查的简易骨架／体块侧前方渲染，二者都需真实附入。本次是新姿态候选，不承诺原图像素不变。下列是表达示意，效果待验。

```text
生成图1同一机械兽的全身奔跑概念图，采用图2的观察方向、躯干前倾与四肢大致走向。
图1只负责身份：楔形头、背部覆叠甲片、短粗尾与灰白外壳配橙色关节；不要把图1静站姿态带入。图2只负责重心、连接和空间框架，不复制灰色体块、骨架线或简化几何外形。
前足接近落地，后足向后蹬起，所有肢体都从相应肩胯自然连接；允许透视缩短、局部遮挡及自然曲率，不要求逐点描线。
用清晰侧前方全身机位呈现前冲瞬间，保持图1硬表面材料与关键识别特征。背景低对比，无文字；四肢和尾部不要被画框截断。
```

**检查**：身份、行为、连接、机位分别判断；3D输入存在且正确不代表最终图自动通过。若再转放大／重绘阶段，重新审每类身份、区域和结构条件是否仍需、是否实际传入，并回验；不默认全部沿用或关闭。

## 停止与边界

辅助图已能表达验收重点时就转向生图；重复输出仍无法兑现，说明限制并选择局部编辑、换基底或更合适工具。新建完整3D工程、精确重建和视频运动验证属于范围升级，先取得授权。静态多视图、简单骨架与自然美术连接不证明真实解剖、可制造性、动力学或视频连续性。
