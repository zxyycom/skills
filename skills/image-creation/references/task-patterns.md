# 任务分支与样例

只读当前分支。样例用于表达职责和检查点，不是固定提示公式或已经通过生图实验的模板。

## 角色、产品与系列图

先建立可辨认的基准，再列“跨图稳定什么、本图变什么”：

- **稳定**：关键身份特征、产品外形／标签、媒介、主色或品牌方向，按用途选择。
- **变化**：场景、姿态、观察角度、状态、构图等本次授权变量。
- **逐图交付**：每项用途与资产数量；单张拼板不自动等于分别可用的文件。
- **验收**：每张身份、内容与关系，再检查系列风格。整体气氛近似不能替代产品保真。

先做有代表性的基准再扩展，而非未验证就批量放大错误。单张参考未展示的背面与遮挡部位属于生成推测；多视图相似、固定 seed 或同一大图并不证明三维精确一致。视频前期图只交付静态资产；实际镜头连续性需另以视频工具验证，不擅自把静图任务扩成视频项目。

## 文字、信息图与专业内容

1. 从用户／已核实来源取得精确文案、数据和关系，区分真实内容与明确标注的演示占位。缺真值时不编造科研模块、价格、引文或统计来填满版面。
2. 按信息层级、阅读顺序、分区及连线写简报，文字逐字给定；画幅由字量和使用空间决定，不固定某一比例。
3. 分开验文字字符／译义、标签归属、箭头关系、事实真值和美术表现。对照全部需要交付的区块，小字看不清即未验，而非默认正确。
4. 精确图表、公式、系统工程源或可编辑矢量优先用相应确定性工具；生成图可以提供视觉稿或装饰，但不能冒充计算正确或可维护的源文件。需要后期排字或合成时，先确认工具与授权，再核对最终成品。

## 紧凑提示示例

### 从零成图：把抽象气质落到画面

请求：“画一只在雨夜等车的小狐狸，温暖但孤单。”

可执行描述示意：

> 一只小狐狸独自在雨夜公交站等车，身体微缩、目光朝向空的道路。暖色站灯照亮它的脸与湿毛，站外是冷蓝雨幕；中景能同时读出表情和空站台，狐狸是唯一主角。温柔手绘质感，不加文字。

用户若已有明确风格／构图，以其要求替换示意选择；不为展开情绪自行添加第二角色或剧情。执行后看情绪是否来自姿态与空间，而不只剩冷暖滤镜。

### 参考融合：身份不等于姿态

请求：“用图1的角色做图2草图的奔跑姿态。”

可执行描述示意：

> 图1提供同一角色的面部、服饰与材料；图2只提供奔跑的大致重心、四肢方向和取景，不继承草图的外观、颜色或多余线条。呈现正在前冲的瞬间，连接自然，允许透视缩短与遮挡；保持图1关键识别特征。

执行前看清两张图，并按当前工具决定是编辑图1还是参考引导生成；所选路线及其保留风险不能仅靠这段文字消除。执行后分别看姿态、身份与连接。

### 局部编辑：载体与非目标回归

请求：“只把海报中上排人物的红围巾改成蓝色，下排完全不动。”

可执行描述示意：

> 以图1整张海报为编辑目标。仅将上排人物颈部的红围巾改为蓝色，保留其褶皱、材质、姿态与原光影。保留脸、衣服、文字、版式和整个下排内容；不将蓝色扩散到其他物体。

如果“完全不动”要求像素级保护，先确认区域工具／合成能否兑现；自然语言保留不能保证。输出检查上排围巾、邻域和下排，不只验改色成功。

## 只要提示词或缺少执行工具

交付足以让执行端继续的最小信息：最终提示、编辑目标与实际附图顺序／职责、规格、保留项和主要验收点。仅在确实需要用户提供时保留占位，并说清应填什么；不要把未验证的参数写成既定配置。

用户原本要成图而当前无法执行时，明确说“尚未生成”，说明缺少／失败的是哪个环节；提示是阶段成果，不是完成的图片。不要无声切到另一平台，也不为凑交付创建替代 SVG 或占位图。

## 需要验证方法收益时

仅在用户授权实验后设计对照。先确定视觉问题和逐项指标，记录基线的自然波动，再改一个因素；尽可能固定模型／入口／版本、参考、规格与可控设置，保存全部输出，不只选最好的一张。seed 只是条件之一，不保证身份不变或跨版本可比。条件无法固定时，把结果称为案例观察，不宣称成功率或唯一原因。
