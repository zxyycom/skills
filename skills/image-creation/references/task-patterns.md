# 任务分支

只读当前分支。核心提示构建见[提示词工程指南](prompting-guide.md)，专题按本文件路由读取，实际调用及回看证据统一见[生成记录](generation-records.md)。

## 角色、产品与系列图

多画面先区分同一时刻多视角、时间推进故事、独立方案或状态过程，再按[系列与版面](series-and-layouts.md)确定公共项／变量、可读容量与逐图交付；该文件含故事自动展开、换装观察表、方案板、过程板及图标完整例。需要统一结构或机位才读[结构引导](structure-guidance.md)，不让普通系列任务自动变成3D工程或视频项目。

用户希望复用已认可审美时，读[可覆盖视觉配方](style-and-design.md#从认可样本提炼可覆盖的视觉配方)，输出来源、认可范围和本次展开后的提示；这不授权自动修改用户长期配置。真实产品借效果参考、文字海报的五项规划及完整例也见该专题。

## 文字、信息图与专业内容

1. 对既定文案或需表达的真实数据、事实关系，以用户／已核实来源为依据，区分真实内容与明确标注的演示占位。缺真值时不编造科研模块、价格、引文或统计来填满版面。
2. 按信息层级、阅读顺序、分区及连线写简报，文字逐字给定；画幅由字量和使用空间决定，不固定某一比例。
3. 分开验文字字符／译义、标签归属、箭头关系、事实真值和美术表现。对照全部需要交付的区块，小字看不清即未验，而非默认正确。
4. 精确图表、公式、系统工程源或可编辑矢量优先用相应确定性工具；生成图可以提供视觉稿或装饰，但不能冒充计算正确或可维护的源文件。需要后期排字或合成时，先确认工具与授权，再核对最终成品。

专业关系图先列节点／区域、边型／方向、标签及图例，再核编号、名称、色彩语义在多处是否一致。对照可信内容依据、当前图与实际旧词，把“箭头连错端点 → 误解流程 → 正确起止与边型”改回关系描述，并回验其他边和标签。真值来自用户、可靠来源或领域审查，不由模型自评分认证；转换为矢量或后期排字后仍重验内容和真实格式。

## 只要提示词或缺少执行工具

交付足以让执行端继续的最小信息：最终提示、编辑目标与实际附图顺序／职责、规格、保留项和主要验收点。仅在确实需要用户提供时保留占位，并说清应填什么；不要把未验证的参数写成既定配置。

用户原本要成图而当前无法执行时，明确说“尚未生成”，说明缺少／失败的是哪个环节；提示是阶段成果，不是完成的图片。不要无声切到另一平台，也不为凑交付创建替代 SVG 或占位图。

## 需要验证方法收益时

仅在用户授权实验后设计对照。先确定视觉问题和逐项指标，记录基线的自然波动，再改一个因素；尽可能固定模型／入口／版本、参考、规格与可控设置，保存全部输出，不只选最好的一张。seed 只是条件之一，不保证身份不变或跨版本可比。条件无法固定时，把结果称为案例观察，不宣称成功率或唯一原因。

先区分**创意探索**与**方法验证**：探索在授权数量内比较可用方向，不要求一次只变一词；验证才选择能区分解释的对照。总调用／输出数与可能重试计入预算，不按“批数”掩盖实际费用。

要判断两个候选是否互相促进／压制，先看无候选的基线，再看A、B，最后A+B，不能把单项效果相加。变量可以是单词或完整短语组；只问整组是否有用时整组比较，要定位组内原因再拆组。四条件只是设计示意，不授权为普通成图自动多生成四张或穷举组合。

**可改写实验示意**：用户已授权比较水彩边缘与纸感，基线完整提示为“画一只完整可见的橙色狐狸侧身坐在浅灰背景前，姿态安静，画内无其他对象和文字”。A只追加“轮廓边缘有轻微水彩渗染”，B只追加“浅色背景保留细微纸面纹理”，A+B追加这两句。逐条件保存展开后的完整实际词和全部输出，分别看边缘、纹理及主体身份／数量回归；若组合出现脏边，不能只因A和B单项喜欢就保留组合。样本不足只能报本次观察，不保证复现或统计收益。
