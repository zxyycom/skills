# 正文反推与对照报告

从正文证据恢复细纲、实际导演视角与模拟读者信息，再逐项对照目标卡，形成供作者选择修订方式的报告。本地流程按提取、对照与回查分阶段执行；上下文独立性须依据实际输入另行说明。

## 执行与证据要求

1. 锁定正文输入（路径、版本/hash 或可复核快照），确定定位方式（行号、段号或章节+短引文）。长引文只保存必要证据，原文仍是事实源。
2. 提取阶段只读取正文及必要背景；列出实际输入，不读取目标细纲/导演卡。若当前会话已经知道目标，声明上下文污染，不冒充盲审；要独立执行必须另有被授权的独立上下文。
3. 形成事件因果、实际视角/信息显隐/切场，以及模拟读者所知、期待与困惑；逐项附定位，不把作者意图当正文证据。
4. 先固定提取结果，再进入对照阶段，读目标卡与必要上层约束。为每个目标义务匹配提取项；未匹配先回查原文，区分“正文未表现”和“提取未发现”。局部节录不足以支持全文缺漏结论。
5. 用合法差异、偏离、证据不足、待作者决定分类，提出选项而不改卡或正文。模拟读者只是模型判断，不是实际读者测量。
6. 本 skill 未接通独立远端审稿 API。外调须有接口契约及显式稿件传输、费用授权；缺失、失败或未授权时保持本地流程，报告接口未验证，不发送稿件、产生费用或伪造响应。

```markdown

- 对照阶段目标 ID 与实际读取卡：
- 外部调用：未使用 / 明确授权及实际结果（没有调用不得填“通过”）。
```
