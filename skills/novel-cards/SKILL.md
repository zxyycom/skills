# Novel Cards

## 目标

用卡片承接作者的当前规划，从构思或已有文本建立小说结构，按受影响层级修改，再依据细纲与导演视角写作。正文反推提供可定位的差异证据，卡片或正文如何修订由作者决定。

## 读取路径与运行前提

1. 建卡、修改、查询前完整读 [卡片与本地工具契约](references/card-contract.md)。它唯一拥有字段、目录、身份、引用和 CLI 边界。
2. 正文反推或检查前完整读 [反推与对照报告](references/review-report.md)，按其中的提取、对照和回查阶段执行。
3. 本地工具需要 Node.js >=24.18，无其他 skill 运行时依赖。实际稿件、卡片与报告保存在小说项目；已安装 skill 只提供通用流程、契约与 CLI。

## 卡片模型

- **详情**承接领域实质：剧情详情包含细纲与导演视角，人物/设定详情包含必要核心信息与明确剧情位置上的状态。
- **总结**是可任意递归的语义压缩，保留因果、转折、适用条件与残余矛盾。顶层剧情总结叫剧情卡；卷、册、弧线、章是组织标签，章也能是总结。
- `children` 表示组成与展开，`sources` 表示依据。总结可以只压缩来源而不拥有那些剧情节点，也可以先有完整远期意图，待实际建卡后再补下级 ID。
- 人物/设定的阶段与变迁复用递归总结；具体变迁由剧情节点承担，历史总结引用这些节点，保持同一套事件事实。
- 人物关系以有向边表达，两个方向各写态度和知情状态；共同的关系事实与各自的认识分开判断。

## 主工作流

### 1. 恢复任务与阅读范围

1. 确认小说项目根、作者意图、当前故事位置、叙述范围、已有卡片/稿件以及写入授权。已有文本与原创构思走同一工作流，只是事实输入不同。
2. 对同人确认原作 cutoff。cutoff 之后的设定/弧线可由作者选入当前区作为可修改预期；后续单章详情可完整提取至独立参考区。区分已保存的参考内容与作者已采用的当前规划。
3. 先运行 `check`；未初始化或索引陈旧时核对来源，合法集合经授权显式 `sync-index --write`，再查询。身份按精确 ID 选择，失败时修复来源或选择，而非猜测相似卡。
4. 先 `show` 顶层或最高相关总结，再用有界 `expand` 逐步下钻；从返回的 `frontier` 继续读取。`expand.complete` 只描述本次 `children` 闭包，所需的 `sources`、`refs`、关系与状态锚点正文须另行显式读取。
5. 参考内容用具体 ID 与 `--include-reference` 显式选择。CLI 全体机械扫描会读取参考区字节校验，但查询只输出被选内容；分别记录校验范围、agent 实际阅读范围与作者采用范围。

### 2. 建立或反推卡片

1. 从作者意图或来源正文恢复剧情结果、动机、代价、因果与信息变化；不确定项留为作者问题，不补造发生事实。
2. 从顶层剧情卡逐步展开，组织标签按实际小说采用。待展开规划使用 `planned`，可以保留无下级总结。
3. 剧情详情分“细纲”和“导演视角”：细纲记录事件因果、行动与变化，导演记录多线组织、切场、焦点人物、视角、信息显隐及节奏，不强迫严格电影分镜。
4. 人物/设定详情通过 `state_at` 锚定剧情位置；核心信息与位置状态分别写清。关系态度、人物所知与作者所知分开，不把单向认识当双向事实。
5. 用总结承接下层因果与条件，`sources` 引实际依据，`children` 引实际组成卡。
6. 时间元数据附在相关卡，分别写故事时间与叙述位置。`expected`（预期/未来）表示作者安排但尚未发生；`planned`（待展开）表示规划完整度。混合范围总结使用 `mixed`，正文分清已发生与预期段，保持 `occurred` 的真实发生含义。
7. 完成机械检查与语义复核，再同步索引。

### 3. 修改与传播

1. 作者先改卡片，从**最高受影响卡**向下复核：变更顶层结果则先改顶层，局部详情变化则先判断是否影响更高总结，再从最高实际受影响处下传。
2. 查实际 `children` 与 `sources`/`refs` 的依赖，列出受影响卡、理由、正文范围及待决定项，按实际影响逐层核对。
3. 明确每个位置的当前状态与预期；预期不得自动覆盖已发生位置的状态。新故事节点发生后，由作者确认再更新对应状态及历史摘要。
4. 重写总结时恢复原因、转折、条件和残余冲突，复核它是否仍准确概括实际下级或来源，并在交付中列出已核对/未核对项。摘要有效性由 agent/作者判断，索引同步不自动确认或标记语义失效。
5. 正文不会自动反向回写卡片；正文发现新构思时先报告，再由作者决定改卡并下传，或改正文回到规划。

### 4. 按卡写作

1. 读取目标详情、必要祖先约束、实际依据、人物/设定位置状态；引用只证明可定位，需要显式读取所需正文，不以索引标题推断内容。
2. 明确这次章节采用的细纲、导演约束、可自由调整的表达及允许的差异。若章为总结，先展开到本次执行详情。
3. 写作时保留因果和信息义务，允许语言、镜头密度和局部呈现的合法变化。输出正文不改卡或发生状态。

### 5. 正文反推与独立对照

1. 先按报告契约锁定正文版本与定位方式，提取阶段读取正文和必要背景，不读取目标细纲/导演规划；若无法隔离已有上下文，如实标记，不冒充盲审或独立模型。
2. 先交付证据化细纲、实际导演视角与模拟读者信息/期待，再独立读取目标卡逐项对照；模拟读者不是实际读者测试。
3. 缺漏或冲突先回查正文，并区分“正文未表现”和“提取未发现”。差异分类：合法差异、偏离、证据不足、待作者决定。
4. 检查只产出报告，作者决定改正文，或先改卡再传播。本 skill 提供本地流程，未接通独立远端审稿 API；外调需要独立接口契约及显式稿件传输、费用授权。

## 完成标准

- 卡片模型、范围、发生与完整度、状态位置、参考使用和传播路径清楚；所有实际引用可定位。
- 本次机械校验与语义复核分别说明：身份、引用和索引正确不证明因果、人物理解或文学质量；读取预算与未读 `frontier` 明确呈现。
- 报告引用正文定位，缺漏有回查记录，提取与对照隔离程度如实呈现；卡或正文修订由作者决定。
