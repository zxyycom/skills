# 易错判断集

本文件供设计与存量审查两套 SOP 在候选准入前共同校准；裁决门槛见[共同准入原则](../SKILL.md#共同准入原则)。

以下反例校准裁决，不是补测清单。只增加能改变判断的新边界，合并重复情形；效果验证使用未收录的材料。

## 准入与处置

1. **关键契约必须自动化。** 某关键 GUI 行为只能用昂贵且脆弱的环境验证，仍要求补齐自动化。
   契约重要不等于方案通过准入；成本不可接受时可以明确不自动化，在授权内接受风险。硬性自动化要求交 owner 决定，出现低成本可靠入口时重新举证。
2. **便宜就值得保留。** 一个稳定、瞬间完成的测试锁定无消费者依赖的私有计数，因开销小便长期保留。
   低成本不能代替保护价值；没有具体资源、兼容或消费依据，就不能通过准入。
3. **有效就取得当前形态的保留资格。** 证明某条重型测试能拦截重要错误，就连同全部准备、场景和断言保留。
   有效性和价值不能替形态与开销举证；当前形态不成立时退出或降级，不能借用大类的重要性保住整组。
4. **保留待修复。** 发现断言失效，立即提出修复，并将旧测试列为保留。
   当前形态有效性未通过，不能保留；修复方案独立过三项门槛，可修不等于已准入。
5. **把未调查清楚当成无必要，或反过来。** 未读完就判删；事实已清楚却提不出投入理由，又以“待确认”原样保留。
   未读完不能判删，也不能计入已证明应保留；事实已清楚却缺依据时判不准入，不能用未决代替取舍。
6. **用失败或精简目标代替淘汰依据。** 关键测试因真实产品缺陷失败就被删除；或已充分举证，却因想减少数量而删除关键观察。
   报告真实缺陷，保留通过三项门槛的测试；测试失败不等于无效，不设删除配额。
7. **没有替代所以先留。** 当前观察的必要性无法成立，却要求找到等价探针后才允许删除。
   事实查清仍无准入依据时退出，说明失去的保护；替代不作为默认退出前提。只有明确决定继续承担保护时，才核对替换是否就绪。
8. **找完问题，其余自然必要。** 全部文件已读，只对问题项详细举证，再用“核心行为覆盖”批准剩余测试。
   读取不等于准入；保留者同样须有适用的三项依据。成组说明须覆盖明确成员的实际锁定内容，不能用一条重要观察批准全部附带约束。

## 职责与证据

1. **把局部测试扩成全链路证明。** 验证状态计算函数的幂等性，却因其结果最终用于文件更新，要求同条测试再监视写入。
   按计算函数自身契约验证幂等；执行副作用另属执行函数，缺少其断言不构成本条测试的缺陷。
2. **相同输出就是重复。** 规则测试与参数映射测试都返回成功，就删去其中一个；反过来，同一矩阵经重入口重复运行又全部保留。
   计算与接线分别举证，不能因输出相同就互相替代；同一责任的等价样例选择代表，独有参数解释在所属层验证。
3. **正确预期照搬当前实现。** 规则要求“小于 100 才通过”，源码使用 `<= 100`，测试手写“100 应通过”；或保存未经审核的当前快照。
   用契约校准边界预期；同一契约指导代码与测试是正常的，照搬其错误解释却无法相互检查。只有当前输出时可以刻画行为，不冒充正确性证明。
4. **混淆协议与内存表示。** 文件契约要求字段有序，测试却断言解析后 JS 对象的 `Object.keys` 顺序。
   文本格式由解析或序列化层验证；解析器改变属性构造顺序不应使业务测试失败。

## 设计变化

1. **难测就重构，或实现不可质疑。** 为构造一个规则样例需要启动整套环境，直接增设通用注入框架；或只允许继续补重型测试。
   先区分测试范围、投入价值、实现职责与固有复杂性，再比较保留现状、调整测试、不自动化及有限设计调整的整体得失；测试便利不自动授权生产重构。
2. **实现已改，旧测试照修照留。** 状态模型调整后，直接把旧断言更新到全绿，未核对原风险是否还在，也未说明行为变化；或在重构尚未实施时先声称旧保护可退出。
   按实际变化重审受影响候选的三项门槛，允许退出、降级或重设计；行为变化先获确认，新风险同样举证，条件方案不冒充已有保障。
