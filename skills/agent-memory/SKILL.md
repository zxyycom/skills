# Agent Memory

## 使用边界

只访问宿主显式绑定的一个项目库。记忆是判断线索；现行规范、当期事实和操作权限分别以相应规范、证据和当前授权为准。只保存用户明确要求保留的项目内容，排除凭据等敏感值。

调用前读 [CLI 操作](references/cli.md)，使用固定的项目根和库路径。工具或绑定不可用时，报告限制并继续不依赖记忆的工作；不在查询时自行安装、建库或换库。

## 召回与采用

1. **判断相关性。** 先确定哪项当前判断可能被既有做法、纠正或待回访条件改变。没有具体关联就直接处理任务，不查询；仅同属一个项目或提到同一个工具不算关联。用户明确要求查看或管理记忆时，按请求处理。
2. **从换述构造线索。** 从问题提取对象、动作、场景，换成可能的项目术语。给 `recall` 若干精确标签和短原文关键词，无需原标题或 ID。标签精确匹配，标题和正文按字面子串匹配。无命中时可换一组同任务的线索；被截断时收窄查询。
3. **核对当前版。** 对相关候选用不带版本的 `show`。命中和当前可用都不等于适用：核对它回答的问题、适用条件、证据和重查条件。条件不符或单元被阻断时不采用，不用历史版绕过；条件未知时只给出带前提的说法。当前任务确需补证且获授权时再回查来源。
4. **保留证据强度。** 区分材料记载、限定条件下的直接观察、推断和用户明确确认的范围。结论只采用有依据的部分；报告关键依据、适用范围和影响判断的未知。区分未触发、未命中、命中未采用、命中并采用与查询错误。

### 待回访意图

任务涉及活动意图指定的问题，且触发条件成立时，才核对其证据。只有新证据会改变判断时才提醒，说明改在哪里。意图不启动轮询或后台任务，也不授权采取行动。

结束意图保留原证据，但停止为它召回、重查外部证据和提醒。当前请求若独立需要同一份证据，按本次授权处理；新对话中没有找到适用的活动意图时，不为回访补查资料。

## 保存与修订

1. 说明要改善哪类判断，先查是否已有同一条认识。记录出处、适用条件、未知及形成时间或重查条件；把有依据的推断标为推断。用对象、动作、场景和常用换述作标签。
2. 基础认识保存实际依据。联合认识引用确切前提版本，解释每项前提的作用，并用新问题检验解释；一般的支持、限制和冲突不算构成依赖。待回访意图记录触发条件和要核对的问题。
3. 修订须核对当前版本，说明结论、范围、确定性或状态是否实质改变。用现行可用前提复核，或明确移除不再采用的前提。含义不变与实质改变分别声明；冲突未解则保持待复核。

## 用户控制

先确认具体单元和授权，按 [遗忘预览与提交](references/cli.md#遗忘预览与提交)区分停止使用、停止召回和库内清除。清除前说明将删除的单元及历史、保留单元会失去的关联，并取得对当前预览的明确确认。连带删除不可接受时，可先在授权范围内停止召回。清除只覆盖受控库；外部记录、备份及介质擦除不在承诺内。

执行了保存或用户控制时，说明实际生效的范围和保留的内容；不能验证时直接说明，不以发出命令代替结果。
