# AI-Ready Docs

## 目标与范围

以 AI 实际获得的文本为依据，整理同一份可维护的权威内容，使目标 AI 能识别文档的用途、对象、信息、关系、范围、权威性和边界，并完成预期任务。人类可维护性是约束与共同收益；已有契约要求的机器字段或消费视图，应能追溯到权威内容。

本 skill 处理文档侧的语义和组织。获取、解析、索引、召回与上下文组装属于交付链路；所需信息未进入 AI 上下文时，明确指出缺口及其影响。纯措辞润色和视觉美化不触发本流程。

## 读取策略

1. 普通编辑直接使用下方流程。
2. 遇到原理争议、复杂取舍、不熟悉的文档用途或需要解释理由时，按标题读取 [principles.md](references/principles.md) 的相关章节；校准例只帮助判断边界。
3. 整体审阅本 skill、检查引用一致性或多个原则相互影响时，读取完整原则文件。

## 工作流程

### 1. 确定消费场景与处理范围

- 确定目标 AI、实际可用文本、预期操作和可观察结果。用户指定文件或目录时以其为范围；只给出项目时，从当前 AI 任务及已暴露问题定位直接相关文档。
- 标出必需但未进入上下文的信息，以及安全、隐私、机密性、权限、合规、真实性、不可逆操作或明确契约风险。只有多个高风险目标的优先级会改变结果且无法恢复时，确认该优先级。

### 2. 恢复主承诺与内容 owner

- 从标题、开头、适用范围、触发条件、字段和输入输出恢复文档承诺；用正文的篇幅、层级、结论及验收方式检查重心是否兑现承诺。
- 按执行、流程、规则、说明、参考、契约、检查或协作等真实用途选择骨架。混合用途以最容易造成误用的一项为主线，其余内容按需降为局部说明或参考。
- 为事实、规则和关键判断确定稳定 owner。正文偏题时收窄入口或调整内容位置；有独立价值的内容移交对应 owner。

### 3. 核对语义并收敛内容

- 补足完成任务所需的定义、背景、输入、判断标准、步骤、边界、输出或示例。显式说明术语、指代、权威性、优先级、依赖、条件、例外、因果方向及当前与历史状态；区分事实与建议、规则与示例、权威内容与引用材料，把必要的口头或视觉语境写入文本。
- 以目标状态、必要约束、推荐路径和验收方式组织主线，同时保留定义或检验承诺所需的精确规格。禁止条款、反例与负向表述按其当前职责判断：独立的安全或协议边界保留；只重复已成立规则或继续点名退场方案的内容合并或删除。不要为了统一句式改变含义。
- 事实、规则和判断在 owner 处完整表达，其他位置只保留摘要、触发条件或引用。无关背景、重复解释、低价值示例和迁移残留退出主线；有判断价值的细节按需进入参考材料。
- 区分表达调整、事实补充、要求变化和领域决策。原意无法确认且不同解释会改变结果时，标明不确定性，交由相应 owner 确认。

### 4. 形成可恢复的阅读路径

- 使用稳定术语、描述性标题、清楚范围和局部足够的表述；将相关定义、条件与例外放在便于共同读取的位置。主文档保留任务主线，可访问的引用按需展开；不可访问时补足最小语境或暴露依赖。
- 遵循目标已有格式契约；没有契约时，用有序列表表达顺序与优先级，用每行自足的表格表达简单对照，复杂输入输出采用适合其用途的结构化格式。图示按关系类型与目标环境选择，关键语义仍须可由文本或图源读取。
- 保持原文主要语言；只有用户要求翻译或目标文档确需统一语言时切换。

### 5. 验证实际使用结果

- 用代表性 AI 阅读或使用任务检查：它能否从实际文本恢复目标、关系、范围、权威性与边界，并得到预期结果；再检查人的阅读和维护是否明显退化。
- 运行目标已有的格式、链接、schema 或文档检查。机械检查通过与 AI 实际使用结果分别报告。

## 边界与交付

编辑任务按授权范围写入；审阅任务交付问题、影响、建议及理由。高风险边界、更高优先级指令或明确契约冲突时先确认路径；缺失信息会实质改变结果时说明缺口并只问一个具体问题。其他可逆取舍按用户目标处理并说明。交付区分文档侧改动、外部交付链路状态、已验证结果和残余风险。

完成前核对：主承诺、骨架和 owner 是否一致；AI 能否恢复必要语义并完成任务；原意、精确边界和风险约束是否保留；重复、冲突、模糊与历史残留是否收敛。
