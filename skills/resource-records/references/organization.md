# 资源组织与用途选择

本页帮助判断身份粒度和当前选用；字段与硬约束见[记录模型](record-model.md)，完整场景见[示例](examples.md)。

## 身份与变化

| 信号 | 处理 |
| --- | --- |
| 需要稳定归类 | 使用集合及其父子层级；tags 用于横向筛选，不能代替层级、版本或选择。 |
| 对象或制作分支可独立选用、修改或追溯 | 建立 resource；同一制作对象的小步演进使用多个 version。 |
| 同一确切内容新增保管位置 | 确认内容一致后，为同一文件增加 location；无法确认时不视为同一文件。 |
| 文件内容修改 | 另存独立版本及路径，保留旧版。既有文件身份和内容、图包成员身份、组成、目标及顺序不漂移。 |
| 新增仅展示本版的附属预览 | 可在同版追加独立 ID 的 derivative file，用 `preview-of` 指向确切源文件；不必仅为补预览新开版本。 |
| 图包可独立选用 | 建立图包 resource，以有序 members 引用确切文件；改变成员身份（包括 ID）、组成、目标或顺序形成新图包版本；这不同于同版新增独立 ID 的附属 file。 |

### 裁片与重设计

裁切仅随主图展示时可作同版 derivative；作为实际输入、独立复用或具有独立迭代生命周期时，可独立成 resource 并追溯来源。底图改出新设计是新内容候选：同一制作对象的演进用新版本，需独立选择或长期分支则用独立 resource，并记录制作沿革。按真实用途和证据判断，不因尺寸自动分类，也不把重设计称作预览。

## 关系与当前选择

版本 `parents` 表达制作沿革；文件 `input` 表达实际输入，`preview-of` 标记预览对象，`reference` 表达参考；图包 `members` 是有序引用和别名，集合 `selections` 是用途决定。这些关系互不推导，具体证据及引用约束见[记录模型](record-model.md)。

| basis | 选择依据 |
| --- | --- |
| `agent-provisional` | 代理可逆暂选。 |
| `user-preference` | 用户表达的偏好。 |
| `user-confirmed` | 用户明确确认的范围。 |

保留选择的 scope 和证据，不知道是否确认时不能升级 basis。每个集合的选择范围独立、不继承；当前用途由 slot 明确选择决定，新版本不会自动升级选择，历史作品引用也不漂移。
