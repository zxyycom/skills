# Design

以详情与总结构成递归卡片模型；文件为事实，索引只承接可靠定位，文学语义由作者与 agent 复核。

## Context

采用详情与递归总结模型，卷、册、弧线、章是组织标签；人物、设定及历史复用总结模型但保留各自详情职责。当前行为与精确协议分别由 [skill 入口](../../skills/novel-cards/SKILL.md) 与 [卡片契约](../../skills/novel-cards/references/card-contract.md) 承接。正文反推只产生报告，稿件保留本地；独立远端审稿接口不在本 Change 内。

## Goals / Non-Goals

- 目标：可用的本地卡片维护与写作流程，以实际扫描证明引用存在，以证据报告支持作者复核。
- 非目标：通用图引擎、事件溯源、自动小说质量评分、正文自动回写、远端审稿服务或安装发布。

## Decisions

### Intended Change

1. 小说项目分开保存当前卡片与独立参考，稳定 ID 与路径分离。`children` 表示组成、`sources` 表示依据，其他明确关联由 `refs` 承接。
2. 总结可先保存待展开远期目标，也可仅依据来源完成压缩；详情承接细纲/导演或人物/设定位置状态，具体变迁复用 `plot` 节点。
3. `state_at` 锚定实际剧情位置，人物关系使用有向边分别表达态度与知情。时间字段提供显示信息，不承担时间算术。
4. CLI 复用现有 Index Runtime，来源指纹包含实际路径和完整文本；查询全扫合法来源并核对完整投影，使索引与实际卡片共同支持精确定位。
5. `expand` 只递归 `children`，预算到界输出 `frontier`；依据、关系与状态锚点显式选择后读取，参考卡须加 `--include-reference`。查询完成度只描述此次组成闭包。
6. 原创与文本恢复统一建立卡片；从最高受影响卡下传并复核总结。反推阶段隔离目标规划，对照阶段读目标；缺失证据回查，合法差异不当偏离。

### Resulting Impacts

1. 通过共享 bundler 生成 Node 自包含 MJS/source map，接入 updater、package scripts 与 Gate，源码与生成物保持一致。
2. 测试分别证明可读有效集合、错误身份/引用、循环、陈旧或篡改索引、参考隔离、有界展开以及生成分发。
3. 长期行为取舍集中在该 skill，测试 Case 和决策仅记录各自 owner 的证据与理由。

## Risks / Trade-offs

- 每次查询扫描全集合，以本地查询成本换取来源与索引的直接核对；文件/总字节/卡数有界，超限失败而非截断成功。
- 索引同步不标记或证明摘要语义有效；摘要、关系含义和混合状态需要人工复核。
- 受信本地工作区单写者，无恶意并发文件系统隔离承诺。

## Open Questions

无阻塞本 Change 的开放问题。真实作者使用、独立审稿 API 与大规模性能不属于本次已证明结果。
