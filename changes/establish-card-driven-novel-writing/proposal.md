# Proposal

建立卡片驱动小说创作 skill，承接规划、分层修改、正文执行和反推对照检查。当前为 Draft。

## Why

作者已用同一卡片体系进行原创与同人续写，需要将其整理为可复用的行为入口：AI 按卡片规划写作，修改由上层向下层传导，成稿通过正文证据与单章卡对照。

## Outcome

交付一个可独立使用的 skill：从作者构思或已有作品建立卡片，组织细纲与导演视角，按规划写作；修改按受影响层级传播，检查产出可复核的偏离报告。

## Scope

### Intended Change

1. 定义卡片职责、剧情卡 → 弧线卡 → 单章卡的层级，以及单章卡中细纲与导演视角的分工。
2. 将构思建卡与原文反推纳入同一工作流，明确预期、当前规划和参考区的使用方式，支持分层修改与正文执行。
3. 通过受控接口从正文反推细纲、导演视角和读者视角，与单章卡对照；按实际协议补充结构、引用和响应检查。

### Resulting Impacts

1. 新增 skill 本体与必要资源，同步仓库入口、独立版本和分发验证。
2. 若需随包工具，核定受控接口的调用、失败处理、费用与稿件传输授权，按项目源码／生成边界交付。
3. 用现实卡片和正文验证建卡、修改、执行与检查；审稿结果只提供依据，卡片或正文的修订由作者决定。

## Success Criteria

1. 原创与续写采用同一卡片协议，预期、参考区读取和上层修改传播方式清楚。
2. 单章卡能表达事件因果与多线镜头组织；报告附正文定位，并区分计划偏离、允许的表达差异和无法判定项。
3. 提取缺漏先回查正文；读者视角明确为模拟判断，实际行为证据与机械检查结果分别交付。
4. skill 结构、相关仓库检查和代表性行为验证完成，未覆盖的边界如实说明。
