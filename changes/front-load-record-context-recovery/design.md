# Design

本 design 将“先恢复可复用记录”设为两个 skill 的共同前置行为，并为调查请求增加明确的复用或复查分流；命令级 help 为这条主线提供就地查询指导。

## Context

- `decision-records` 已在形成候选前恢复相关 active 判断，现行决策 `260718-trigger-on-long-term-decision-points` 也要求触发后先恢复相关当前决策。
- `investigation-report` 已提供候选与正式报告查询，并要求区分同轮完善与独立新报告，但“查找与阅读”位于主工作流之后，尚未承接新调查前的复用选择。
- 调查报告保存形成时认识，而当前事实由代码、配置、规范和运行结果等 owner 承接。已有报告可能直接回答原问题，也可能因形成时间、范围、事实变化或剩余未知而需要复查。
- 现行决策 `260905-search-authoritative-files-with-index-identity` 拥有全文搜索、索引身份和只读降级边界；固定契约拥有精确查询语义；skill 与 help 只需提供完成当前任务所需的行为入口和操作摘要。

## Goals / Non-Goals

- **目标行为**：两个 skill 在新建或重新开展工作前选择最小查询入口、读取相关完整记录，并据此判断复用、完善、新建或停止。
- **调查选择**：已有报告足以回答原问题时，先恢复结果与边界，再按用户意图复用或复查。
- **运行时入口**：`list` 与 `search` 的命令级 help 支持普通正确调用和结果解释；固定契约保留完整语义。
- **既有责任**：搜索算法、索引 Schema、关系模型、生命周期和查询输出保持由当前 owner 管理；当前事实继续从事实 owner 验证。
- **交互边界**：明确要求最新验证或由项目规则要求当次调查时直接复查；Decision Records 继续按既有授权与偏离分类使用恢复的判断。

## Decisions

### Intended Change

1. **恢复已有记录**：两个 skill 在形成新记录前先检查相关 candidate，再按已知信息选择 `show`、`list` 或 `search`；需要理解直接演进时继续 `trace`。查询在足以区分继续候选、完善原记录、独立新记录或无需记录时停止。
2. **分流调查请求**：Investigation Report 按下表处理已有报告与用户意图。

   | 当前情形 | 下一步 |
   | --- | --- |
   | 既有报告大致回答同一问题，用户未说明是否需要当前验证 | 先概述已有认识，再询问复用还是复查。 |
   | 用户只要求查找、总结或审阅已有材料 | 直接交付已有结果及其形成时边界。 |
   | 用户明确要求重新调查、最新结果或当前事实，或项目规则要求当次调查 | 以旧报告为背景，直接按当前事实复查。 |
   | 没有足够相关的已有报告 | 继续正常调查。 |

3. **概述已有认识**：复用选择前说明命中报告的身份、形成时间、原问题、关键结果、主要依据、适用范围、未覆盖内容和剩余未知，并明确其尚未证明当前事实。用户选择复查后，以旧报告为输入，再按同轮完善或独立新轮次的既有规则决定记录方式。
4. **分层承载说明**：
   - `SKILL.md` 在读取路径和工作流前部说明查询选择、停止条件与调查分流。
   - 命令级 help 以紧凑的 `Semantics` 和 `Examples` 说明正式记录与 candidate 的边界、搜索范围、匹配模式、筛选组合、关系参数依赖、结果上限、warning 和 `show` 后续入口。
   - 固定契约继续完整定义查询、降级、事务、恢复和机器结构；面向人类的 `docs/skills/` 入口只同步开始顺序和核心体验。

### Resulting Impacts

- **行为文档**：调整两个 `SKILL.md` 与对应 `docs/skills/` 入口；实施前按 Decision Records 门槛承接长期行为方向。
- **CLI 表面**：扩展两个工具的 help 定义、行为测试和生成制品；以 `unify-record-cli-location-and-help` 落定后的 parser 与 renderer 为实现基线。
- **验证账本**：help 测试变化同步对应 Test Evidence Case 与索引。
- **分发**：按实际改动提升两个 skill 版本并更新生成制品。

## Risks / Trade-offs

| 风险 | 控制 |
| --- | --- |
| 询问复查打断明确任务 | 只在已有报告足以回答原问题且当前验证意图不明确时询问；其他情形按分流表直接执行。 |
| 形成时认识被误当成当前结论 | 概述固定包含形成时间、适用范围和未知；复查从当前事实 owner 取证。 |
| 有界或降级查询漏掉已有报告 | Skill 与 help 要求读取 warning，并在结果不完整时收紧条件或扩大查询。 |
| Help 摘要与固定契约漂移 | Help 只投影普通调用所需的既有语义，并由行为测试固定；精确规则保留在固定契约。 |
