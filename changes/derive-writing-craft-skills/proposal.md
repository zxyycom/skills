# Proposal

参考已有写作 skill 和方法材料，提炼可独立使用、适合本仓库维护的写作辅助能力。当前为 Draft。

## Why

结构、人物张力、场景呈现、对白和正文修订可由专项方法辅助。已有材料提供了参考，需要按实际写作任务提炼判断与动作，并辨明其中的题材偏好、流程约定和运行依赖。

## Outcome

交付经过边界审阅和现实任务验证的写作辅助 skills，数量与名称由候选收敛决定。仅服务某项流程的局部方法归入对应 skill 的按需资源。

## Scope

### Intended Change

1. 按实际需求提炼结构与读者期待、场景呈现、对白与人物声音、正文修订等候选能力。
2. 依据独立使用意图、行为责任与验收方式，选择新建 skill、扩展既有 owner、归入按需资源或不采用。
3. 为选中能力明确触发、输入输出、判断、权限与完成标准，形成可实施契约。

### Resulting Impacts

1. 核对来源、许可与必要归属，以可维护的表达组织方法；原文只按采用需要引用或留存。
2. 明确独立使用及协作边界；协作时保留作者现有工作流的规划与修改权限。
3. 同步新能力的入口、独立版本、分发与行为验证；工具和测试按项目对应 owner 接入。

## Success Criteria

1. 每个独立 skill 有可观察结果、明确触发与验收方式，所选边界符合实际请求。
2. 作者规则、题材偏好、参考方法和运行前置各有明确角色；必要依赖与协作关系显式声明。
3. 代表性请求和正反例支持所声明能力，许可核对、机械检查与实际行为证据分别可复核。
4. skill 结构与相关仓库检查通过，未验证边界如实交付。

## Affected Owners

- 待选定的 skill：具体能力与按需资源；按 [Skill Maintainer](../../skills/skill-maintainer/SKILL.md) 确定归属与分发。
- [仓库导航](../../docs/navigation.md)、[AGENTS](../../AGENTS.md)、[README](../../README.md)与[项目工具链](../../docs/tooling.md)：正式入口及必要工具集成。
- [Test Evidence Review](../../skills/test-evidence-review/SKILL.md)与[Decision Records](../../skills/decision-records/SKILL.md)：新增测试与达到记录门槛的长期判断。
