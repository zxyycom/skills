## 结论与未闭合项

- **DR new/readiness 有明确非必要来源范围，尚未通过性能验收。** 有效发布索引含 10000 个正式路径，两个候选、所选候选无直接关系；after 两动作均只 load/parse 一次索引，但均发生 10002 次 `readDecisionCandidateHeader`、10002 次 read-only open 与 10002 次 FileHandle.readFile。
- 冻结源码中 DR `candidateMembers()` 把正式与候选位置均交为 `unknown`；共同准备已构建 publishedPaths，却只对 kind=formal 跳过已知正式路径，故合法发布投影未被用于跳过这 1W 个 header。此处是范围/准备问题，**不是已接受安全保证成本**；必须保留真正候选、选中来源/直接依赖安全与缺索引扩展发现。
- 旧版 readiness/new 的 domain body parse 分别仅 1/2 次，不能称旧版全体 body readiness。旧版 fs.readFile 分别 10004/20007；新路径减少重复 index/投影准备仍不能抵消非必要全集安全 header 成本。所有计数、插桩说明见 `work-counts.json`，插桩时间不混正常样本。
- DR content 的一个 after 28.8s 对 before 中位 20.3s；IR full/metadata/readiness 及 DR metadata/show 也有较慢值。尚未做有限同机旧/新交错复核，不能断言噪声或稳定回退；DR selected 范围 7.3–11.5s 的波动照实保留。范围修复前停止扩测。
- 未采 after CLI、after 查询热点计数及 publish/关系替换/rename/discard/check。事务/check 后测等 4–6 最终稳定；最终真实 CLI import 闭包也待受影响代表复核。已有有效样本不因后续仅事务改动自动作废，但未经证明不得默认跨版本完全等价。

## 保证分栏

G1 按实际查询依赖门禁：无关系查询不再承诺全集关系/owner 图健康，属已批准产品边界改变；任何相关耗时变化不得称完全同保证的无损收益。metadata 仍完整计数、仅保留窗口 DTO 是机械准备改进。show 的 canonical/安全 FileHandle、同字节身份与严格 UTF-8 是 G5 安全强化，完整正文仍不套搜索预算。G3 允许未完成候选、收窄 show-candidate 选择集合；合法发布索引可提供未读正式身份/位置，不授权把正常候选动作扩大为全集当前 header 验收。G2 全量 check 首次采集、G4/严格事务与后续 G5 事务恢复不由本阶段 after 证明。
