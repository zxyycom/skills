Contract:
- 滚动发布必须先上传并回读本轮不可变恢复包，再上传独立运行时资产；中断后只能以已验证原字节恢复，同名冲突不得覆盖。
- 发布资产回读核验失败时不得退役旧资产。

Proves:
- 隔离远端替身记录恢复包首先上传并回读，在部分运行时上传后中断；恢复包声明六个运行时，冲突尝试后原远端条目保持不变，恢复一致内容后重入成功，六目标实际字节分别等于 release 输入并发布 manifest。
- 恢复包回读缺失或 digest 错误时失败且只上传恢复包；其他包回读 digest 错误时失败且两个旧名均未被删除。
- 测试不访问真实 GitHub，不证明真实发布或跨平台运行。
