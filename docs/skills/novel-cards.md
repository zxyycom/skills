# Novel Cards

用详情与递归总结组织原创或续写中的剧情、人物和设定：先确认卡片规划，从最高受影响层向下修改，再依据细纲与导演视角写作。正文发现差异时先产出证据报告，由作者决定改正文或改卡；卡片对应放在报告，小说文本无需维护性回标。

## 章节与版本变迁

章节日常按标题或编号定位，重名会列候选及所属全作/卷的计数范围。稳定身份不随改名、插章或重排变化；总结可以自由递归，章也可以是总结，写作时展开到详情。

人物与设定保存剧情位置状态。旧卡完整快照与专门变迁一次连接多个对象的前后版本，从对象或事件自动找到关联：故事演进保留真实阶段，作者修订保留被否定旧版但不把它当经历，撤回与预期另有明确效力。历史总结只负责压缩解释。

本作卡直接放 `cards/`，参考区只表达独立来源。未来预期与待展开程度写在卡内，不由目录或版本判断。

## 本地工具与正文对照

随包 CLI 提供检查、索引同步、精确/版本读取、有界展开、章节候选、自动历史查询与可恢复批量变迁。机械检查证明身份、引用、组成图与索引约束；因果、人物理解和文学质量由作者与 agent 复核。

正文检查先提取细纲、实际导演视角和模拟读者判断，再对照目标卡、回查缺漏。报告说明正文定位、实际阅读范围与上下文隔离程度；模拟读者不是实际读者测试。本 skill 使用本地流程，外部审稿需要另有接口契约及稿件传输、费用授权。
