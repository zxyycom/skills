# Novel Cards

用详情与可任意递归的总结组织小说。顶层剧情卡向下展开，卷、册、弧线、章只是标签；人物与设定保存剧情位置状态，历史总结引用实际剧情节点。

创作、原文反推和同人续写共享流程：先改卡，从最高受影响处向下复核，再按卡写作；正文不自动回写。已发生、作者预期和待展开分别表达，参考未来章节不默认进入当前规划。

随包本地 CLI 提供卡片检查、派生索引同步、精确读取与有界展开，拒绝重复身份、悬空引用、`children` 循环和陈旧索引。正文检查先提取证据，再对照目标卡，并回查缺漏；报告区分模拟读者判断、实际阅读范围与上下文隔离程度。机械正确性和文学语义分别验证。

使用前从 [行为入口](../../skills/novel-cards/SKILL.md) 开始；[卡片与工具契约](../../skills/novel-cards/references/card-contract.md) 承接精确协议，[反推与对照报告](../../skills/novel-cards/references/review-report.md) 承接正文检查。本 skill 使用本地流程，未接通独立远端审稿 API。
