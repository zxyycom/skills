# Video Understanding

围绕总结、局部问答和操作还原理解本地或网站视频：先确定交付物和范围，复用已有材料，再按缺口读取字幕、画面或调用本地工具，交付可回查的结论。

随包 TS CLI 保存带稳定身份的字幕、帧、采用与校正记录；媒体处理使用独立的 Windows 运行时，程序包、用户配置和证据数据分别维护。安装、下载、素材外发与付费操作始终按具体任务授权。

从[行为入口](../../skills/video-understanding/SKILL.md)开始；首次调用查看[本地工具入口](../../skills/video-understanding/references/local-tools.md)，安装和支持边界见[运行环境](../../skills/video-understanding/references/runtime.md)。维护源码、通用测试和 Windows 制品验收见[工具维护](../../tools/video-understanding/README.md)，两类产品门禁与聚合发布条件遵循[项目工具链](../tooling.md#ci-与发布)。客户端或宿主项目自行维护稳定包接入、本机路径、凭据引用与报告保存约定。
