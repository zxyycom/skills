# Video Understanding

围绕总结、局部问答和操作还原理解本地或网站视频：先确定交付物和范围，复用已有材料，再按缺口读取字幕、画面或调用本地工具，交付可回查的结论。

随包 TS CLI 保存带稳定身份的字幕、帧、采用与校正记录，便于继续阅读、比较来源和核实结论。媒体处理使用独立的 Windows 运行时；用户配置和证据位于程序包外，跨程序更新保留。

## 使用与维护入口

- 理解视频：从[行为入口](../../skills/video-understanding/SKILL.md)开始，按任务选择文字、画面与复核。
- 使用本地 CLI：首次调用查看[本地工具入口](../../skills/video-understanding/references/local-tools.md)，依赖安装和支持范围见[运行环境](../../skills/video-understanding/references/runtime.md)。
- 维护产品：源码、同步、测试和 Windows 制品验收见[工具维护](../../tools/video-understanding/README.md)，聚合交付见[项目工具链](../tooling.md#ci-与发布)。

客户端或宿主项目维护稳定包接入、本机路径、凭据引用与报告保存约定；安装、取材和外发按具体任务授权。
