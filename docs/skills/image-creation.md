# Image Creation

Image Creation 把生图当作交付图像的过程，而不是提示词写作比赛：先恢复用途和本次状态，核对实际参考，选择生成／编辑路线，再看图定位偏差，交付可用资产。用户只要提示词或诊断时，也能停在相应结果。

## 它解决什么

“主体出现了”不代表关系正确，“局部很好”不代表全图落实，“只改这里”也不意味着其他像素锁住。这个 skill 关注这些容易被漂亮画面掩盖的差异：

- 将情绪、材料、动作和风格展开为可见选择，不靠堆叠词汇。
- 给身份、姿态、材料和构图参考分工，并检查生成器实际收到的图。
- 区分输入错误、提示遗漏、路线限制、回填弱化和非目标区域回归。
- 保持当前基准、候选用途与用户认可范围可恢复，不让最新图自动成为定稿。

## 与图像工具怎样配合

本体位于 [`skills/image-creation/`](../../skills/image-creation/)，主要是流程与产出型指令，不包含生成 API、模型权重或专用执行脚本。它可与当前环境的 `imagegen` 等执行能力协作：本 skill 负责目标、输入和验收，执行能力负责调用协议、参数、路径和展示规则。没有执行能力时可以交付提示与输入说明，但不宣称已完成成图。

单个 skill 独立获取、版本化与更新；不要求同时安装其他仓库 skill。指令使用不需要安装 updater 依赖，也不自动启用收费服务或改变用户全局安装。

## 按缺口读取

主入口维护从意图到交图的闭环，三个按需资源分别提供视觉表达、参考／编辑诊断和特殊任务样例。简单请求直接执行，复杂参考或多轮项目才展开相应控制与恢复记录，不要求先填完整表单。

## 验证与发展边界

文档结构、链接、独立打包和 updater 检查证明可分发性；代表请求的阅读走查证明规则能否区分路径。这些不等于已经验证模型收益。后续实际评估应覆盖从零生成、身份／姿态分工、局部回填、非目标回归、系列和精确文字，并以获授权的输入—实际调用—输出对照检验，不预先承诺跨模型成功率。

当前不维护模型专属参数库、完整提示词大全或实时生成服务。需要精确数据、原生矢量、三维重建或视频连续性时，交给能兑现其验收的对应能力；静态图像不替代这些证明。
