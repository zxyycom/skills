# Subagent Orchestration

`subagent-orchestration` 用于用户明确要求委派、并行或独立审查，或者任务耗时长、影响面广、上下文负担重，并且能够拆成边界清楚的调查、实现、验证或审查子任务时。主 agent 负责目标、权限、所有权、依赖和结果审计，子代理负责有界交付。

主 agent 先判断哪项结果值得交给别人独立完成，哪项由自己直接做。派发说明按接手者实际可见的材料编写，不假设共享工作区就能看到主线程对话。例如，可以让子代理核对两份说明是否一致，自己根据返回的原文位置决定要不要改。

并行边界按写入对象划分：同一文件、配置、生成产物或外部状态同时只有一个写入方。不同代理可以读取同一材料以取得互补证据。需要独立审查时，先等实现稳定，再由另一代理检查，不修改被评估对象。

子代理自行选择范围内的执行步骤，返回结论和证据。主 agent 将其与自己负责的工作合在一起验收，对最终交付负责。

从[子代理编排入口](../../skills/subagent-orchestration/SKILL.md)开始。入口说明日常分工、派发和验收；需要拟写跨语言交接或安排独立检查时，再按正文链接读取相应资源。
