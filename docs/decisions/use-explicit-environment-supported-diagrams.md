## 目的

- 让复杂流程、依赖和层次在图示确有收益且目标环境支持时更容易被 AI 理解。
- 让关键语义在图示无法渲染、视觉布局丢失或内容被拆分读取时仍能完整恢复。

## 背景

- 不同 AI 消费链路可能获得图源、渲染结果、纯文本转写或完全不支持图示的内容。
- 方位、距离、颜色、列位置和嵌套外观可以辅助浏览，但不能稳定表达对象、方向、条件、优先级和例外。
- Mermaid 是可选的表达工具，不是所有目标文档已有契约或消费环境的共同能力。

## 决策

- 采用: 图示只在能显著改善关系理解且目标环境支持时使用；已有格式契约时遵循该契约，没有契约时按关系复杂度和实际消费方式选择文本、表格、结构化数据或图示。
- 采用: 关键对象、关系、方向、条件、范围、优先级和例外必须在文本、字段或可读取的图源中显式表达，不依赖视觉位置、颜色或空间距离。
- 采用: 图示作为已经明确语义的组织和消费视图；图示不可用时，正文或相邻权威结构仍提供完成预期任务所需的语义路径。
- 采用: 选用 Mermaid 时按目标内容选择方向、节点和分组，不把 `LR`、`TD`、`subgraph` 或固定表格列数设为 AI-Ready Docs 的通用验收条件。
- 不采用: 为统一外观强制一种图示语法或版式，或让渲染后的空间布局单独承担关键含义。
