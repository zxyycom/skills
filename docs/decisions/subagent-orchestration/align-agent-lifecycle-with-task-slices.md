## 目的
- 让子代理拥有边界清楚、可独立交付和验收的主要责任。
- 在隔离收益与交接成本之间形成稳定的代理创建和延续边界。

## 背景
- 调查、实现、验证和审查包含多个动作，但按每个动作建立代理会让交接成本超过上下文隔离价值。
- 持续让同一代理承担不同目标或从实现切换到独立审查，会混合局部上下文、责任和独立性。
- 必须共同改变同一状态或只有组合后才形成稳定中间结果的工作，不能仅为并行而拆开。

## 决策
- 采用: 任务按最小可独立交付和验收的切面拆分，每个子代理只承担一个主要切面，切面内允许包含完成该结果所需的多个动作。
- 采用: 必须共同写入同一状态或只有合并后才能形成稳定可验收结果的相邻工作保留在同一切面；交接成本高于隔离收益时不继续细拆。
- 采用: 同一切面的继续实现、自验证和定向修复优先延续原代理，保留局部上下文与写入所有权。
- 采用: 目标、主要责任或独立验证与审查角色发生变化时建立新代理；原代理不可延续时，在前序停止写入后显式交接必要上下文和所有权。
- 采用: 交付代理完成自身结果的自验证，需要独立证据或判断时由不同代理在稳定结果上执行交叉验证或审查。
