## 目的
- 让子代理运行能力与任务切面的真实能力要求和问题难度匹配。
- 防止提高思考强度被误作更换模型或补足模型能力边界。

## 背景
- 模型影响目标理解、知识与上下文利用、工具使用、跨范围综合和约束遵守等可用能力。
- 思考强度影响所选模型可用于多步推理、证据消歧、探索和自检的预算上限，但不会改变模型本身。
- 相同角色下的具体切面可能具有不同能力要求和推理难度，统一起始档位或按角色固定配置不能稳定匹配任务。

## 决策
- 采用: 先根据切面的理解、知识与上下文利用、工具使用、跨范围综合和约束遵守要求选择具备必要能力的模型。
- 采用: 再根据问题对该模型而言所需的多步推理、约束处理、证据消歧、方案探索和自检空间选择思考强度。
- 采用: 提高思考强度只提高所选模型可使用的思考预算上限，不视为更换模型，也不能补足模型能力边界。
- 采用: 不规定统一起始档位，不按调查、实现、验证或审查角色固定模型与思考强度；相同职责的不同切面可以使用不同组合。
- 采用: 工具不支持独立配置或目标组合时，把实际配置视为当前约束，通过调整切面、上下文和验证降低误判风险。
