## 目的

- 让 `lightweight-judgment` 的调用者从已留存日志比较延迟、用量与批次起始表现，并能核对样本、缺失和筛选口径。
- 将正常读写与保留旧数据的迁移分离，使日常路径只维护一个结构；不需要历史时可直接重新建库。

## 背景

- 适用 skill 为 `lightweight-judgment`，路径为 `skills/lightweight-judgment/`。可选 SQLite 日志保存调用状态、耗时和服务报告的用量；统一统计入口让分位数、缺失值与批次比较采用同一口径。
- 调用、问题与实验样本各有分母，批次首条也有独立于筛选结果的身份。保留这些差异，才能复核汇总与对照结果。
- 统计消费已有记录；主动实验、质量评测与服务端计时另需相应样本、证据和授权。旧数据保留需求不等于正常入口必须同时支持多个结构。
- 将旧版本分支放进查询、校验与 writer，会持续增加正常路径的维护面；由普通推理触发升级，还会把持久数据变更混入请求前置。缺库本就由正常写入创建，继续使用不以迁移为前提；需要旧历史时，关键是说清字段含义和回填依据，已知的简单转换可附 SQL，不引入通用迁移框架。

## 决策

- 采用: 保留 CLI 的 `stats`，以单个 SQLite 只读事务取得调用摘要的一致快照，复用日志而不新增统计库或后台服务。显式数据库路径独立于连接配置；读取无需有效服务凭据，不触发推理。缺库、错误库或不支持的结构明确失败，统计入口不创建、修复或迁移目标。
- 正常 writer 与 stats 只接受当前日志结构，新库直接创建该结构；版本或布局不符时以存储错误停止，推理不发送 HTTP。运行时不保留旧结构查询分支，也不自动升级既有库。
- 无需旧历史时，停止访问后移走旧库及遗留旁文件，或选择尚不存在的新路径；后续正常日志写入自然创建当前格式的新库，不要求迁移。新库不含旧历史，stats 本身仍不建库，文件清理由使用者决定。
- 需要保留历史时才读取该 skill 的 [migrations/](../../skills/lightweight-judgment/migrations/README.md)，按来源 → 目标版本独立说明字段含义、来源、转换、缺失和验证条件。附带脚本是可选便利，只实现数据来源已知、转换可确定且能验证的部分；缺少必需数据或依赖未知映射时保留说明与人工条件，不提供猜测性或占位脚本，也不把附带脚本接入正常读写或 updater。具体迁移在副本上验证数据保留后再切换；未知或损坏数据按其来源另行处理，不伪造历史或自动合并。
- 按调用累计状态、延迟和服务报告的 token，费用按接收方隔离。默认保留失败与重复调用的实际权重，输出筛选条件、计量方法及有效／缺失数量；缺失值保持缺失。资源预算显式且可调整，超限整体失败。
- 调用方显式提供批次 ID、批内序号和标签，作为仅本地元数据留存。序号表达指定位置，首条、后续、缺失与部分选择分别呈现；筛选保留原首条身份。该顺序不证明并发发出顺序或冷启动原因。
- 新调用的批次与字节数摘要独立于正文留存开关；显式升级保留旧字段，按逐字段来源回填可确定的数据：原始请求文本恢复 UTF-8 字节数，原始响应 BLOB 恢复响应字节数，来源缺失保持 NULL，空响应保留为 0。批次、序号和标签没有库内依据，不从正文或时间猜测；仅在存在可按调用 ID 关联的可靠外部映射时另行回填。迁移不重放请求，也不补造未确认的调用结果。
- 结果用于调用级表现比较，计时起止、分位数、分组与分桶由[统计契约](../../skills/lightweight-judgment/references/statistics.md)承接。TTFT、纯推理时间、缓存收益及依赖标准答案与语义映射的质量结论，均须取得相应证据后另行评估。
