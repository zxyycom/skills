## 目的

- 允许调查资源直接使用常见中文、英文、数字和经验证的常用符号形成可读名称。
- 保持名称边界可逐项审查，并避免从宽泛 Unicode 类别推断资源成员。

## 背景

- 路径逃逸防护主要由相对路径结构、精确链接目标、符号链接拒绝、规范根约束和普通文件身份校验承担；小写 ASCII 白名单额外排除了常见可读名称。
- 任意可打印 Unicode 或整个字符类别会纳入双向文本控制符、不可见字符、URL 与路径控制字符及未经验证的 Markdown 边界。

## 决策

- 采用: 每个资源 ID 路径段只接受常用汉字 `U+4E00..U+9FFF`、`〇`、大小写 ASCII 英文、ASCII 数字，以及固定契约逐项列出的点、连接符、括号、方括号、书名号和中英文常用标点；以后只根据现实名称与解析验证逐项扩充。
- 采用: 路径段不能以点开头或结尾，必须至少包含一个汉字、英文字母或数字，并拒绝 Windows 保留设备名及其带扩展名形式；ASCII 圆括号必须成对，允许空内容和最多 32 层嵌套。
- 采用: 绝对路径、空段、`.`、`..`、反斜杠、查询、片段、百分号编码、空白、路径或 URL 控制字符、符号链接、非普通文件和越过资源根目录继续被拒绝；扩大名称白名单不削弱文件身份与路径收口。
- 不采用: 任意可打印 Unicode、宽泛 Unicode 字符类别、静默字符归一化或百分号编码别名。
