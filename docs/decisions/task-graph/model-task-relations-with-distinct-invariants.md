## 目的

- 让任务分解、硬完成顺序和同时执行限制拥有互不替代的权威表示。
- 让多个执行者只依据已经写入并通过图校验的关系恢复调度事实。

## 背景

- 父子关系表达真实目标组成，完成依赖表达结果消费顺序，并发排斥只禁止同时运行；三者不能互相推导。
- 通用无约束 edge 无法分别保证单一父节点、有向无环和对称无自环等不变量。
- Agent 的发现和建议只有经过事实核对与工具事务写入后，才能成为共享调度依据。

## 决策

- 采用: `parentId` 维护单一父节点并形成无环森林，`dependsOn` 维护完成依赖并形成有向无环图，`excludes` 维护对称且无自环的并发排斥集合。
- 采用: 三类关系分别按真实目标组成、结果消费顺序和已确认并发安全约束建立；主题相近、方便分组或偏好顺序不构成关系事实。
- 采用: Agent 可以发现和建议关系，但只有通过 task-graph 工具写入权威索引的关系才进入调度事实。
- 采用: children、dependents 和反向排斥从完整索引确定性派生，不作为需要双向维护的第二事实源。
- 不采用: 用一个通用 edge、显示层级或临场推演代替三类关系的独立语义和机械约束。
