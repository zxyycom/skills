## 目的

- 让未参与调查的读者先理解关键认识，再按需核对现场和做法。
- 以适合阅读和 Git 维护的材料保存调查上下文，将复现与工具维护作为独立义务。

## 背景

- 本决策适用于 `investigation-report`，行为 owner 为 `skills/investigation-report/SKILL.md`。
- 关键依据、结论与条件在正文闭合，才能让读者独立理解本轮认识；明细、日志和代码则适合按需展开。
- 材料的阅读价值、结论可信度与可重跑性是不同判断。完整导出和环境重建有额外成本，而文本、节选与当时使用的代码通常已能说明关键现场和逻辑。

## 决策

- 采用: 正文独立解释本轮问题、关键认识、依据、条件、探索转折和剩余未知。写法随各领域的判断需要调整；阶段性认识与报告分篇继续服从既有独立轮次规则。
- 采用: 按阅读用途选择资源。短而关键的内容放正文，稳定来源足够时直接引用，其余仅保留有必要随报告保存的现场与做法。资源优先采用 Git 友好的等价纯文本；文本会丢失影响判断的信息时，才保存最小非文本材料并说明用途。
- 采用: 长日志和过细数据可节选、去重、汇总、脱敏与简化，保留影响判断的状态、顺序、差异及反例，说明处理方式并保持原意。
- 采用: 调查中使用的一次性分析代码、测试代码或查询可原样或节选保留，以真实语言形式解释当时动作。节选说明省略范围，纯伪代码以 `.txt` 等明确文本形式区分。
- 采用: 结论可信度由来源、方法与推理判断；资源默认供阅读，复现、重跑和工具维护仅按任务要求承担，执行继续服从授权。资源路径、关系、索引和事务保持既有固定契约。
