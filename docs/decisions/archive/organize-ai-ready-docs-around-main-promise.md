## 目的

- 让 `skills/ai-ready-docs/` 的文档优化流程通过清楚的目标方向和必要规格兑现文档主承诺。
- 保持低判断成本的默认路径，而不按表达形式或对象类别分类。

## 背景

- 明确目标通常更容易为不同能力的 agent 提供稳定方向，因而适合作为默认主线。
- 目标方向不能代替定义或检验结果所需的具体规格；规则是否必要也不由句子的正负形式决定。
- 当前 AI-ready 文档流程需要从入口信号恢复主承诺，并以正文主题、层级、篇幅、结论、验收或校验方式检查是否兑现该承诺。

## 决策

- 采用: `skills/ai-ready-docs/` 默认先用目标状态、必要约束、推荐路径和验收方式建立主线，再保留定义或检验主承诺所需的具体规格。
- 采用: 从标题、开头、适用范围、触发条件、前置条件、资源名、字段或输入输出恢复文档主承诺，并对照正文主题、层级、篇幅、结论、验收或校验方式检查是否兑现。
- 采用: 具体规则能让主承诺更清楚或可验证时保留原有表达，不为统一正负形式而改写；无法确认语义等价时保留原规则并暴露不确定性。
- 不采用: 只强化内容 owner 判断，或用表达正负、对象类别代替主承诺和正文重心判断。
