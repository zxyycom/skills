## 目的

- 让大量存量下的起草、文本发现与单对象维护只承担本次结果必需的工作。
- 让调用者准确区分发布事实、当前所读文本、局部操作成功和全集健康结论。

## 背景

- 本判断适用于本仓库的 `skills/decision-records/` 与 `skills/investigation-report/`，不改变其他 skill 的验证责任。
- Markdown 是内容事实源，持久索引保存可严格校验的发布投影。每次局部操作重新验收无关正文，会把存量成本重复附加到简单输入。
- [全操作调查](../../investigations/record-tools-all-operations-100k.md)记录了极端规模的小输入成本；这些测量不能直接推算日常收益，也不构成引入缓存体系的理由。
- 用户接受无关未同步问题在显式集合级验收时发现，要求保留最终领域约束、事务保护和高风险维护边界。
- [前序判断](investigation-local-validation-and-phase-facts.md)共同维护调查只读检查与局部暂存。本判断承接检查的首次对象语义并扩展普通维护的发布基线；暂存与阶段写入责任由[独立暂存判断](../refresh-selected-records-in-pending.md)承接，两者共同保留前序仍有效的含义。

## 决策

- 采用: 以严格合法的发布基线支持局部操作，由显式检查与同步承担当前全集验收；普通结果、只读证据与高风险事务分别按下列责任交付。

- **普通维护采用发布基线**：从严格合法的发布基线取得未读对象事实，只读取选中对象、受影响演进成员及必要资源 owner 依赖；最终图、身份、生命周期、写前漂移与恢复继续由正式事务验证。
- **候选按自身范围准备**：起草验收自身输入、可见身份冲突、安全路径和不覆盖条件，候选读取按所选对象与直接依赖报告 readiness；正式全局闭合交给发布门禁，起草成功不表示已经采用或可发布。
- **文本发现区分范围与文本**：content 搜索按发布投影选范围，再匹配同次安全读取且已核对 ID 的当前文本。来源明确表达复合范围；索引失败走显式恢复，未同步新增或筛选变化在同步后生效。
- **全集结论显式取得**：当前全集健康由显式全量 check 与 sync 承担；已知正式手改先同步。预检用于写前审阅预计影响，全集任务在批次验收取得完整结论，普通局部成功按其实际覆盖交付。
- **只读检查验证首次对象**：两域全量只读 check 使用首次取得的同一份源字节、解析、身份与资源事实验证完整集合，并比较完整发布索引投影。该证据只证明本次取得的事实，不承诺结束时来源未改变或跨文件原子快照；单阶段复用因此无需结束重读全集。
- **事务阶段独立验收**：预检零写、不持独占写锁且不保存凭据，执行在锁内重新准备并独立 fresh；unchanged 仍完成适用来源、成员与索引保护。正式事务以实际索引发布为提交点，候选使用实际动作提交点且不制造正式索引；成功还须目标 bytes/identity/mode 与相关成员写后验收。
- **结果保留真实提交事实**：提交后验收失败或未知保留已知提交事实并报告 `partial-or-unknown`，只有验收通过且仅收尾未完才是 `committed-cleanup-pending`；清理与解锁失败非零、保留真实路径，先对账而非直接重试。
- **恢复保护后来修改**：提交前只撤销仍匹配本事务 written bytes/identity/mode 的实际写集，旧路径仅缺失时独占恢复，索引同样 CAS；完整旧范围与未选保护均已证明才报告 `rolled-back`。归属不明时保留现场人工对账，不承诺非合作编辑原子隔离。
- **高风险事务保持严格**：删除、资源 owner 删除、身份更正及相应组合事务保留严格来源验收和历史确认；不以局部路径绕开授权、完整闭合或恢复义务。
- **零写与空集合各有合法结果**：同 ID、同位置 rename 在必要身份、安全与冲突确认后真零写，不规范化正文、索引或 mode，不要求变更历史确认。删除最后正式成员保留合法空索引。
- **保持交付边界**：沿用现有索引格式与调用内快照，保持其他 skill 和共享消费者的默认契约。领域规则与精确参数由两域契约承接；收益按代表存量与常数输入实测，不从局部读取量推断整体固定成本。
