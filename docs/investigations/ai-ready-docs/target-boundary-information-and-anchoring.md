## 调查报告

### 从负向描述争议恢复候选概念模型
- 形成时间: 2026-08-13T08:35:10+00:00

#### 形成时背景
本轮调查来自对 `skills/ai-ready-docs/` 中负向描述原则的连续讨论。起点是现有原则只强调“不要 X”会让模型继续围绕 X 搜索，却没有解释一个更基础的现象：负向描述通常只说明什么不是目标，没有同时确定什么是目标、怎样在剩余候选中选择以及如何验收。最初用“目标实现是低阶无穷，非目标是高阶无穷”表达这种直觉，随后发现若把它普遍化为“负向描述剪枝效率低于正向描述”，就会遇到高剪枝负向约束、闭合候选集和专门禁止契约等反例。

讨论由此引入“任务相关的信息效率”作为更上位的解释：一段描述的价值可能取决于它以多少上下文减少了多少任务相关不确定性，而不只取决于正向或负向句式。但这一方向又产生新的风险。如果 agent 被要求寻找高信息量的负向剪枝，它可能主动枚举错误道路、补造原文不存在的约束，并把更多被排除对象带入上下文。与此同时，正向目标也不自动提供无坑的实现路径；目标、路径和禁止边界可能承担不同责任，不能只按一次剪枝的规模互相替代。

当前工作区存在尚未提交的中间实现：`skills/ai-ready-docs/SKILL.md` 与 `references/principles.md` 已把“目标约束不对称”和“解空间锚定”拆成两个章节；相关决策记录也经历了先合并、再拆分的演进。这些文件反映讨论过程中的阶段性认识，不视为本轮已经确认的最终原理。

#### 调查目的
本轮准备保存讨论已经暴露的概念层次、较稳定的观察与尚未闭合的问题，为后续逐项讨论提供共同起点。具体要回答：哪些概念只是分析模型或语义角色，哪些可能成为独立原理；信息效率能否解释正向与负向描述的相对价值；负向边界在什么条件下可以独立成立；解空间锚定是否具有不能被信息效率吸收的独立机制。

本轮不决定 `ai-ready-docs` 的最终规则名称、章节数量或执行动作，不据此继续修改 skill 本体或激活新的长期方向，也不把概念分析外推为所有 prompt 或所有模型上的经验定律。

#### 调查范围与依据
调查依据是当前任务中围绕负向描述形成的完整论证链，以及 2026-08-13 读取到的当前仓库文件：`skills/ai-ready-docs/SKILL.md`、`skills/ai-ready-docs/references/principles.md` 和 `docs/decisions/ai-ready-docs/` 下直接相关的决策记录。仓库基线为 Git commit `229ff70bf7d0fd37875c939c17bc24b17590ac72`；上述 skill 文件、决策索引、旧锚定决策以及三份新增决策在工作区存在未提交变化，因此当前文件只能作为阶段性方案证据，不能代表已提交基线。

本轮采用概念分层、反例比较和语义责任分析，没有进行模型行为实验、样本计量、外部文献调查或跨模型复现。讨论中的“剪枝”“距离”“道路”和“解空间”均为帮助分析生成与选择过程的模型，不是已经建立了度量、拓扑或搜索算法的数学形式系统。“低阶无穷”和“高阶无穷”只作为原始直觉来源接受检查，未被证明为严格集合基数结论。

#### 调查结果与边界
当前较稳定的认识是，讨论中的四个词并不处于同一层次：

1. **解空间**是候选分析模型。文档中的目标、选择标准、路径和边界都会改变 AI 生成或选择候选的方式；它本身尚不是一条动作规则。
2. **正向引导与负向边界**更像两类语义责任，而不是两条并列原理。正向引导可以包含目标状态、候选排序依据、推荐路径和验收方式；负向边界用于排除不合法结果、危险状态或已知错误路径。句子表面的肯定或否定形式不必然等于它承担的语义责任，例如“只允许 A、B”虽然是肯定句，仍在定义可行边界。
3. **任务相关的信息效率**是候选上位原理。它试图解释一段内容对目标方向、候选范围、选择依据、路径和验收边界贡献了多少可用信息，以及这些贡献是否值得相应的上下文和维护成本。它比“正向天然优于负向”覆盖更多现实情况，但“任务相关信息”和“效率”尚未形成稳定、可执行的判断定义。
4. **解空间锚定**描述的是对象被点名后的方向性副作用。即使模型正确理解“不使用 X”，X 的典型做法、修正路径和反例仍可能被激活，使搜索继续围绕 X 展开。这个效应可能与内容提供了多少约束信息不同，因此目前不能直接断言它已经被信息效率完整吸收。

讨论支持一个尚待检验的组合模型：文档先用正向引导和必要边界形成任务的搜索契约，再在不改变各自语义责任的前提下选择更有效的表达，并对被点名对象额外考虑锚定成本。这个模型能够解释为什么开放任务中逐项排除通常不能替代目标与选择标准，也能容纳两类现实例外：文档自身就是禁止边界契约；候选全集闭合且稳定，负向补集比正向枚举更紧凑。后两类例外只证明负向表达可以高效承担边界责任，尚不能证明边界通常可以替代开放任务中的目标引导。

当前不能确认“负向描述通常效率更低”是一条普遍事实。高剪枝负向约束并非纯数学可能，但常见价值似乎集中在已有目标后的关键边界、专门禁止契约和闭合候选集的补集表达。相反，把信息效率直接写成 agent 动作可能诱导其主动寻找或发明错误道路；这会违反语义保真、扩大 denylist，并增加锚定对象。因此，即使信息效率最终成为原理，动作层也需要独立限制：负向边界来自已有契约、现实风险或已证实的高概率错误，而不是为了提高剪枝率被主动补造。

后续需要逐项讨论并形成反例检验：

1. “任务相关的信息”具体包含哪些维度，是否允许把目标方向、路径指导与可行边界压缩成一个可比较量。
2. 信息效率只能比较承担同一语义责任的不同表达，还是可以用于比较目标引导与边界约束的相对价值。
3. 一份文档达到什么条件时，负向边界本身已经构成完整主承诺，而不需要另造正向替代方案。
4. 解空间锚定应继续作为独立原理，还是作为信息效率中的方向偏置成本；两种组织会分别导出什么动作。
5. 正向引导是否应被进一步拆成目标状态、选择标准、推荐路径和验收方式，避免用“给出目标”假设它已经说明如何到达目标。
6. 最终动作怎样保留信息效率的解释力，同时明确禁止 agent 为了剪枝主动枚举或补造负向项。

在这些问题闭合前，本报告只保存候选模型和讨论边界，不支持将“信息效率最高”直接设为 `ai-ready-docs` 的执行规则，也不支持恢复为“正向描述无条件优于负向描述”的简单规则。

### 区分语义责任与解空间分析层
- 形成时间: 2026-08-13T08:42:11+00:00

#### 形成时背景
上一轮报告把“正向引导与负向边界是两类语义责任”与“它们是在共同解空间中提供信息的两种方式”列成了一个待选择的问题。这一问法已经隐含两条不同方向，却把它们放成互斥解释。讨论随后提出新的区分：语义责任的核心是保证 AI 恢复到的目标确实是原本想要的目标，而不是字面相近但已经被曲解的目标；解空间则是更宽泛的分析说明，用于描述一个问题可能产生或被考虑的候选结果空间。

这一区分要求重新检查上一轮的概念分层。尤其不能因为一段话在逻辑上剪掉了大量候选，就直接认为它完成了语义责任；也不能因为某项边界使用负向句式，就把它视为目标之外的次要信息。如果缺少该边界会使恢复出的目标变成另一种目标，那么边界本身就是目标语义的一部分。

#### 调查目的
本轮要厘清语义责任与解空间之间是替代、并列还是上下游关系，并判断正向引导、负向边界、信息效率和解空间锚定分别处在哪一层。重点是形成一个不会把“确保含义正确”降格为“高效裁剪候选”的概念顺序。

本轮继续只形成候选解释，不确定最终术语、原则数量和动作结构，不修改 `skills/ai-ready-docs/` 当前阶段性实现或相关决策记录。

#### 调查范围与依据
本轮依据是用户对上一轮核心问题的直接修正、上一份报告保存的讨论链，以及当前 `ai-ready-docs` 对语义保真、目标描述和解空间锚定的阶段性文本。分析方法是区分规范性问题与描述性问题，并用“相同候选裁剪是否必然得到正确目标”检查两者能否互相替代。

本轮没有通过模型实验验证“目标被曲解”或“锚定”的发生频率，也没有建立解空间的数学结构。这里的解空间暂指一项任务中可能被解释、生成、选择或接受的候选结果集合及其关系；模型怎样在其中移动、对候选赋予多大概率，暂称搜索过程或搜索偏置，不假定能够直接观察模型内部路径。

#### 调查结果与边界
当前形成的主要修正是：**语义责任与解空间不是两个竞争解释，而是规范层与分析层。**

1. **语义责任回答“什么含义必须被正确恢复”。** 对 `ai-ready-docs` 而言，它首先要求文档让 AI 恢复到使用者真实想要的目标、条件和判断，而不是一个仅在表面上相似的替代目标。这是评价文档正确性的规范标准。
2. **解空间回答“现有文本留下了哪些候选结果，以及它们怎样被区分”。** 它可以帮助分析某条目标描述、约束或边界如何扩大、缩小、分区或排序候选结果，但它本身不决定哪一个空间才符合原始意图。
3. **语义责任先于解空间优化。** 一段高剪枝描述若删除了使用者真正需要的目标，或者没有表达决定目标身份的条件，即使留下的空间很小也不正确。反过来，一项负向边界若是区分“想要的目标”和“被曲解目标”的必要条件，它就在履行语义责任，不只是附加剪枝。
4. **正向与负向是表达方式，不直接等于语义责任类型。** 同一项目标条件可以写成“只允许 A”或“不允许非 A”；一条正向句也可能只给出宽泛方向，一条负向句也可能精确表达目标不可缺少的性质。需要先判断它承载了什么意图，再分析它怎样塑造解空间。
5. **信息效率只能在语义正确的前提下评价表达。** 它可以比较不同写法以多少上下文传递了目标身份、选择依据或必要边界，却不能用“剪枝更多”证明一段话更忠实，也不能授权 agent 发明新的负向约束。
6. **解空间锚定更接近搜索过程的偏置。** 两种写法可能在逻辑上表达相同的允许结果集合，但点名某个被排除对象会改变模型优先联想到或生成什么。锚定因此不必改变逻辑解空间，也可能改变候选在实际生成中的可达性或概率分布。

这使当前候选结构变为：使用者意图提供需要忠实恢复的来源；语义责任规定文档必须保真的内容；正向或负向表达承载这些内容；解空间模型用于观察表达留下和组织了哪些候选结果；信息效率与锚定分别评价表达成本和搜索偏置。它们可以组合成一条因果链，而不需要在“语义责任”与“解空间方式”之间二选一。

仍需继续讨论的关键问题是：语义责任应保持为“避免目标被曲解”的单一上位责任，还是需要拆成目标身份、选择标准、必要条件和验收方式等可独立检查的子责任；同时要明确“目标”是否天然包含所有决定其身份的边界，避免再次把目标与边界机械地分成两类。只有这一步稳定后，才能判断信息效率和锚定在原理层应怎样依附于语义保真。

### 目标在抽象层完整而在实践层逐步收敛
- 形成时间: 2026-08-13T08:48:36+00:00

#### 形成时背景
上一轮把后续问题落在“目标是否天然包含所有决定其身份的边界”。讨论指出，这个问题在高层抽象与底层实践中可能得到完全不同的答案。从理想数学对象看，解就是满足问题定义的解；如果完整成员条件已经给定，目标解可以视为一个独立集合，边界已经隐含在“属于或不属于该集合”之中。但现实中的目标说明很少能事先穷尽全部细节。人通常只知道大致想要哪一类结果，尚未形成一个可直接枚举或精确判定的目标解集合。

因此，实际文档并非总是在转录一个已经完整存在且已知的目标集合。它经常先提供一个大致方向，使 AI 形成较宽的候选结果空间，再通过补充条件、对照和排除常见的不希望结果逐步收敛。负向描述在这里不只是对完整目标的重复说明，也可能是发现和表达隐含偏好的现实手段。

#### 调查目的
本轮要定义讨论中“目标”的不同含义，解释为什么高层上边界可以被视为目标的一部分，而在文档编写和 AI 使用层又需要把目标描述与边界收敛分开处理；同时判断“先形成大致解空间，再剪枝”能解释什么，不能据此推出什么。

本轮不确定具体剪枝规则，不判断所有现实目标都没有客观解集合，也不把逐步收敛简化为只能增加负向描述的单向过程。

#### 调查范围与依据
本轮依据是用户提出的数学理想与现实目标形成之间的差异，以及前两轮对语义责任、解空间和表达方式的分层。分析采用集合近似与目标形成两种视角：一方面假设存在理想目标集合但当前描述只恢复了它的近似；另一方面考虑开放设计任务中，使用者的偏好会在看到候选与反例后继续形成，目标集合本身尚未闭合。

没有检查认知科学、需求工程或形式化规格文献，也没有用实际模型样本验证不同收敛步骤的效果。以下集合表示只用于区分概念，不表示已经定义了距离、概率或可计算的成员判定。

#### 调查结果与边界
当前需要把“目标”至少区分为三个对象：

1. **意向目标**：使用者真正希望得到的结果类型及其价值取向。它可能含有尚未说出的偏好，也可能在比较候选后继续演化。
2. **当前目标规格**：文档在某一时点已经显式表达的目标状态、条件、优先级、边界和验收依据。它是 AI 实际能够恢复的语义来源，但通常只是对意向目标的有限表达。
3. **当前候选解空间**：AI 根据当前规格仍可能解释、生成或接受的结果集合。它由文本与模型既有先验共同影响，不等同于使用者心中完整的意向目标。

这一分层使高层与底层答案可以同时成立：

- **高层抽象上**，若存在一个完整、确定且可判定的目标集合，那么所有决定成员资格的边界都已经属于目标定义；“目标”和“边界”只是同一集合从内部与外部观察的两面。
- **实践操作上**，当前目标规格通常不完整，文档只能先建立一个覆盖意向方向的较宽候选空间，再逐步加入能够区分想要与不想要结果的信息。此时把目标主线与边界修正分开表达，有助于维护目标的大致方向，并针对高概率误解继续收敛。

现实中的不确定还需要分成两类。第一类是**认识不完整**：理想答案或约束客观存在，但编写者尚未完全知道或表达，例如尚未恢复全部接口契约。第二类是**目标尚在形成**：开放设计任务没有预先闭合的唯一目标集合，使用者会通过候选、反例和取舍逐步形成偏好。前者要求继续发现事实，不能由 agent 补造；后者要求保留选择空间并显式呈现会改变方向的取舍，不能假装目标早已精确存在。

“先定义大致解空间，再剪枝”因此是一个有解释力的实践模型。可以把初始规格形成的候选空间记为 `C₀`，后续用正向条件进一步限定或排序候选，用负向边界排除已知的不希望区域，逐步得到更接近意向目标的 `C₁`、`C₂`。这里的收敛不只依赖负向剪枝：新的正向标准、优先级、代表性示例和验收反馈也会重新组织候选，而不只是从集合中删除成员。

边界之所以在实践中必要，至少有四种原因：自然语言目标存在欠指定；模型或领域存在高概率默认解；安全、权限、兼容性等不变量不能从宽泛目标自动恢复；人有时只有在看到反例后才能意识到某项隐含偏好。负向边界可以有效排除这些已知错误区域，并通过对比帮助意向目标变得清楚。

但该模型不支持主动穷举所有非目标。非目标空间仍可能巨大，持续增加孤立排除项会形成脆弱 denylist 并引入更多锚点。较稳的候选动作是只记录已有契约、现实反例、高概率默认错误或高后果风险所证明的边界；多个负向项若反复体现同一选择理由，应尝试恢复它们共同暴露的正向标准或命名不变量，而不是无限追加剪枝项。这个动作仍需后续讨论，尚未成为已采用规则。

本轮把下一问题收窄为：目标规格究竟只需要定义“哪些解可接受”，还是还必须表达可接受解之间的偏好与排序；以及在一次反例暴露隐含边界后，何时应保留负向表达，何时应将它提炼成目标的正向性质。前一个问题决定目标是集合还是带有评价结构的空间，后一个问题直接连接信息效率与解空间锚定。

### 目标是层级化且部分可表达的动态意向
- 形成时间: 2026-08-13T09:01:17+00:00

#### 形成时背景
上一轮仍把问题问成“目标是可接受解集合，还是还包含解之间的偏好、距离和排序”。讨论指出，这种问法依然把偏好放在目标之外。偏好本身就是目标的一部分；只是人的偏好并非一成不变，也未必能被本人清楚观察和表达。当前明确说出的目标还可能只是更深层目的在当前情境下形成的手段或代理。出现更能满足深层目的的结果时，人可能合理接受一个不满足当前表述目标的方案。

现实接受结果还受到多种因素共同作用：使用者可能尚未识别自己的偏好，偏好可能在看到候选后改变，期限和重做成本可能使更偏好的方案不再可行，已经投入的成本也可能通过心理上的沉没成本偏差影响选择。这些因素可以同时存在，因此不能把“被接受的结果”直接等同于预先稳定且完整表达的理想目标。

讨论进一步提出，目标之所以经常没有被写清，可能不是单纯的文档质量问题。若要求事先写清所有目标细节，似乎等同于要求预见事务发展的全部问题；当问题真正被描述到可以机械判定时，描述也可能已经从自然语言转化为代码、数学或领域专用语言。自然语言具有歧义、语境依赖和未闭合之处，而形式语言可以在受控语义内提供更精确的表达。

#### 调查目的
本轮要修正目标模型：把偏好、深层目的、当前代理目标、现实约束和允许偏离的理由放回同一个层级化目标结构；同时判断“不写清目标是因为无法预知一切”与“只有形式语言才能准确描述目标”分别成立到什么程度。

本轮不要求把人的全部价值形式化，不判断任何偏离当前目标的结果都更符合深层目标，也不把自然语言与形式语言划成准确和错误的简单二分。

#### 调查范围与依据
本轮依据是用户对“集合与偏好”二分的修正、关于深层目标与当前目标关系的实例分析，以及对自然语言和形式化规格能力边界的概念讨论。分析分别检查目标层级、时间变化、可观察性、资源约束和表达媒介，没有使用行为实验或外部文献。

“沉没成本”在本轮按两类影响区分：已经不可追回的过去投入本身，与当前制品状态产生的剩余切换或重做成本不同；前者可能通过认知偏差改变人的实际选择，后者会直接改变当前可行方案。两者都可能影响被接受结果，但不应在目标文档中被混写成同一项客观约束。

“完备性”也只作一般表达使用，不采用形式逻辑中的特定完备性定理含义。代码、数学和 DSL 是否能表达领域全部相关价值，以及表达能否正确对应人的真实意图，本轮没有得到形式证明。

#### 调查结果与边界
当前形成的主要修正是：**目标不是先有一个可接受集合、再额外附加偏好；目标本身就是随时间和情境变化、部分可见并具有层级的意向与取舍结构。** 可接受集合只是这个结构在某一时点、某组约束和某种表达下的投影。

至少需要区分以下层次：

1. **深层目标**说明为什么要做这件事以及最终希望保护什么价值，例如降低维护负担、获得信任或减少现实损失。
2. **当前目标**是深层目标在当前认知和情境下形成的可操作代理，例如采用某种架构、完成某项功能或取得某个指标。
3. **显式目标规格**是当前目标中已经进入文档、能够被 AI 取得的部分；未表达不等于不存在，表达出来也不保证仍然完整或最新。
4. **现实约束与承诺**决定哪些目标仍可执行，包括剩余时间、预算、兼容义务和重做成本。它们会改变当前最优选择，但不必等同于使用者的内在偏好。
5. **实际接受结果**是上述层次在当时认知、资源和心理状态下共同作用的结果，可能不满足某项当前目标，也可能并非事后看来最符合深层目标的结果。

因此，“更好的结果不满足当前目标”不一定是目标违约。当前目标若只是代理，而新方案更直接地满足深层目标，偏离可能是合理的目标修正。相反，agent 不能仅凭自己推测存在更深层目标就擅自推翻明确要求；文档需要尽可能表达当前目标与上层目的的关系、允许重新判断的条件和做决定的 owner，缺失且会改变结果时再请求确认。

精确描述目标也不等于完整预言未来。文档可以在不知道全部未来事件时精确声明当前不变量、优先级、可接受风险、适应规则、复核触发条件和决策权限。它无法穷尽的是未来情境及尚未形成的偏好，而不是所有精确性本身。把“未确定”明确写成未确定，也是一种语义准确。

自然语言确实容易依赖语境、保留歧义并省略成员判定，因此不适合独自承担所有需要机械验证的契约；但这些特性也允许人们在目标尚未闭合时表达方向、理由、类比和可协商取舍。它不应被简单认定为天然存在逻辑错误，而更适合被理解为默认不提供形式系统那种封闭、可判定的语义。

代码、数学和 DSL 可以在已经选定的语法、语义和领域边界内更精确地描述行为或性质，却不自动完整表达人的目标。代码可以精确执行错误意图，数学模型可以遗漏未被建模的价值，DSL 通常只覆盖它被设计承接的领域。形式化过程仍需要一个从人的深层目标与自然语言判断映射到形式符号的语义桥梁；桥梁错误时，形式规格只会更稳定地执行被曲解的目标。

这对 `ai-ready-docs` 暴露出一个候选方向：AI-ready 不应承诺把所有目标都改写成完全闭合的规格，而应让 AI 能区分哪些内容已经确定、哪些只是当前代理或偏好、哪些仍未知或可协商、哪些边界不可违反、什么条件允许重新打开当前目标。形式化适合承接已经稳定且需要机械判断的局部契约，自然语言继续承接目的、理由、未知和演进关系。这个方向尚未转化为最终原则或动作。

该模型也限制负向剪枝。若当前目标只是深层目标的代理，围绕它建立过密的禁止边界可能把更符合深层目标的新方案排除出去；但完全不写边界又会让 AI 沿高概率默认解曲解当前意向。下一步需要讨论的不是目标是否包含偏好，而是：文档怎样表达目标层级与重新解释权限，使边界既能保护当前意向，又不会把代理目标永久固化成最终目的。

### 文档投影会反过来参与目标形成
- 形成时间: 2026-08-13T09:07:50+00:00

#### 形成时背景
上一轮把后续问题落在“文档怎样表达当前目标只是代理，以及谁有权基于深层目标重新打开它”。讨论指出，这个问题把简单事项复杂化了：深层目标归谁所有，修改权就自然归谁；多人共同拥有时才需要由具体项目治理解决。更根本的问题是，文档不可能完整表达一个持续变化、连拥有者本人也无法精确观察和描述的真实目标。文档只是目标在形成当时、特定语境和表达能力下的一次投影。

投影并非被动快照。目标一旦被写成较精确的表述，就会成为新的认知锚点。拥有者可以围绕这个具体参照判断哪些部分可接受、哪些理解令人反感、哪些遗漏此前没有意识到；这些反应又会改变偏好和目标本身。因此，文档既描述目标，也介入目标形成。

#### 调查目的
本轮要判断目标投影的反身性怎样修正此前的语义保真、目标规格和解空间锚定模型，尤其是：文档是否应被默认理解为暂时投影；精确表达为何既可能固化目标，也可能帮助目标变清楚；负向锚定是否只是更一般的“表述产生锚点”的特殊情况。

本轮不设计项目级修改权限协议，不要求每份文档都增加“这是代理目标”的声明，也不把所有目标变化归因于文档锚定。

#### 调查范围与依据
本轮依据是用户对修改权限问题的修正，以及关于“目标投影成为新锚点并改变后续理解”的机制分析。它与前四轮形成的目标动态性、自然语言局限和解空间锚定候选模型进行比较，没有使用模型实验、用户研究或外部文献。

这里的“真实目标”仅指拥有者在某一时点实际具有但未必能够完整自省和表达的意向结构，不假设它是跨时间不变或客观可读取的实体。“投影”表示文档只能保存其中在当时被选择、被意识到并可表达的部分；不表示文档内容没有当前约束力。

#### 调查结果与边界
当前形成的主要认识是：**文档与目标之间不是静态的复制关系，而是一个反身反馈循环。** 可以暂时表示为：

`当时意向 → 文档投影 → 候选理解或结果 → 拥有者反应 → 更新后的意向`

这个循环包含以下含义：

1. **文档不能完整等同于真实目标。** 对持续变化且部分隐含的人类目标而言，文档至多忠实保存形成时能够表达的投影。所谓语义保真不能再解释成复制一个完整、稳定且可直接取得的目标对象。
2. **精确表达本身会改变认知条件。** 一个具体目标、示例或边界成为参照后，拥有者不再从完全开放的状态判断，而是在接受、拒绝、比较和修正这个锚点的过程中发现偏好。目标因此可能在被描述后发生变化。
3. **锚定不只有负面作用。** 锚点会压缩后续思考范围，但也使模糊偏好变得可观察、可对照和可讨论。正向目标可以形成参照锚点，负向方案可以形成对比锚点；两者都可能帮助澄清，也都可能过早固化局部理解。
4. **负向解空间锚定可能是一般表述锚定的特殊形式。** 此前关注“不使用 X”会继续激活 X；本轮表明任何被明确写出的目标或候选都可能改变后续搜索和偏好形成。负向锚定是否仍需单独成原理，要看它是否具有稳定而不同的方向性后果，而不能只因它是锚点就独立。
5. **当前权威不等于终极真实。** 文档可以作为 AI 当前行动的权威投影，直到目标拥有者修改它；“只是投影”不授权 agent 猜测隐藏目标并偏离明确要求。拥有者自然拥有目标修改权，协作环境中的代理、审批和冲突处理属于具体治理契约，不是这一原理本身。
6. **无需要求每份文档自称代理。** 对开放的人类目标，投影性可以作为分析文档时的默认认识。只有版本、有效期、假设、授权或复核条件会实际改变使用行为时，才需要在正文显式表达；否则增加元说明只会扩大维护面。

这要求再次修正语义责任：它不是保证文档永久对应一个不可变真实目标，而是准确保留当前投影中已经明确的含义、关系和边界，不把未知或推断伪装成深层目标，并让拥有者能够根据具体结果继续识别和修订目标。目标后来变化不证明原文在形成时错误；但文档若把阶段性投影伪装成永恒目的，就会妨碍正常演进。

信息效率也可能因此出现第二种价值。除了让 AI 更快收敛到当前可接受结果，一段表达还可能因为提供了高质量参照而更有效地帮助拥有者发现自己的偏好。这个“反馈效率”是否属于 `ai-ready-docs`，还是属于产品探索、需求发现或协作设计，目前没有闭合；不能因为它有启发性就直接扩大本 skill 的承诺。

下一步需要讨论的核心已经不再是修改权，而是：**当所有显式目标都会形成锚点时，什么样的锚定是在提供必要参照，什么样的锚定是在过早固化解空间？** 这个区别将同时决定正向描述、负向边界、信息效率和解空间锚定怎样重新组合。

### 区分逻辑剪枝、搜索偏置与路径依赖
- 形成时间: 2026-08-13T09:12:51+00:00

#### 形成时背景
上一轮又把后续问题写成“什么样的锚点提供必要参照，什么样的锚点过早固化目标”。讨论指出，这个问法仍然过宽，并预设需要先把锚点二分或贴标签，再为不同类别配置动作。“固化”本身也没有被定义：从数学集合角度看，正确排除一个错误选项只是缩小可行解集合，不等于目标被不当固化。

讨论同时提出，所谓解空间锚定并非 LLM 独有。人也可能因既有解释、示例和处理路径形成惯性思维，只是这种现象通常只能作为群体层面的概率倾向理解，不能作为对每个人必然生效的确定性原理。这也反过来要求检查：此前对 LLM 锚定的描述是否同样过于确定。

#### 调查目的
本轮要撤回“必要锚点 / 过早固化”的简单二分，区分正确约束带来的逻辑剪枝、对象被点名后产生的搜索或注意偏置，以及结论跨时间难以修订的路径依赖；并判断“锚定”应该严格指向哪一种机制。

本轮不为文档内容建立锚点标签体系，不判断人类与 LLM 的锚定机制相同，也不把任何候选被排除都视为认知偏差。

#### 调查范围与依据
本轮依据是用户对“固化”概念和二分问题的反例检查，以及关于人类惯性思维与 LLM 上下文影响的类比。分析只做概念分离，没有检索认知心理学研究、运行 LLM 对照实验或测量效应大小。

因此，关于人类存在类似偏置只能作为待验证的群体概率假设；关于 LLM 的表述也只确认被写入上下文的内容成为条件输入，不能由此直接证明某个被点名对象必然获得特定方向或大小的生成偏置。模型、提示结构、任务和采样过程都可能改变实际结果。

#### 调查结果与边界
当前至少混合了三种不同效应：

1. **逻辑剪枝**：目标、契约或事实排除某些候选，使可接受解集合缩小。只要排除依据正确且仍然适用，这就是目标规格的一部分，不是固化，也不因使用负向表达而可疑。
2. **搜索或注意偏置**：在逻辑允许集合相同的情况下，点名某个对象改变了系统优先考虑、联想或生成哪些候选。若保留合法值集合已经排除 X，而额外写“不使用 X”又让思考持续围绕 X 展开，这才接近此前所说的解空间锚定。
3. **路径依赖或修订阻力**：某个阶段性目标、假设或边界进入文档和后续工作后，即使原依据变化，维护者仍沿用它，或修改需要承担额外协调成本。只有这种不再由当前目标和证据支持、却持续阻碍重估的情况，才适合称为不当固化；稳定保存仍然有效的不变量不是固化。

三种效应可以同时存在，但不能相互替代。一条负向规则可以正确剪掉危险结果，同时提高该危险方案的显著性，还可能在多年后变成失去依据的历史惯例。也可能只有第一种效应而完全没有可观察的锚定问题。因此，不能从“文本排除了 X”直接推导“文本固化了解空间”。

这也修正了锚定的候选定义：**锚定不是约束本身，而是表述在其逻辑语义之外，对候选显著性、搜索顺序或后续修订产生的附加影响。** 若同一边界改用不点名 X 的合法值集合表达后，逻辑允许结果相同，但候选生成和注意分配发生变化，这种差异才是锚定假说要解释的对象。该反事实目前只是可检验思路，不是已完成实验。

人类与 LLM 都可能出现这种附加影响，但当前只能安全得出概率性陈述。人类会受到记忆、经验、社会惯例和既有问题框架影响；LLM 的输出以当前上下文为条件，被点名对象可能改变后续 token 分布和方案联想。两者的内部机制、可持续时间和可修正方式不同，不能用“人也会惯性思考”证明 LLM 的具体效应，也不能把 LLM 的条件生成机制外推为人的确定规律。

上一轮的二分问题因此应当撤回。当前不需要给每个锚点贴“必要”或“过早”标签，而应在概念上分别问：排除是否由当前目标或契约支持；点名对象是否带来超出逻辑约束的搜索偏置；原依据变化后是否仍能重新评估。这三个问题分别检查语义正确性、概率性行为影响和时间上的可修订性。

这一修正对 `ai-ready-docs` 的直接边界是：在缺少行为证据时，不能把“提到负向方案必然限制 LLM 解空间”写成确定规律；最多可以作为需要减少无信息量重复点名的风险解释。是否应保留独立的解空间锚定原理，需要后续结合模型样本或更谨慎的机制表述再判断。
