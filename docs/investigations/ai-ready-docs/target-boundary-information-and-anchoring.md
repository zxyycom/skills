## 调查报告

### 从负向描述争议恢复候选概念模型
- 形成时间: 2026-08-13T08:35:10+00:00

#### 形成时背景
本轮调查来自对 `skills/ai-ready-docs/` 中负向描述原则的连续讨论。起点是现有原则只强调“不要 X”会让模型继续围绕 X 搜索，却没有解释一个更基础的现象：负向描述通常只说明什么不是目标，没有同时确定什么是目标、怎样在剩余候选中选择以及如何验收。最初用“目标实现是低阶无穷，非目标是高阶无穷”表达这种直觉，随后发现若把它普遍化为“负向描述剪枝效率低于正向描述”，就会遇到高剪枝负向约束、闭合候选集和专门禁止契约等反例。

讨论由此引入“任务相关的信息效率”作为更上位的解释：一段描述的价值可能取决于它以多少上下文减少了多少任务相关不确定性，而不只取决于正向或负向句式。但这一方向又产生新的风险。如果 agent 被要求寻找高信息量的负向剪枝，它可能主动枚举错误道路、补造原文不存在的约束，并把更多被排除对象带入上下文。与此同时，正向目标也不自动提供无坑的实现路径；目标、路径和禁止边界可能承担不同责任，不能只按一次剪枝的规模互相替代。

当前工作区存在尚未提交的中间实现：`skills/ai-ready-docs/SKILL.md` 与 `references/principles.md` 已把“目标约束不对称”和“解空间锚定”拆成两个章节；相关决策记录也经历了先合并、再拆分的演进。这些文件反映讨论过程中的阶段性认识，不视为本轮已经确认的最终原理。

#### 调查目的
本轮准备保存讨论已经暴露的概念层次、较稳定的观察与尚未闭合的问题，为后续逐项讨论提供共同起点。具体要回答：哪些概念只是分析模型或语义角色，哪些可能成为独立原理；信息效率能否解释正向与负向描述的相对价值；负向边界在什么条件下可以独立成立；解空间锚定是否具有不能被信息效率吸收的独立机制。

本轮不决定 `ai-ready-docs` 的最终规则名称、章节数量或执行动作，不据此继续修改 skill 本体或激活新的长期方向，也不把概念分析外推为所有 prompt 或所有模型上的经验定律。

#### 调查范围与依据
调查依据是当前任务中围绕负向描述形成的完整论证链，以及 2026-08-13 读取到的当前仓库文件：`skills/ai-ready-docs/SKILL.md`、`skills/ai-ready-docs/references/principles.md` 和 `docs/decisions/ai-ready-docs/` 下直接相关的决策记录。仓库基线为 Git commit `229ff70bf7d0fd37875c939c17bc24b17590ac72`；上述 skill 文件、决策索引、旧锚定决策以及三份新增决策在工作区存在未提交变化，因此当前文件只能作为阶段性方案证据，不能代表已提交基线。

本轮采用概念分层、反例比较和语义责任分析，没有进行模型行为实验、样本计量、外部文献调查或跨模型复现。讨论中的“剪枝”“距离”“道路”和“解空间”均为帮助分析生成与选择过程的模型，不是已经建立了度量、拓扑或搜索算法的数学形式系统。“低阶无穷”和“高阶无穷”只作为原始直觉来源接受检查，未被证明为严格集合基数结论。

#### 调查结果与边界
当前较稳定的认识是，讨论中的四个词并不处于同一层次：

1. **解空间**是候选分析模型。文档中的目标、选择标准、路径和边界都会改变 AI 生成或选择候选的方式；它本身尚不是一条动作规则。
2. **正向引导与负向边界**更像两类语义责任，而不是两条并列原理。正向引导可以包含目标状态、候选排序依据、推荐路径和验收方式；负向边界用于排除不合法结果、危险状态或已知错误路径。句子表面的肯定或否定形式不必然等于它承担的语义责任，例如“只允许 A、B”虽然是肯定句，仍在定义可行边界。
3. **任务相关的信息效率**是候选上位原理。它试图解释一段内容对目标方向、候选范围、选择依据、路径和验收边界贡献了多少可用信息，以及这些贡献是否值得相应的上下文和维护成本。它比“正向天然优于负向”覆盖更多现实情况，但“任务相关信息”和“效率”尚未形成稳定、可执行的判断定义。
4. **解空间锚定**描述的是对象被点名后的方向性副作用。即使模型正确理解“不使用 X”，X 的典型做法、修正路径和反例仍可能被激活，使搜索继续围绕 X 展开。这个效应可能与内容提供了多少约束信息不同，因此目前不能直接断言它已经被信息效率完整吸收。

讨论支持一个尚待检验的组合模型：文档先用正向引导和必要边界形成任务的搜索契约，再在不改变各自语义责任的前提下选择更有效的表达，并对被点名对象额外考虑锚定成本。这个模型能够解释为什么开放任务中逐项排除通常不能替代目标与选择标准，也能容纳两类现实例外：文档自身就是禁止边界契约；候选全集闭合且稳定，负向补集比正向枚举更紧凑。后两类例外只证明负向表达可以高效承担边界责任，尚不能证明边界通常可以替代开放任务中的目标引导。

当前不能确认“负向描述通常效率更低”是一条普遍事实。高剪枝负向约束并非纯数学可能，但常见价值似乎集中在已有目标后的关键边界、专门禁止契约和闭合候选集的补集表达。相反，把信息效率直接写成 agent 动作可能诱导其主动寻找或发明错误道路；这会违反语义保真、扩大 denylist，并增加锚定对象。因此，即使信息效率最终成为原理，动作层也需要独立限制：负向边界来自已有契约、现实风险或已证实的高概率错误，而不是为了提高剪枝率被主动补造。

后续需要逐项讨论并形成反例检验：

1. “任务相关的信息”具体包含哪些维度，是否允许把目标方向、路径指导与可行边界压缩成一个可比较量。
2. 信息效率只能比较承担同一语义责任的不同表达，还是可以用于比较目标引导与边界约束的相对价值。
3. 一份文档达到什么条件时，负向边界本身已经构成完整主承诺，而不需要另造正向替代方案。
4. 解空间锚定应继续作为独立原理，还是作为信息效率中的方向偏置成本；两种组织会分别导出什么动作。
5. 正向引导是否应被进一步拆成目标状态、选择标准、推荐路径和验收方式，避免用“给出目标”假设它已经说明如何到达目标。
6. 最终动作怎样保留信息效率的解释力，同时明确禁止 agent 为了剪枝主动枚举或补造负向项。

在这些问题闭合前，本报告只保存候选模型和讨论边界，不支持将“信息效率最高”直接设为 `ai-ready-docs` 的执行规则，也不支持恢复为“正向描述无条件优于负向描述”的简单规则。

### 区分语义责任与解空间分析层
- 形成时间: 2026-08-13T08:42:11+00:00

#### 形成时背景
上一轮报告把“正向引导与负向边界是两类语义责任”与“它们是在共同解空间中提供信息的两种方式”列成了一个待选择的问题。这一问法已经隐含两条不同方向，却把它们放成互斥解释。讨论随后提出新的区分：语义责任的核心是保证 AI 恢复到的目标确实是原本想要的目标，而不是字面相近但已经被曲解的目标；解空间则是更宽泛的分析说明，用于描述一个问题可能产生或被考虑的候选结果空间。

这一区分要求重新检查上一轮的概念分层。尤其不能因为一段话在逻辑上剪掉了大量候选，就直接认为它完成了语义责任；也不能因为某项边界使用负向句式，就把它视为目标之外的次要信息。如果缺少该边界会使恢复出的目标变成另一种目标，那么边界本身就是目标语义的一部分。

#### 调查目的
本轮要厘清语义责任与解空间之间是替代、并列还是上下游关系，并判断正向引导、负向边界、信息效率和解空间锚定分别处在哪一层。重点是形成一个不会把“确保含义正确”降格为“高效裁剪候选”的概念顺序。

本轮继续只形成候选解释，不确定最终术语、原则数量和动作结构，不修改 `skills/ai-ready-docs/` 当前阶段性实现或相关决策记录。

#### 调查范围与依据
本轮依据是用户对上一轮核心问题的直接修正、上一份报告保存的讨论链，以及当前 `ai-ready-docs` 对语义保真、目标描述和解空间锚定的阶段性文本。分析方法是区分规范性问题与描述性问题，并用“相同候选裁剪是否必然得到正确目标”检查两者能否互相替代。

本轮没有通过模型实验验证“目标被曲解”或“锚定”的发生频率，也没有建立解空间的数学结构。这里的解空间暂指一项任务中可能被解释、生成、选择或接受的候选结果集合及其关系；模型怎样在其中移动、对候选赋予多大概率，暂称搜索过程或搜索偏置，不假定能够直接观察模型内部路径。

#### 调查结果与边界
当前形成的主要修正是：**语义责任与解空间不是两个竞争解释，而是规范层与分析层。**

1. **语义责任回答“什么含义必须被正确恢复”。** 对 `ai-ready-docs` 而言，它首先要求文档让 AI 恢复到使用者真实想要的目标、条件和判断，而不是一个仅在表面上相似的替代目标。这是评价文档正确性的规范标准。
2. **解空间回答“现有文本留下了哪些候选结果，以及它们怎样被区分”。** 它可以帮助分析某条目标描述、约束或边界如何扩大、缩小、分区或排序候选结果，但它本身不决定哪一个空间才符合原始意图。
3. **语义责任先于解空间优化。** 一段高剪枝描述若删除了使用者真正需要的目标，或者没有表达决定目标身份的条件，即使留下的空间很小也不正确。反过来，一项负向边界若是区分“想要的目标”和“被曲解目标”的必要条件，它就在履行语义责任，不只是附加剪枝。
4. **正向与负向是表达方式，不直接等于语义责任类型。** 同一项目标条件可以写成“只允许 A”或“不允许非 A”；一条正向句也可能只给出宽泛方向，一条负向句也可能精确表达目标不可缺少的性质。需要先判断它承载了什么意图，再分析它怎样塑造解空间。
5. **信息效率只能在语义正确的前提下评价表达。** 它可以比较不同写法以多少上下文传递了目标身份、选择依据或必要边界，却不能用“剪枝更多”证明一段话更忠实，也不能授权 agent 发明新的负向约束。
6. **解空间锚定更接近搜索过程的偏置。** 两种写法可能在逻辑上表达相同的允许结果集合，但点名某个被排除对象会改变模型优先联想到或生成什么。锚定因此不必改变逻辑解空间，也可能改变候选在实际生成中的可达性或概率分布。

这使当前候选结构变为：使用者意图提供需要忠实恢复的来源；语义责任规定文档必须保真的内容；正向或负向表达承载这些内容；解空间模型用于观察表达留下和组织了哪些候选结果；信息效率与锚定分别评价表达成本和搜索偏置。它们可以组合成一条因果链，而不需要在“语义责任”与“解空间方式”之间二选一。

仍需继续讨论的关键问题是：语义责任应保持为“避免目标被曲解”的单一上位责任，还是需要拆成目标身份、选择标准、必要条件和验收方式等可独立检查的子责任；同时要明确“目标”是否天然包含所有决定其身份的边界，避免再次把目标与边界机械地分成两类。只有这一步稳定后，才能判断信息效率和锚定在原理层应怎样依附于语义保真。

### 目标在抽象层完整而在实践层逐步收敛
- 形成时间: 2026-08-13T08:48:36+00:00

#### 形成时背景
上一轮把后续问题落在“目标是否天然包含所有决定其身份的边界”。讨论指出，这个问题在高层抽象与底层实践中可能得到完全不同的答案。从理想数学对象看，解就是满足问题定义的解；如果完整成员条件已经给定，目标解可以视为一个独立集合，边界已经隐含在“属于或不属于该集合”之中。但现实中的目标说明很少能事先穷尽全部细节。人通常只知道大致想要哪一类结果，尚未形成一个可直接枚举或精确判定的目标解集合。

因此，实际文档并非总是在转录一个已经完整存在且已知的目标集合。它经常先提供一个大致方向，使 AI 形成较宽的候选结果空间，再通过补充条件、对照和排除常见的不希望结果逐步收敛。负向描述在这里不只是对完整目标的重复说明，也可能是发现和表达隐含偏好的现实手段。

#### 调查目的
本轮要定义讨论中“目标”的不同含义，解释为什么高层上边界可以被视为目标的一部分，而在文档编写和 AI 使用层又需要把目标描述与边界收敛分开处理；同时判断“先形成大致解空间，再剪枝”能解释什么，不能据此推出什么。

本轮不确定具体剪枝规则，不判断所有现实目标都没有客观解集合，也不把逐步收敛简化为只能增加负向描述的单向过程。

#### 调查范围与依据
本轮依据是用户提出的数学理想与现实目标形成之间的差异，以及前两轮对语义责任、解空间和表达方式的分层。分析采用集合近似与目标形成两种视角：一方面假设存在理想目标集合但当前描述只恢复了它的近似；另一方面考虑开放设计任务中，使用者的偏好会在看到候选与反例后继续形成，目标集合本身尚未闭合。

没有检查认知科学、需求工程或形式化规格文献，也没有用实际模型样本验证不同收敛步骤的效果。以下集合表示只用于区分概念，不表示已经定义了距离、概率或可计算的成员判定。

#### 调查结果与边界
当前需要把“目标”至少区分为三个对象：

1. **意向目标**：使用者真正希望得到的结果类型及其价值取向。它可能含有尚未说出的偏好，也可能在比较候选后继续演化。
2. **当前目标规格**：文档在某一时点已经显式表达的目标状态、条件、优先级、边界和验收依据。它是 AI 实际能够恢复的语义来源，但通常只是对意向目标的有限表达。
3. **当前候选解空间**：AI 根据当前规格仍可能解释、生成或接受的结果集合。它由文本与模型既有先验共同影响，不等同于使用者心中完整的意向目标。

这一分层使高层与底层答案可以同时成立：

- **高层抽象上**，若存在一个完整、确定且可判定的目标集合，那么所有决定成员资格的边界都已经属于目标定义；“目标”和“边界”只是同一集合从内部与外部观察的两面。
- **实践操作上**，当前目标规格通常不完整，文档只能先建立一个覆盖意向方向的较宽候选空间，再逐步加入能够区分想要与不想要结果的信息。此时把目标主线与边界修正分开表达，有助于维护目标的大致方向，并针对高概率误解继续收敛。

现实中的不确定还需要分成两类。第一类是**认识不完整**：理想答案或约束客观存在，但编写者尚未完全知道或表达，例如尚未恢复全部接口契约。第二类是**目标尚在形成**：开放设计任务没有预先闭合的唯一目标集合，使用者会通过候选、反例和取舍逐步形成偏好。前者要求继续发现事实，不能由 agent 补造；后者要求保留选择空间并显式呈现会改变方向的取舍，不能假装目标早已精确存在。

“先定义大致解空间，再剪枝”因此是一个有解释力的实践模型。可以把初始规格形成的候选空间记为 `C₀`，后续用正向条件进一步限定或排序候选，用负向边界排除已知的不希望区域，逐步得到更接近意向目标的 `C₁`、`C₂`。这里的收敛不只依赖负向剪枝：新的正向标准、优先级、代表性示例和验收反馈也会重新组织候选，而不只是从集合中删除成员。

边界之所以在实践中必要，至少有四种原因：自然语言目标存在欠指定；模型或领域存在高概率默认解；安全、权限、兼容性等不变量不能从宽泛目标自动恢复；人有时只有在看到反例后才能意识到某项隐含偏好。负向边界可以有效排除这些已知错误区域，并通过对比帮助意向目标变得清楚。

但该模型不支持主动穷举所有非目标。非目标空间仍可能巨大，持续增加孤立排除项会形成脆弱 denylist 并引入更多锚点。较稳的候选动作是只记录已有契约、现实反例、高概率默认错误或高后果风险所证明的边界；多个负向项若反复体现同一选择理由，应尝试恢复它们共同暴露的正向标准或命名不变量，而不是无限追加剪枝项。这个动作仍需后续讨论，尚未成为已采用规则。

本轮把下一问题收窄为：目标规格究竟只需要定义“哪些解可接受”，还是还必须表达可接受解之间的偏好与排序；以及在一次反例暴露隐含边界后，何时应保留负向表达，何时应将它提炼成目标的正向性质。前一个问题决定目标是集合还是带有评价结构的空间，后一个问题直接连接信息效率与解空间锚定。

### 目标是层级化且部分可表达的动态意向
- 形成时间: 2026-08-13T09:01:17+00:00

#### 形成时背景
上一轮仍把问题问成“目标是可接受解集合，还是还包含解之间的偏好、距离和排序”。讨论指出，这种问法依然把偏好放在目标之外。偏好本身就是目标的一部分；只是人的偏好并非一成不变，也未必能被本人清楚观察和表达。当前明确说出的目标还可能只是更深层目的在当前情境下形成的手段或代理。出现更能满足深层目的的结果时，人可能合理接受一个不满足当前表述目标的方案。

现实接受结果还受到多种因素共同作用：使用者可能尚未识别自己的偏好，偏好可能在看到候选后改变，期限和重做成本可能使更偏好的方案不再可行，已经投入的成本也可能通过心理上的沉没成本偏差影响选择。这些因素可以同时存在，因此不能把“被接受的结果”直接等同于预先稳定且完整表达的理想目标。

讨论进一步提出，目标之所以经常没有被写清，可能不是单纯的文档质量问题。若要求事先写清所有目标细节，似乎等同于要求预见事务发展的全部问题；当问题真正被描述到可以机械判定时，描述也可能已经从自然语言转化为代码、数学或领域专用语言。自然语言具有歧义、语境依赖和未闭合之处，而形式语言可以在受控语义内提供更精确的表达。

#### 调查目的
本轮要修正目标模型：把偏好、深层目的、当前代理目标、现实约束和允许偏离的理由放回同一个层级化目标结构；同时判断“不写清目标是因为无法预知一切”与“只有形式语言才能准确描述目标”分别成立到什么程度。

本轮不要求把人的全部价值形式化，不判断任何偏离当前目标的结果都更符合深层目标，也不把自然语言与形式语言划成准确和错误的简单二分。

#### 调查范围与依据
本轮依据是用户对“集合与偏好”二分的修正、关于深层目标与当前目标关系的实例分析，以及对自然语言和形式化规格能力边界的概念讨论。分析分别检查目标层级、时间变化、可观察性、资源约束和表达媒介，没有使用行为实验或外部文献。

“沉没成本”在本轮按两类影响区分：已经不可追回的过去投入本身，与当前制品状态产生的剩余切换或重做成本不同；前者可能通过认知偏差改变人的实际选择，后者会直接改变当前可行方案。两者都可能影响被接受结果，但不应在目标文档中被混写成同一项客观约束。

“完备性”也只作一般表达使用，不采用形式逻辑中的特定完备性定理含义。代码、数学和 DSL 是否能表达领域全部相关价值，以及表达能否正确对应人的真实意图，本轮没有得到形式证明。

#### 调查结果与边界
当前形成的主要修正是：**目标不是先有一个可接受集合、再额外附加偏好；目标本身就是随时间和情境变化、部分可见并具有层级的意向与取舍结构。** 可接受集合只是这个结构在某一时点、某组约束和某种表达下的投影。

至少需要区分以下层次：

1. **深层目标**说明为什么要做这件事以及最终希望保护什么价值，例如降低维护负担、获得信任或减少现实损失。
2. **当前目标**是深层目标在当前认知和情境下形成的可操作代理，例如采用某种架构、完成某项功能或取得某个指标。
3. **显式目标规格**是当前目标中已经进入文档、能够被 AI 取得的部分；未表达不等于不存在，表达出来也不保证仍然完整或最新。
4. **现实约束与承诺**决定哪些目标仍可执行，包括剩余时间、预算、兼容义务和重做成本。它们会改变当前最优选择，但不必等同于使用者的内在偏好。
5. **实际接受结果**是上述层次在当时认知、资源和心理状态下共同作用的结果，可能不满足某项当前目标，也可能并非事后看来最符合深层目标的结果。

因此，“更好的结果不满足当前目标”不一定是目标违约。当前目标若只是代理，而新方案更直接地满足深层目标，偏离可能是合理的目标修正。相反，agent 不能仅凭自己推测存在更深层目标就擅自推翻明确要求；文档需要尽可能表达当前目标与上层目的的关系、允许重新判断的条件和做决定的 owner，缺失且会改变结果时再请求确认。

精确描述目标也不等于完整预言未来。文档可以在不知道全部未来事件时精确声明当前不变量、优先级、可接受风险、适应规则、复核触发条件和决策权限。它无法穷尽的是未来情境及尚未形成的偏好，而不是所有精确性本身。把“未确定”明确写成未确定，也是一种语义准确。

自然语言确实容易依赖语境、保留歧义并省略成员判定，因此不适合独自承担所有需要机械验证的契约；但这些特性也允许人们在目标尚未闭合时表达方向、理由、类比和可协商取舍。它不应被简单认定为天然存在逻辑错误，而更适合被理解为默认不提供形式系统那种封闭、可判定的语义。

代码、数学和 DSL 可以在已经选定的语法、语义和领域边界内更精确地描述行为或性质，却不自动完整表达人的目标。代码可以精确执行错误意图，数学模型可以遗漏未被建模的价值，DSL 通常只覆盖它被设计承接的领域。形式化过程仍需要一个从人的深层目标与自然语言判断映射到形式符号的语义桥梁；桥梁错误时，形式规格只会更稳定地执行被曲解的目标。

这对 `ai-ready-docs` 暴露出一个候选方向：AI-ready 不应承诺把所有目标都改写成完全闭合的规格，而应让 AI 能区分哪些内容已经确定、哪些只是当前代理或偏好、哪些仍未知或可协商、哪些边界不可违反、什么条件允许重新打开当前目标。形式化适合承接已经稳定且需要机械判断的局部契约，自然语言继续承接目的、理由、未知和演进关系。这个方向尚未转化为最终原则或动作。

该模型也限制负向剪枝。若当前目标只是深层目标的代理，围绕它建立过密的禁止边界可能把更符合深层目标的新方案排除出去；但完全不写边界又会让 AI 沿高概率默认解曲解当前意向。下一步需要讨论的不是目标是否包含偏好，而是：文档怎样表达目标层级与重新解释权限，使边界既能保护当前意向，又不会把代理目标永久固化成最终目的。

### 文档投影会反过来参与目标形成
- 形成时间: 2026-08-13T09:07:50+00:00

#### 形成时背景
上一轮把后续问题落在“文档怎样表达当前目标只是代理，以及谁有权基于深层目标重新打开它”。讨论指出，这个问题把简单事项复杂化了：深层目标归谁所有，修改权就自然归谁；多人共同拥有时才需要由具体项目治理解决。更根本的问题是，文档不可能完整表达一个持续变化、连拥有者本人也无法精确观察和描述的真实目标。文档只是目标在形成当时、特定语境和表达能力下的一次投影。

投影并非被动快照。目标一旦被写成较精确的表述，就会成为新的认知锚点。拥有者可以围绕这个具体参照判断哪些部分可接受、哪些理解令人反感、哪些遗漏此前没有意识到；这些反应又会改变偏好和目标本身。因此，文档既描述目标，也介入目标形成。

#### 调查目的
本轮要判断目标投影的反身性怎样修正此前的语义保真、目标规格和解空间锚定模型，尤其是：文档是否应被默认理解为暂时投影；精确表达为何既可能固化目标，也可能帮助目标变清楚；负向锚定是否只是更一般的“表述产生锚点”的特殊情况。

本轮不设计项目级修改权限协议，不要求每份文档都增加“这是代理目标”的声明，也不把所有目标变化归因于文档锚定。

#### 调查范围与依据
本轮依据是用户对修改权限问题的修正，以及关于“目标投影成为新锚点并改变后续理解”的机制分析。它与前四轮形成的目标动态性、自然语言局限和解空间锚定候选模型进行比较，没有使用模型实验、用户研究或外部文献。

这里的“真实目标”仅指拥有者在某一时点实际具有但未必能够完整自省和表达的意向结构，不假设它是跨时间不变或客观可读取的实体。“投影”表示文档只能保存其中在当时被选择、被意识到并可表达的部分；不表示文档内容没有当前约束力。

#### 调查结果与边界
当前形成的主要认识是：**文档与目标之间不是静态的复制关系，而是一个反身反馈循环。** 可以暂时表示为：

`当时意向 → 文档投影 → 候选理解或结果 → 拥有者反应 → 更新后的意向`

这个循环包含以下含义：

1. **文档不能完整等同于真实目标。** 对持续变化且部分隐含的人类目标而言，文档至多忠实保存形成时能够表达的投影。所谓语义保真不能再解释成复制一个完整、稳定且可直接取得的目标对象。
2. **精确表达本身会改变认知条件。** 一个具体目标、示例或边界成为参照后，拥有者不再从完全开放的状态判断，而是在接受、拒绝、比较和修正这个锚点的过程中发现偏好。目标因此可能在被描述后发生变化。
3. **锚定不只有负面作用。** 锚点会压缩后续思考范围，但也使模糊偏好变得可观察、可对照和可讨论。正向目标可以形成参照锚点，负向方案可以形成对比锚点；两者都可能帮助澄清，也都可能过早固化局部理解。
4. **负向解空间锚定可能是一般表述锚定的特殊形式。** 此前关注“不使用 X”会继续激活 X；本轮表明任何被明确写出的目标或候选都可能改变后续搜索和偏好形成。负向锚定是否仍需单独成原理，要看它是否具有稳定而不同的方向性后果，而不能只因它是锚点就独立。
5. **当前权威不等于终极真实。** 文档可以作为 AI 当前行动的权威投影，直到目标拥有者修改它；“只是投影”不授权 agent 猜测隐藏目标并偏离明确要求。拥有者自然拥有目标修改权，协作环境中的代理、审批和冲突处理属于具体治理契约，不是这一原理本身。
6. **无需要求每份文档自称代理。** 对开放的人类目标，投影性可以作为分析文档时的默认认识。只有版本、有效期、假设、授权或复核条件会实际改变使用行为时，才需要在正文显式表达；否则增加元说明只会扩大维护面。

这要求再次修正语义责任：它不是保证文档永久对应一个不可变真实目标，而是准确保留当前投影中已经明确的含义、关系和边界，不把未知或推断伪装成深层目标，并让拥有者能够根据具体结果继续识别和修订目标。目标后来变化不证明原文在形成时错误；但文档若把阶段性投影伪装成永恒目的，就会妨碍正常演进。

信息效率也可能因此出现第二种价值。除了让 AI 更快收敛到当前可接受结果，一段表达还可能因为提供了高质量参照而更有效地帮助拥有者发现自己的偏好。这个“反馈效率”是否属于 `ai-ready-docs`，还是属于产品探索、需求发现或协作设计，目前没有闭合；不能因为它有启发性就直接扩大本 skill 的承诺。

下一步需要讨论的核心已经不再是修改权，而是：**当所有显式目标都会形成锚点时，什么样的锚定是在提供必要参照，什么样的锚定是在过早固化解空间？** 这个区别将同时决定正向描述、负向边界、信息效率和解空间锚定怎样重新组合。

### 区分逻辑剪枝、搜索偏置与路径依赖
- 形成时间: 2026-08-13T09:12:51+00:00

#### 形成时背景
上一轮又把后续问题写成“什么样的锚点提供必要参照，什么样的锚点过早固化目标”。讨论指出，这个问法仍然过宽，并预设需要先把锚点二分或贴标签，再为不同类别配置动作。“固化”本身也没有被定义：从数学集合角度看，正确排除一个错误选项只是缩小可行解集合，不等于目标被不当固化。

讨论同时提出，所谓解空间锚定并非 LLM 独有。人也可能因既有解释、示例和处理路径形成惯性思维，只是这种现象通常只能作为群体层面的概率倾向理解，不能作为对每个人必然生效的确定性原理。这也反过来要求检查：此前对 LLM 锚定的描述是否同样过于确定。

#### 调查目的
本轮要撤回“必要锚点 / 过早固化”的简单二分，区分正确约束带来的逻辑剪枝、对象被点名后产生的搜索或注意偏置，以及结论跨时间难以修订的路径依赖；并判断“锚定”应该严格指向哪一种机制。

本轮不为文档内容建立锚点标签体系，不判断人类与 LLM 的锚定机制相同，也不把任何候选被排除都视为认知偏差。

#### 调查范围与依据
本轮依据是用户对“固化”概念和二分问题的反例检查，以及关于人类惯性思维与 LLM 上下文影响的类比。分析只做概念分离，没有检索认知心理学研究、运行 LLM 对照实验或测量效应大小。

因此，关于人类存在类似偏置只能作为待验证的群体概率假设；关于 LLM 的表述也只确认被写入上下文的内容成为条件输入，不能由此直接证明某个被点名对象必然获得特定方向或大小的生成偏置。模型、提示结构、任务和采样过程都可能改变实际结果。

#### 调查结果与边界
当前至少混合了三种不同效应：

1. **逻辑剪枝**：目标、契约或事实排除某些候选，使可接受解集合缩小。只要排除依据正确且仍然适用，这就是目标规格的一部分，不是固化，也不因使用负向表达而可疑。
2. **搜索或注意偏置**：在逻辑允许集合相同的情况下，点名某个对象改变了系统优先考虑、联想或生成哪些候选。若保留合法值集合已经排除 X，而额外写“不使用 X”又让思考持续围绕 X 展开，这才接近此前所说的解空间锚定。
3. **路径依赖或修订阻力**：某个阶段性目标、假设或边界进入文档和后续工作后，即使原依据变化，维护者仍沿用它，或修改需要承担额外协调成本。只有这种不再由当前目标和证据支持、却持续阻碍重估的情况，才适合称为不当固化；稳定保存仍然有效的不变量不是固化。

三种效应可以同时存在，但不能相互替代。一条负向规则可以正确剪掉危险结果，同时提高该危险方案的显著性，还可能在多年后变成失去依据的历史惯例。也可能只有第一种效应而完全没有可观察的锚定问题。因此，不能从“文本排除了 X”直接推导“文本固化了解空间”。

这也修正了锚定的候选定义：**锚定不是约束本身，而是表述在其逻辑语义之外，对候选显著性、搜索顺序或后续修订产生的附加影响。** 若同一边界改用不点名 X 的合法值集合表达后，逻辑允许结果相同，但候选生成和注意分配发生变化，这种差异才是锚定假说要解释的对象。该反事实目前只是可检验思路，不是已完成实验。

人类与 LLM 都可能出现这种附加影响，但当前只能安全得出概率性陈述。人类会受到记忆、经验、社会惯例和既有问题框架影响；LLM 的输出以当前上下文为条件，被点名对象可能改变后续 token 分布和方案联想。两者的内部机制、可持续时间和可修正方式不同，不能用“人也会惯性思考”证明 LLM 的具体效应，也不能把 LLM 的条件生成机制外推为人的确定规律。

上一轮的二分问题因此应当撤回。当前不需要给每个锚点贴“必要”或“过早”标签，而应在概念上分别问：排除是否由当前目标或契约支持；点名对象是否带来超出逻辑约束的搜索偏置；原依据变化后是否仍能重新评估。这三个问题分别检查语义正确性、概率性行为影响和时间上的可修订性。

这一修正对 `ai-ready-docs` 的直接边界是：在缺少行为证据时，不能把“提到负向方案必然限制 LLM 解空间”写成确定规律；最多可以作为需要减少无信息量重复点名的风险解释。是否应保留独立的解空间锚定原理，需要后续结合模型样本或更谨慎的机制表述再判断。

### 区分内容保真、目标符合与目标显化
- 形成时间: 2026-08-13T09:29:48+00:00

#### 形成时背景
上一轮讨论后，后续问题一度被表述为：既然文档只是动态目标在某一时刻的投影，语义保真究竟在保真什么，以及一份不可能完整描述目标的文档怎样才算没有曲解目标。讨论随后指出，这仍然错误地把语义保真与真实目标是否得到满足绑在一起。

语义保真最初要保护的不是一个隐藏且完整的目标，而是已经进入现有内容的含义在阅读、整理和改写过程中不被改变。它可以保证已经固定的内容不变形，却不能保证这些内容本身正确、完整或确实对应拥有者的深层目标。与此同时，“曲解目标”往往是看到具体结果后的回顾性判断：人可能只能表达由深层目标派生出的浅层目标，直到一个完全符合浅层描述的结果与深层目标发生冲突，才识别出此前没有说出的差异。

#### 调查目的
本轮要把现有内容的语义保真、结果与深层目标的符合程度，以及深层目标通过结果反馈逐步显化这三件事分开；进一步解释为什么 AI 即使正确理解了现有文档，也可能在人的判断中表现为慢了一步或曲解了目标。

本轮不判断人的深层目标始终正确或稳定，不为隐含目标建立可计算表示，也不把帮助目标显化直接纳入 `ai-ready-docs` 的现行能力承诺。

#### 调查范围与依据
本轮依据是用户对“语义保真保存什么”和“曲解何时能够被识别”的直接修正，以及本主题前六轮关于动态目标、文档投影和反馈循环的概念分析。当前报告基线已经提交为 Git commit `37e75747a29326dd9a6fc9ec911455aa412dcab2`；`skills/ai-ready-docs/` 与相关决策记录中的阶段性改动仍未提交，本轮没有据此修改 skill 行为。

本轮没有使用模型对照实验、用户研究或外部理论材料。“深层目标”仍指尚未被完整语言化、但能够影响拥有者评价的意向和偏好结构；说人“掌握”深层目标，不要求人能事先把它陈述为完整规则，只要求其可能在面对具体结果时表现出接受、拒绝或比较能力。

#### 调查结果与边界
当前需要区分三种不同关系：

1. **语义保真**比较现有内容与其后续表达。若当前文档为 `D`，整理或转写结果为 `T(D)`，它检查的是两者已经表达的含义是否保持一致。这里的“固定”只表示内容在本次变换中是输入事实，不表示它永久有效或符合真实世界与深层目标。
2. **目标符合**比较具体结果与拥有者的深层评价。当前文档可以得到完全保真的改写，AI 也可以正确执行其浅层要求，但结果仍可能违背没有进入文档的偏好。语义保真不能证明文档本身正确，也不能保证结果符合深层目标。
3. **目标显化**描述隐含判断怎样通过候选结果和反馈进入后续表达。人未必事先知道“正确结果”是什么，却可能在看到一个具体结果后知道“这不是我要的”，并由此形成此前无法写出的新条件、偏好或理由。

因此，至少要区分两种通常都被称为“曲解”的情况。第一种是 AI 或改写者改变了现有文档已经表达的含义，这是语义保真可以直接检查和阻止的内容变形。第二种是 AI 正确实现了显式目标，但显式目标只是深层目标的不完整投影；这只能在拥有者对具体结果作出判断后被识别为目标偏移，不能反过来证明 AI 当时错误理解了文档。

“AI 慢人类一步”在这里更接近信息位置的不对称。AI 取得的是拥有者上一次已经成功表达并提供到上下文中的目标投影；拥有者还具有尚未语言化、但可能被具体结果触发的评价能力。结果出现后，拥有者先发现冲突，再把反馈交给 AI，AI 才能取得新显化的目标内容。即使每轮传递都完全保真，这个时间差仍可能持续存在。

这种差异不意味着人始终完整理解自己的深层目标。人的判断也会随情境、锚点和时间改变，并可能受认知偏差影响。当前只确认拥有者相对于 AI 具有对自身接受与拒绝反应的优先访问；不能由此推出每次事后拒绝都揭示了一个预先稳定存在的正确规则。

这也收窄了 `ai-ready-docs` 中语义保真的责任：它应保护现有内容不因整理、结构化、消歧或格式迁移而改变含义，并在内容矛盾、错误或不完整无法由证据确定时暴露问题，而不是以推测的深层目标静默修正原文。帮助拥有者通过示例、候选和反馈发现未表达目标可能有价值，但那是在促进目标显化，不能借用“语义保真”获得改写授权。

对负向描述而言，同样需要先检查内容来源。现有文档已经明确承诺的负向边界属于待保真的内容，不能因为它可能产生锚定就直接删除；为了提高剪枝效率而由 agent 新增的负向边界则没有现有语义依据。至于原有边界是否真正符合深层目标，仍要由现实结果、证据或拥有者反馈判断，不能从正负句式本身推出。

下一步需要讨论的具体问题是：**帮助目标显化是否属于 `ai-ready-docs` 的职责，还是应当与“忠实整理现有内容”保持明确边界？** 如果属于，skill 需要说明它何时只能呈现候选或疑问、不能直接写回文档；如果不属于，就要解释 AI-ready 文档怎样承认静态目标投影的固有限制，而不对深层目标符合性作出无法兑现的承诺。

### 深层目标只有局部且不可靠的可识别性
- 形成时间: 2026-08-13T09:37:25+00:00

#### 形成时背景
上一轮之后，讨论进一步追问：当现有内容无法唯一解释时，把不确定性显式写出来是在保真还是在增加内容。用户指出，显式呈现不确定性本身会改变认识条件。如果人面对具体分歧后能够迅速作出判断，那么歧义可能只存在于浅层目标的语言投影中；至少对当前这组候选而言，深层目标已经能够给出区分。

但这不能扩展为“人可以在看到结果后可靠读取深层目标”。人对自身深层目标也只有大致、局部的理解，缺乏足够具体的描述和自省能力。即使实际结果已经与深层目标发生冲突，人也未必能够识别冲突、定位原因或把它转化成新的明确规则。此前用“结果触发人的判断能力”解释目标显化，仍然高估了这种判断能力的稳定性和覆盖范围。

#### 调查目的
本轮要区分文档中的表达歧义、拥有者对具体候选的局部判断能力，以及拥有者识别深层冲突的能力；说明把不确定性写出来为何既可能揭示已经存在但未表达的区别，也可能参与形成新的偏好，而不能被简单视为读取一个清晰的隐藏答案。

本轮不判断深层目标是否作为完整对象预先存在，不把即时选择等同于稳定偏好，也不为人的冲突识别能力建立普遍强弱结论。

#### 调查范围与依据
本轮只依据用户对上一轮问题的概念修正，并与本主题中“目标是动态投影”“文档参与目标形成”“内容保真不同于目标符合”的已有分析进行对照。Git 基线仍为 `37e75747a29326dd9a6fc9ec911455aa412dcab2`，本轮只追加调查报告并同步派生索引，没有修改 `ai-ready-docs` 的行为文本。

本轮没有使用认知心理学研究、用户实验或模型实验。以下关于“迅速判断”“未识别冲突”和“偏好形成”的解释都是候选机制，不能用于推断某个具体人的内部状态。

#### 调查结果与边界
当前至少需要区分三种不确定性：

1. **表达不确定性**：浅层目标的自然语言允许多个合理解释，现有文本不足以区分它们。
2. **评价不确定性**：拥有者面对具体候选时也无法形成稳定选择，可能因为深层目标尚未形成、内部价值冲突或当前信息不足。
3. **识别不确定性**：候选实际已经损害某项深层价值，但拥有者尚未意识到该后果、没有把感受归因到正确原因，或根本没有察觉冲突。

三者不能互相推出。文档含有歧义，不表示拥有者对相关区别没有偏好；拥有者能够立即选择 A，也只说明当前对 A 与 B 的局部比较具有判别力，不证明其全部深层目标已经清晰、无冲突或能够被完整描述。反过来，拥有者没有立即拒绝某个结果，也不能证明结果符合深层目标，因为冲突可能尚不可见或未被识别。

因此，显式呈现不确定性更像一次**认知探针**。它把抽象歧义转化为可比较对象，使原本无法语言化的局部判断有机会出现。如果拥有者迅速且稳定地选择，至少可以确认浅层规格此前漏掉了一项当前有效的区别；但无法仅凭这一反应判断该区别一直潜藏于稳定深层目标中，还是在对比、锚定和情境作用下刚刚形成。

这也意味着显式化并非纯被动转录。列出 A 与 B 会改变拥有者看到的问题结构，可能帮助识别偏好，也可能制造新的参照和锚点。诊断“现有证据不足以在 A、B 间判断”可以忠实描述文档的认识边界；将 A、B 作为正式目标选项写入权威正文，则已经介入目标形成。两者需要在工作流上区分，不能都以语义保真为依据。

此前“人掌握真正的深层目标，AI 因此总慢一步”的说法需要进一步收窄。人相对于 AI 拥有第一人称反应和现实处境，但不拥有一份可随时查询、内部一致且覆盖全部未来情境的深层目标规格。AI 通常落后于已经发生但尚未传递的判断；人与 AI 也可能共同落后于尚未被任何一方识别的深层冲突。

由此，目标符合不能只以“用户当时没有反对”作为充分证据，目标显化也不能承诺通过提问把完整答案提取出来。对 `ai-ready-docs` 而言，更稳妥的候选边界仍是：保存现有承诺，显式区分证据不足与已经确认的选择，并让后续反馈能够修订当前投影；但不能把尚未被识别的深层目标伪装成可通过一次澄清获得的事实。

下一步需要讨论的是反馈的认识地位：**当拥有者针对一个具体候选给出接受、拒绝或修正时，怎样判断这次反馈是在揭示此前已经存在的深层偏好，还是在当前候选与锚点作用下形成了新的偏好；以及对文档维护而言，是否真的需要区分两者。** 这将决定一次反馈应当直接固化为长期规则，还是只作为带有情境和来源的当前目标投影。

### 正负描述的不对称来自参照结构而非句式
- 形成时间: 2026-08-13T09:46:59+00:00

#### 形成时背景
上一轮准备继续讨论一次反馈何时可以升级为长期规则。用户随后把问题重新拉回正向与负向描述本身，并观察到这几轮对话实际上让双方互相提供候选解释和反例，形成了一种双向的认知探查。这个过程发现了不少此前没有表达清楚的问题，但它也再次表明：任何一方提出的概念框架都可能成为新的参照，不能因为它触发了判断就直接视为读取到了一个预先完整的深层目标。

新的直觉是，正向描述似乎总能被内化为解的一个方向，至少提供一种定位方式；负向描述则更复杂，可能出现不相关、曲解、范围扩张或只排除局部错误等不同情况。描述一个状态时，直接指向该状态通常更简单，因为状态本身已经形成锚点，描述越接近这个锚点，恢复目标所需的推断就越少。但反例同样存在：某个负向条件本身可以是任务的一个锚点；即使它存在逻辑等价的正向改写，正向表达也可能更长、更抽象或更不准确。

#### 调查目的
本轮要解释正向描述为何通常比负向描述更容易提供方向，同时容纳负向内容本身就是稳定参照、等价正向表达反而更复杂的情况；并判断真正的不对称来自肯定与否定句式，还是来自描述对象与任务实际承诺之间的参照距离。

本轮不采用“所有负向描述都应改成正向描述”的动作，不假设存在可量化的统一语义距离，也不把一句话是否包含否定词直接当作其语义责任和信息价值。

#### 调查范围与依据
本轮依据是用户对正向定位、负向复杂性、状态锚点和负向锚点反例的直接分析，并与本主题此前关于解空间、信息效率、语义保真和搜索偏置的候选模型进行概念对照。Git 基线仍为 `37e75747a29326dd9a6fc9ec911455aa412dcab2`；工作区中的 skill 与决策改动仍是未提交的阶段性实现，本轮只追加报告并同步索引。

本轮没有进行语言学分析、模型生成实验或数学证明。“方向”“距离”“中心”“补集”和“锚点”仍是解释候选生成与语义恢复的分析比喻，不表示已经为自然语言建立度量空间。关于正向描述“总能”提供方向的说法在本轮只作为待收窄直觉接受，因为“高质量”“更自然”等宽泛正向词虽然具有评价方向，也可能没有足够分辨率来定位可执行结果。

#### 调查结果与边界
当前更有解释力的区分不是语法上的正向与负向，而是：**一句话直接指向任务真正需要恢复的参照，还是要求读者先围绕另一个对象计算补集、推断替代物或发明未命名的共同性质。**

正向描述通常占优，是因为它经常直接命名目标状态、代表性候选、评价方向或验收性质。若目标参照为 `A`，文本直接描述 `A` 的性质，即使不完整，也往往使后续候选能够围绕同一个中心继续细化。它提供的是朝向某个区域的定位，而不必先理解一个错误对象再判断应向无数其他方向中的哪一边移动。但正向句式本身不保证有效；一个没有尺度、判据或领域含义的抽象褒义词只能提供低分辨率方向。

一般负向描述则常以被排除对象 `N` 为直接参照，只说明结果不属于 `N`。在开放且高维的候选空间中，补集 `U \\ N` 可能由大量彼此无关的区域组成，没有自然中心、排序或抵达路径。这比“非目标具有更高阶无穷”更接近当前真正要表达的问题：关键未必是集合基数，而是补集缺少可供生成过程使用的内部结构。离开一条错误道路，并不会自动指出剩余道路中的哪一条更接近目标。

负向描述还容易把不同问题叠在一起：被否定对象可能与当前任务无关；否定的范围、量词和时间条件可能被误读；一次局部拒绝可能被扩张成全局规则；文本可能准确排除一个结果却没有提供选择剩余候选的依据；点名错误对象还可能产生额外的注意或搜索偏置。这些问题解释了为什么负向内容在实践中经常比表面的一个“不”更复杂。

但负向表达并不必然远离任务参照。当任务真正要保护的是某个不可发生的事件、缺失状态或保持不变的性质时，负向条件本身就是直接承诺。例如“不得删除用户未提交的改动”直接点明违规事件和受保护对象；若改成“妥善保护用户工作”，虽然表面为正向，反而失去可判定的边界。“输出不得包含密钥”同样可能比“保持输出安全”更具体。这里负向描述不是用错误对象间接猜目标，而是在直接命名一项禁止事件或结果不变量。

逻辑等价也不保证文档效果等价。把负向条件改写成正向条件，可能需要新造一个尚未定义的类别、扩大或缩小原有范围、隐藏真正需要检查的失败事件，或者增加更多推断步骤。反过来，在允许集合闭合且已有稳定名称时，正向列出合法状态可能更直接。表达选择取决于哪一种写法更贴近原始契约锚点，而不是哪一种写法避免了否定词。

由此出现一个候选上位解释：**正向描述通常更强，不是因为肯定句天然拥有更高价值，而是因为目标状态通常是任务的主要参照中心；直接描述中心比仅描述一个开放补集更容易定位。负向描述在它直接承载禁止事件、缺失状态或不可违反边界时，也可以成为与目标中心共同定位结果的参照。** 一项完整任务可以同时由目标方向和若干边界参照确定，负向边界不需要假装能够独自提供全部实现方向。

“描述越接近锚点越准确”因此可能比“正向描述优于负向描述”更接近原理，但还不能直接变成动作。这里的锚点究竟只指期望状态的中心，还是也包括边界、禁区和不变量，目前尚未定义；如果把一切被点名的对象都称为锚点，概念又会失去区分能力。信息效率可能描述直接表达节省了多少推断，但也不能替代对原始语义责任的识别。

下一步需要讨论的是：**解空间分析中的“锚点”究竟应当只表示目标中心，还是表示任何能够稳定定位候选的参照，包括禁止事件、边界和不变量？** 如果负向内容可以是锚点，就还要区分“承担契约定位的负向参照”与“仅因被点名而产生搜索偏置的对象”，否则“负向锚定”会同时表示有价值的边界和潜在副作用。

### 分离解空间定位与上下文搜索锚定
- 形成时间: 2026-08-13T09:52:08+00:00

#### 形成时背景
上一轮提出是否应停止用“解空间锚定”同时指代契约定位与搜索偏置。用户确认确有必要区分，并恢复了该术语最初要解释的现象：LLM 更容易因为某些内容被放入上下文而继续在它附近寻找答案，即使这些内容是以否定方式被提及。原来的“解空间锚定”主要指向这种由提及产生的邻近搜索倾向。

随着讨论推进，“解空间”又被泛化为目标所对应的全部可能结果及其关系，目标、边界和不变量对候选的正常限定也被称为锚定。于是同一个术语开始同时表示两件方向不同的事：文档在语义上怎样确定可接受结果，以及措辞在行为上怎样改变 LLM 优先生成的结果。继续沿用会使“负向内容提供有效边界”与“负向内容可能诱发错误方向”互相混淆。

#### 调查目的
本轮要恢复原“解空间锚定”的机制边界，将任务契约对候选结果的正常定位与被提及对象引起的搜索显著性偏置分开；并判断这一区分怎样重新解释正向描述和负向描述可能具有的不同效果。

本轮只确认概念需要拆分，不最终确定 skill 中采用“搜索锚定”“上下文锚定”还是其他名称，也不据此直接修改 `ai-ready-docs` 原理或决策记录。

#### 调查范围与依据
本轮依据是用户对“解空间锚定”原始含义和后续概念泛化的直接确认，以及前九轮报告对逻辑剪枝、搜索偏置、目标中心和负向边界的概念分析。Git 基线仍为 `37e75747a29326dd9a6fc9ec911455aa412dcab2`；本轮没有检查模型内部实现，没有运行提示对照实验，也没有修改当前 skill 行为。

“搜索”在这里继续是生成过程的外部分析比喻，不主张 LLM 内部执行了可观察的符号搜索算法。“附近”可以指语义相似方案、同类实现、围绕被点名对象的修补路径或其他受上下文显著性影响的候选；其存在、方向和强度仍需要具体模型与任务证据。

#### 调查结果与边界
当前可以把两个效应分别表示为：

1. **解空间定位**是语义或契约效应。目标、条件、边界、排序标准和验收要求共同确定哪些候选可接受、哪些被排除以及候选之间怎样比较。它回答“文档承诺了什么”，是任何有效任务说明都需要完成的正常功能，不带有负面含义。
2. **上下文搜索锚定**是概率性或行为效应。某个对象由于被明确提及而获得额外显著性，使 LLM 更可能围绕它、它的同类或修正路径继续生成候选。它回答“相同或相近的语义约束以这种措辞出现后，模型更容易先想到什么”，不等同于合法候选集合发生变化。

如果用抽象表示，解空间定位改变的是文档所定义的可接受结构 `S(D)`；搜索锚定改变的是给定文档后不同候选被生成或优先考虑的倾向 `P(c | D)`。这个表示只用于概念分离：自然语言通常无法给出严格集合，模型输出倾向也未在本调查中被实际测量。

两个效应可以同时存在，也可以彼此独立。例如“不得使用 X”在语义上把 X 排除出可接受结果，这是合法的解空间定位；与此同时，点名 X 可能提高 X 及其邻近方案的显著性，这是候选性的搜索锚定。删除这句话可能减少搜索锚定，却也可能错误删除必要边界；保留它则不代表搜索偏置一定会在每个模型和任务中发生。

这一区分也解释了为什么逻辑等价的表达可能具有不同效果。两种写法可以定义近似相同的 `S(D)`，却因为点名对象、顺序、示例和上下文位置不同而形成不同的 `P(c | D)`。反过来，两种写法可能都点名 X，因而具有相似显著性，却在量词、范围或例外上定义不同的契约。语义保真首先约束前者不能被静默改变；降低搜索锚定只能在保留契约定位后作为表达优化考虑。

因此，后续不宜再把目标状态、边界或禁止事件本身称为“解空间锚定”。它们是在定位或构造解空间。若需要保留原始机制，暂时使用“上下文搜索锚定”能够强调它来自内容被提及后的生成倾向；若“搜索”会被误解为内部算法，则“上下文显著性偏置”更加谨慎。最终术语仍待后续整理 skill 时决定，但两个概念不应再次合并。

拆分后，正向与负向描述出现一个值得继续检查的结构：正向描述点名目标时，其语义定位与上下文显著性通常朝向同一区域；负向描述点名被排除对象时，其语义作用要求远离该对象，而潜在的搜索锚定却可能提高该对象附近候选的显著性。负向描述的特殊风险也许不在于它完全没有信息，而在于它的语义方向与提及产生的行为方向可能相反。

下一步需要讨论的是：**这种“语义定位与搜索显著性同向或反向”的关系，是否才是正向描述通常优于负向描述的核心机制？** 如果是，它仍需解释负向边界不可省略时怎样表达，以及有无证据证明“提及即提高邻近候选显著性”在实际 LLM 任务中足够稳定，而不能再次把候选机制写成确定规律。

### 关联激活邻域不等于任务有效解集合
- 形成时间: 2026-08-13T09:59:09+00:00

#### 形成时背景
上一轮提出，正向描述可能使语义定位与搜索显著性朝向同一区域，负向描述则可能在语义上要求远离被提及对象、在行为上又把生成拉回该对象附近。用户指出，这个“两个方向相反”的几何比喻仍没有准确描述 LLM 的工作方式。

新的机制直觉是：训练后的语言模型以向量化表示和学习到的权重处理 token；一个进入上下文的 token 或概念会影响与它相关的其他表示和后续 token 概率。被共同带入高可用状态的不一定只是语义近义词，也可能包括反义词、搭配词、共同出现的对象、典型操作和修正路径。分布式表示中的“接近”或关联不等于人所需要的目标关系；即使一片相关邻域被提高了生成可能性，其中也可能没有当前任务真正需要的解。

#### 调查目的
本轮要用更谨慎的 Transformer 机制描述修正“被拉回负向对象附近”的比喻，区分 token embedding、上下文化内部表示、输出词表分布和任务有效解集合；并判断负向描述的特殊成本是否更适合解释为关联激活邻域与有效解集合之间的低重合，而不是单一方向上的远近冲突。

本轮不把内部表示简化成可直接观察的语义地图，不主张静态向量距离能够单独预测输出，也不把论文对特定模型和层的发现无条件外推到所有现代 LLM。

#### 调查范围与依据
本轮依据包括用户提出的向量空间、邻近激活和反义词关联解释，以及以下一手论文：Transformer 原始论文 [Attention Is All You Need](https://arxiv.org/abs/1706.03762) 所描述的 embedding、注意力、前馈变换与输出概率结构；[How Contextual are Contextualized Word Representations?](https://aclanthology.org/D19-1006/) 对 ELMo、BERT 和 GPT-2 上下文化表示几何的分析；[Transformer Feed-Forward Layers Are Key-Value Memories](https://aclanthology.org/2021.emnlp-main.446/) 与 [Transformer Feed-Forward Layers Build Predictions by Promoting Concepts in the Vocabulary Space](https://aclanthology.org/2022.emnlp-main.3/) 对前馈层怎样关联输入模式并改变词表分布的研究；以及 [Semantic Specialization of Distributional Word Vectors](https://aclanthology.org/D19-2007/) 对分布式词向量混合近义、反义、蕴含和主题相关等关系的总结。

外部资料于 2026-08-13 核对。它们支持“上下文化表示不能还原为一个静态 token 向量”“学习到的模式会改变输出词表上的概率质量”和“分布式邻近会混合不同词汇关系”，但没有直接实验本调查中的正负文档写法，也没有证明任意一次提及必然激活固定邻域。Git 基线仍为 `37e75747a29326dd9a6fc9ec911455aa412dcab2`；本轮只追加调查报告并同步索引。

#### 调查结果与边界
用户的核心修正成立：**被上下文提高可用性或输出概率的关联邻域，不等于当前任务的有效解集合。** 但“token 被映射到一个就是全部权重的向量空间，并自动带动几何近邻 token 激活”仍需收窄。

现代 Transformer 通常先通过 embedding 矩阵把 token ID 转成初始向量，但 embedding 矩阵只是模型权重的一部分。初始向量会经过多层注意力、前馈网络、残差连接与归一化，形成依赖完整上下文和层级的隐藏状态，再被映射为下一 token 的 logits 和概率分布。研究显示，同一个词在不同上下文和高层表示中的位置会显著变化；因此不能用输入 embedding 中的静态欧氏距离或余弦距离，直接推出哪些 token 必然被一起输出。

更合适的分析对象是**上下文关联激活邻域**：文本中的一个对象参与形成当前隐藏状态后，会使训练中与该模式相关的若干概念、词汇和续写获得不同程度的可用性。这里的关联可以来自语义相似、反义对比、语法搭配、话题共现、典型事件结构或任务范式。反义词常与近义词共享相似分布信息，正说明表示邻近更接近“在类似上下文中相关”，而不是“能够互相替代”或“共同属于正确答案”。

因此至少还要区分四个对象：

1. **输入 token embedding**：词表项的学习向量，是上下文化计算的起点之一。
2. **上下文化表示**：完整上下文经过各层变换后的状态，不再由单个 token 的静态位置决定。
3. **关联激活或输出候选邻域**：当前上下文使哪些模式、概念或词表项更容易参与后续预测。
4. **任务有效解集合**：由目标、事实、边界和验收条件确定的可接受结果，与前三者没有天然同一关系。

这个分层把上一轮的“方向相反”修正为**邻域重合不足**。正向描述直接点名目标时，所激活的关联邻域可能更大比例地与有效解所需概念、属性和典型实现重合；但近义词、常见搭配和默认做法仍可能不是正确解。负向描述点名被排除对象时，激活邻域可能同时包含该对象、反义词、替代项、讨论它的惯常措辞和修复路径；这些内容中有些有助于理解边界，有些继续围绕错误对象，有些则完全不满足目标。否定关系不会自动把整片邻域变成正确补集。

负向描述的额外复杂性可能由此分成两步，但这只是功能分析，不主张模型内部按时间顺序执行：模型需要先形成足以识别被排除对象及其关系的上下文表示，同时还要把该对象绑定为“需要避开或检查的约束对象”，而不是“需要复现的目标对象”。即使排除成功，文档仍可能没有提供怎样从剩余候选中选择有效解的信息。

这并不说明负向边界无效。为了执行“输出不得包含密钥”，模型必须能够识别密钥相关模式；相关激活可以支持检测和抑制，而不只支持生成。真正风险取决于指令关系、模型能力、上下文结构和目标信息能否把概率质量重新组织到有效候选上，不能从“提到了 X”直接推出“必然输出 X”。

因此，“上下文搜索锚定”可能仍然过度暗示模型在一个语义地图上围绕单点做局部搜索。更谨慎的候选名称是“关联邻域激活”或“上下文关联偏置”：它强调提及会改变一组关系混杂的候选和模式的可用性，但不预设它们都在同一种几何意义上接近，也不预设模型真的采用搜索算法。

下一步需要讨论的是：**负向描述相对于正向描述的核心额外成本，究竟应表述为“关联激活邻域与有效解集合的重合率通常更低”，还是表述为“被激活概念还必须被正确绑定为排除对象，而不是生成目标”？** 前者解释为何相关内容仍可能不是解，后者解释否定关系为何比直接描述目标多一层组合责任；两者可能共同成立，但是否属于同一原理仍未确定。

### 负向描述需要额外完成对象角色绑定
- 形成时间: 2026-08-13T10:13:48+00:00

#### 形成时背景
上一轮把负向描述的候选额外成本分成两种解释：被激活的关联邻域与有效解集合重合不足，以及被描述对象还必须被绑定为排除对象而不是生成目标。用户确认角色绑定方向更接近问题核心，并作出进一步概括：负向描述确实能够锚定或定位部分目标，但还必须区分目标本身与负向描述直接指向的对象；相较之下，正向描述在对象就是目标的常见情况下，只需要自身足够准确。

这要求把“负向描述信息少”再次修正。负向描述可能非常具体，也可能提供必要的解空间边界；它的额外复杂性不只取决于信息量，而来自描述对象、语义角色和最终生成目标没有默认重合。

#### 调查目的
本轮要明确对象角色绑定是否构成正向与负向描述之间相对稳定的结构性不对称，区分“准确表示对象”“正确识别对象在任务中的角色”与“提供最终生成目标”三项责任，并检查“正向描述只需要足够准确”成立的条件和例外。

本轮不声称 Transformer 内部存在一个可定位的独立角色绑定模块，不把功能上的额外责任直接等同于固定计算步骤或可量化推理成本，也不据此修改 skill。

#### 调查范围与依据
本轮依据是用户对上一轮角色绑定假说的确认，以及前十一轮报告形成的解空间定位、关联邻域激活、语义保真与负向边界模型。Git 基线仍为 `37e75747a29326dd9a6fc9ec911455aa412dcab2`；本轮没有新增外部资料或模型实验，只在现有证据边界内进行功能分解，并仅追加调查报告与同步派生索引。

“绑定”在这里表示当前上下文必须让同一对象同时带有明确的任务关系，例如目标、禁止项、反例、检查项或历史方案。它是对输入输出责任的功能描述，不主张模型用符号标签保存这些角色。

#### 调查结果与边界
当前形成的候选核心是：**负向描述的额外复杂性来自对象内容与任务角色的分离。** 文本必须让模型形成足够准确的对象表示，才能知道需要排除什么；又必须让这个对象与“禁止、避开、不得输出、仅用于检查”等角色关系结合，防止对象本身或其关联模式被当作目标内容直接延续。

可以把一项描述暂时分成三个功能：

1. **对象表示**：文本在说什么状态、方案、事件或性质。
2. **角色绑定**：该对象在当前任务中是目标、边界、反例、风险、检查项还是其他角色。
3. **目标定位**：最终结果应朝向什么区域，以及在多个合法候选之间怎样选择。

典型正向目标如“生成一个只读调查报告”，对象表示与目标角色基本重合：报告是什么描述得越准确，生成方向通常越清楚。它当然仍需要范围、优先级和验收条件，但不需要把正文主要对象再解释成“需要理解却不得生成的东西”。因此，“正向描述只需要自身足够准确”应理解为这种常见的角色重合，而不是正向句式天然完备。

典型负向描述如“不要生成营销文案”，对象表示直接落在营销文案上，角色却是排除；即使模型完全理解什么是营销文案，这只完成了识别条件。它还需要正确维持否定关系，并从剩余候选中找到实际目标。如果没有正向目标或其他选择标准，角色绑定成功也只能排除一个区域，不能独自决定输出什么。

必要负向边界同样体现这三层，只是它们并不因此低价值。例如“不得删除用户未提交的改动”准确表示删除事件和受保护对象，把事件绑定为禁止边界，并与其他目标共同定位合法操作。这里负向描述承担了不可替代的契约责任；其复杂性意味着关系必须清楚，而不是应该删除或强行改成正向句。

关联邻域重合不足可以视为角色绑定问题的一项放大因素，而不是完整替代解释。对象被表示后，与之相关的概念、操作和措辞可能获得更高可用性；角色关系必须作用于这片混杂内容，区分哪些用于识别、检查和抑制，哪些仍可作为合法替代材料。邻域越杂、否定范围越模糊，角色绑定越容易失效。但即使没有任何额外激活偏置，逻辑上仍需区分“被描述对象”与“要生成对象”。

这也说明正负不对称可以在不依赖具体模型内部机制的层面成立。对于任何执行自然语言约束的系统，正向目标常可让所描述对象直接承担输出角色；负向条件则必须把所描述对象作为非输出角色处理。LLM 的分布式关联表示可能增加实际困难，但不是这项语义结构的唯一来源。

正向描述仍有例外。正向示例可能只是参考而非复制目标，正向陈述可能描述输入事实、历史状态或检查对象，“只允许 A”也可能主要承担边界角色。因此判断对象角色不能依赖肯定句式，必须依赖文档中的关系、作用域和权威上下文。真正的比较应是“描述对象与输出目标是否重合”，而不是句子有没有否定词。

本轮使此前几个机制获得较清楚的层次：解空间定位说明目标与边界怎样规定合法结果；对象角色绑定说明被描述内容怎样参与该规定；关联邻域激活说明措辞还可能改变哪些相关内容更容易参与生成；目标信息不足则说明即使边界执行正确，剩余候选仍可能缺少选择方向。它们可以组合，但不应继续以一个“负向锚定”概念全部承载。

下一步需要讨论的是：**对象角色绑定是否已经足以解释负向描述的结构性成本，还是还需要独立保留“负向描述只定义补集、没有提供剩余候选内部结构”的原理？** 如果正向目标同时存在，负向条件只负责边界，那么缺少内部结构并不是它的失败；只有负向描述被拿来替代完整目标时，这个问题才真正出现。由此可能需要区分“负向边界本身的复杂性”和“用负向边界替代目标的不足”。

### 正负描述表达能力等价但构造成本不对称
- 形成时间: 2026-08-13T10:27:54+00:00

#### 形成时背景
上一轮仍把“负向描述只定义补集、没有提供剩余候选内部结构”表述成它通常无法替代目标描述的原因。用户指出，这错误地混淆了集合表达能力与现实构造难度。单纯从集合角度，在全集确定时，任意目标集合都可以通过排除其补集来精确描述；负向描述并非不能定义与正向描述完全相同的集合。

真正的差异是构造同一描述所需的工作。人通常已经以正向性质、原型、用途或共同特征大致认识目标集合，因此更容易继续挖掘这个潜在集合的直接定义。若坚持使用等价负向描述，则往往要先构造目标集合的补集，再确保被排除内容完整覆盖补集且没有误伤目标。这个过程通常比直接恢复目标集合的共同性质更费劲。综合而言，正向描述仍然更好，但不是因为负向描述在原则上缺少表达能力。

#### 调查目的
本轮要撤回“负向边界通常无法替代目标描述”的集合论断，区分正负表达的形式等价性、自然语言中的有限可构造性以及人类对目标集合的认知入口；并判断此前的“补集缺少内部结构”应改写为表达结果缺陷，还是描述构造成本。

本轮不证明所有目标集合都能由有限自然语言精确定义，不假设任务全集总是明确，也不把“正向通常更简单”提升为没有反例的普遍定律。

#### 调查范围与依据
本轮依据是用户对集合表达能力和补集构造成本的直接修正，并与本主题中目标投影、解空间定位、角色绑定和负向边界的已有模型进行概念对照。Git 基线仍为 `37e75747a29326dd9a6fc9ec911455aa412dcab2`；本轮没有新增外部资料、形式证明或模型实验，只追加调查报告与同步派生索引。

以下集合表示假设一个讨论范围内的全集 `U` 和目标集合 `T`。这是用于澄清逻辑等价性的理想模型，不表示现实目标已经闭合、`U` 已被人完整掌握，或自然语言能够有限且无歧义地表达任意集合。

#### 调查结果与边界
在理想集合模型中，用户的反例成立：

`T = U \\ (U \\ T)`

只要能够准确描述目标集合 `T` 的补集 `U \\ T`，再对其取否定，就可以得到与直接描述 `T` 相同的成员集合。反过来，任何负向定义也可以在逻辑上改写成“属于其允许补集”的正向定义。因此，正向与负向描述之间不存在一般性的集合表达能力高低；“负向描述无法替代目标”作为绝对命题应当撤回。

现实不对称出现在定义怎样被发现、构造和验证。目标通常先以某些内部参照进入人的认识：用途、原型、共同性质、代表实例或想达到的状态。若这些参照已经存在，直接把它们显化成 `T` 的定义只需要继续澄清目标自身。构造等价负向定义则需要转向外部：确定 `U`、恢复 `U \\ T`、找到能够有限概括补集的结构，并证明排除条件既没有漏掉非目标，也没有排除目标成员。

这使“补集缺少内部结构”获得更准确的位置。它不是说补集在数学上没有结构，也不是说负向结果必然无法定位目标；它是说目标补集往往不是人当前已经拥有的认知对象，且在开放任务中可能由许多异质区域组成。为了写出等价负向定义，作者必须额外发现并压缩这些区域。困难位于**描述构造过程**，而不是已经完成的精确负向定义在逻辑上少了什么。

如果负向定义已经被完整、准确且有限地构造出来，它可以提供与正向定义相同的解空间定位，甚至在某些领域更简单。例如合法集合只排除一个清楚类别时，“除 X 外全部允许”可能比枚举所有目标成员紧凑；禁止契约的自然对象本来就是补集中的违规事件。此时不能继续用“没有目标方向”否定它，因为完整补集定义已经间接确定了目标。

但“逻辑可等价”不表示自然语言表达成本相同。等价负向定义可能更长、更依赖全集闭合、更难证明覆盖完整性，也可能引入更多对象表示、角色绑定与关联邻域。正向定义也可能更难：目标集合内部异质而补集由一条简单规则概括时，负向表达更经济。哪一种更简单取决于 `T` 与 `U \\ T` 哪一侧已有更低复杂度、证据更充分且更贴近使用者现有认知的定义。

因此，“综合来说正向描述好一点”可以保留为现实中的默认倾向，但理由应当是：**人的目标通常以目标侧参照被认识，直接挖掘已有潜在定义比另行构造等价补集更省认知、表达和验证成本。** 这是一项关于常见目标形成与文档编写入口的经验判断，不是集合论上的表达能力定律。

角色绑定与构造成本继续是两项不同机制。即使一个完整负向定义已经构造完成，执行时仍需要把补集对象绑定为排除角色；即使某种形式系统能够无成本执行否定，作者仍可能很难发现这个补集定义。前者位于解释和执行关系，后者位于作者怎样取得等价规格，不能相互吸收。

这也重新解释最初的“低阶无穷与高阶无穷”直觉。它可能在捕捉目标侧描述往往更容易被少量共同性质压缩、非目标侧往往更异质的经验现象，但不能用集合基数证明。目标与补集可以具有相同基数，甚至补集更容易定义；真正相关的是描述复杂度、认知可得性和验证成本，而不是无穷的阶数。

下一步需要讨论的是：**“目标侧通常拥有更低描述复杂度”究竟是一项足够稳定的经验原理，还是只因为人会把自己已经能够正向概括的对象称为一个目标集合？** 换言之，正向描述的默认优势可能来自目标形成方式，而不是集合本身。这个问题决定最终原理应写成关于解空间结构、人的认知入口，还是文档作者的构造策略。

### 正向目标是对负向修正历史的认知压缩
- 形成时间: 2026-08-13T10:32:26+00:00

#### 形成时背景
上一轮留下的问题是，目标侧通常更容易描述究竟源于目标集合自身的低描述复杂度，还是源于人怎样形成目标。用户指出，答案已经隐含在此前分析中：人往往从已有认识出发提出一个新目标，再排除常见曲解和边界，而不是从全集开始逐项排除，直到偶然剩下一个目标。

即使目标确实通过连续排除逐步形成，一旦多个负向描述显露出共同方向，人也通常会把它们重新定义为一个正向目标。一个可命名、可复用的目标概念，比长期携带多个离散负向规则需要更少的心智负担。因此，正向描述的常见优势不仅是起始认知入口，也来自人会持续把修正历史压缩为新的正向认识。

#### 调查目的
本轮要把人的目标形成过程描述为“正向投射、负向修正、正向再压缩”的循环，判断它怎样解释正向目标通常比多个负向描述更易使用和维护；同时区分真正的认知压缩与只给复杂规则换一个短名称。

本轮不主张所有负向边界最终都应被正向目标吸收，不把人的心智负担直接外推为 LLM 的内部计算成本，也不据此修改 skill。

#### 调查范围与依据
本轮依据是用户对目标形成、常见曲解排除和负向规则正向重定义的直接分析，并与前十三轮关于动态目标、反馈显化、补集构造成本和角色绑定的结果进行概念整合。Git 基线仍为 `37e75747a29326dd9a6fc9ec911455aa412dcab2`；本轮没有新增外部材料或实验，只追加调查报告与同步派生索引。

“认知压缩”在这里指多个判断能够被一个共同性质、原型、目的或可复用概念解释，从而减少后续恢复和运用目标所需的独立条件数量。它不是信息论或算法复杂度的已测量指标，也不意味着短文本必然具有更低的真实理解成本。

#### 调查结果与边界
当前更合适的目标形成模型是一个循环：

`已有认识 → 大致正向目标 → 候选与常见曲解 → 负向边界或反馈 → 恢复共同性质 → 更新后的正向目标`

人通常不会先枚举全部非目标。新目标从既有概念、用途、类比、愿望或问题情境中被投射出来，天然已经具有一个正向中心。负向描述随后承担局部修正：排除高概率曲解、不可违反边界、危险事件或已经出现的错误结果。它们帮助目标收敛，却通常不是目标从无到有的唯一来源。

多个负向修正若反复指向同一差异，就暴露出一个尚未命名的目标性质。例如连续出现“不要改写用户语气”“不要删掉保留意见”“不要把推测写成事实”，可能共同指向“保持现有语义与认识边界”。一旦这个共同性质被确认，正向命名能够把多个判断压缩成更稳定的目标参照，后续不必每次重新组合全部反例才能理解方向。

因此，“一个目标比多个负向描述更少”不只指字符数量，而是所需独立认知单元更少。一个真正有效的正向目标可以提供共同解释、预测新的未见场景，并让新的边界判断有归属；一串逐项排除通常只能处理已经列出的情况，使用者需要记住每项适用范围及它们之间的关系。正向再定义降低的是恢复、迁移和维护负担。

但命名本身不等于压缩。把十条规则命名为“高质量”而没有给出共同性质、判据或代表性结构，只是把复杂性隐藏在一个模糊标签后。真正的压缩要求该正向概念能够解释原有排除项为何属于同一目标，并对尚未列出的候选提供一定判断力；否则 agent 仍需回读全部负向规则才能行动。

负向边界也不应全部被吸收。安全、权限、隐私、不可逆动作和协议禁止项可能具有独立契约身份；它们存在的原因不是目标概念尚未压缩，而是违规事件本身需要可审计、可验证地被禁止。正向目标可以提供主方向，但不应以抽象概念替代这些高后果边界。

这个循环说明正向描述的优势主要来自人的认知组织方式，而不能简单归因于目标集合客观上总比补集简单。目标之所以显得更低复杂度，部分原因正是人会主动为反复出现的差异建立概念、形成原型并重新命名；无法被压缩或需要独立审计的部分则继续以边界存在。目标集合和表达它的概念是在这一过程中共同成形的。

对 LLM 而言，一个已被人类文化和训练语料稳定使用的正向概念也可能提供高密度关联结构，比临时拼接的多个负向项更容易形成一致输出方向；但本轮没有模型实验，不能把人的认知压缩直接等同于模型概率上的优势。前述对象角色绑定和关联邻域激活仍是独立候选机制。

这一认识也给“信息效率”找到更具体但更窄的位置：它不必比较正句与负句一次剪掉多少候选，而可以观察多个局部规则是否已经暴露出可复用的共同目标性质。把已有共同性质显化，可能减少重复、推理链和维护点；这仍然必须服从语义保真，不能由 agent 为追求压缩而发明原文没有支持的目标。

下一步需要讨论的是：**何时多个负向描述已经足以支持一个正向共同性质，何时这种提炼只是 agent 自行概括并改变了原有边界？** 这将直接连接语义保真与认知压缩：好的正向重定义应当能够解释并保留原有规则，但能解释旧例不一定证明它在未见场景中的外推也获得了授权。

### 人与 AI 具有不同的抽象默认偏差
- 形成时间: 2026-08-13T11:05:47+00:00

#### 形成时背景
上一轮提出 AI 很容易把只能概括已有规则的归纳标签直接升级为能够处理未见场景的权威目标。用户指出，这错误地把过早抽象主要归因于 AI。人类同样经常犯这种错误，而且可能具有更直接的动机：随着正向与负向描述持续增加，人为了逃避复杂度和降低心智负担，会产生抓住本质、建立简单对象的欲望；一旦某个抽象带来理解感，又可能更加确信它就是事物本质，没有意识到自己只是停在一个局部解中。

用户同时提出 AI 可能具有不同的默认倾向。指令遵循训练使 AI 更容易把当前提供的内容当作主线，在原有结构中继续逐项调整，而不一定像人一样因厌烦复杂度主动寻找更高层抽象。至于抽象本身是否正确，人和 AI 都没有天然保障；在缺少 SOP、领域结构或验证标准时，抽象质量很大程度依赖推理能力和对对象的理解，不能仅凭主体类别判定。

#### 调查目的
本轮要撤回“从局部规则直接跳到权威抽象主要是 AI 风险”的偏置，区分产生抽象的动机、是否主动抽象、抽象是否正确以及抽象是否获得外推权威；并检查人类认知闭合与指令微调模型持续遵循当前内容这两种候选默认偏差的证据边界。

本轮不判断人一定比 AI 更容易过度抽象，不把 AI 描述为没有回避复杂度、捷径或过度概括倾向，也不建立人类与 AI 的统一心理机制。

#### 调查范围与依据
本轮依据包括用户对人类简化动机、局部解确信和 AI 指令遵循倾向的直接分析，以及以下一手资料：Kruglanski 与 Webster 的 [Motivated Closing of the Mind: “Seizing” and “Freezing”](https://pubmed.ncbi.nlm.nih.gov/8637961/) 对认知闭合需要的理论描述；Webster、Richter 与 Kruglanski 关于[心理疲劳与印象首因效应](https://www.sciencedirect.com/science/article/pii/S0022103196900098)的实验摘要；[Training Language Models to Follow Instructions with Human Feedback](https://arxiv.org/abs/2203.02155) 对指令遵循微调效果的研究；[From Language Modeling to Instruction Following](https://arxiv.org/abs/2310.00492) 对指令微调后生成持续受指令词条件影响的机制分析；以及 [How Abstract Is Linguistic Generalization in Large Language Models?](https://aclanthology.org/2023.tacl-1.78/) 对 LLM 抽象泛化能力具有任务边界的实验。

资料于 2026-08-13 核对。认知闭合资料支持人会在不确定性、秩序需求或处理成本下更快抓取并冻结解释；指令微调资料支持模型更能识别并持续依赖指令生成。它们没有直接比较人在文档抽象任务中与特定 AI 的过度概括率，也没有证明 AI 普遍缺乏主动抽象动机。Git 基线仍为 `37e75747a29326dd9a6fc9ec911455aa412dcab2`；本轮仅追加调查报告并同步索引。

#### 调查结果与边界
首先应撤回“AI 很容易从归纳标签跳到权威目标”这一单边表述。**从有限例子提炼共同性质，再把候选抽象误认为事物本质，是人和 AI 都可能发生的过度概括。** 能够解释已见规则只证明抽象对当前样本具有解释力，不自动赋予它未见场景的正确性和修改权威；这一逻辑边界与抽象者是人还是 AI 无关。

但人和 AI 触发错误的默认机制可能不同。人具有主观的复杂度负担、疲劳、歧义不适和认知闭合动机。当细节增多时，寻找“本质”不仅是提高复用性的理性压缩，也可能成为尽快结束不确定性的手段。一个简单抽象一旦组织了混乱材料，会带来明显的理解感和控制感；这种收益可能反过来提高确信，使人忽略抽象只覆盖局部样本、遗漏边界或依赖尚未验证的前提。

这可以表示为一条候选风险链，而不是普遍因果定律：

`规则增多 → 心智与不确定性成本上升 → 寻求统一解释 → 获得压缩与理解感 → 确信增强 → 局部抽象被误作全局本质`

AI 没有证据表明具有与人相同的主观厌烦、逃避或闭合欲望。对经过指令微调的模型，现有证据支持的是当前指令更持续地影响生成；在文档整理任务中，这可能表现为沿现有内容和局部修改主线继续工作，而不是主动宣布一个更高层本质。用户观察到的“AI 更容易逐项调整”因此是有机制依据的候选倾向，但缺少针对当前场景的直接对照实验，不能写成 AI 普遍比人更少主动抽象的事实。

同时，AI 也可能因为训练分布、提示要求“总结原则”、上下文压缩、对简洁答案的偏好或常见话语模式而迅速生成抽象。它不需要体验复杂度负担，也能在输出行为上表现为过度概括。因此，“缺少人的逃避动机”不能推出“不会产生逃避复杂度的结果”，只能说明两者可能通过不同机制到达相似错误。

需要把四件事明确分开：

1. **抽象动机**：为什么主体想压缩复杂内容。人可能来自认知负担与闭合需要；AI 的输出行为来自训练目标、指令、上下文和解码条件，不能直接赋予同类心理动机。
2. **抽象倾向**：主体在当前条件下是否主动寻找共同性质。它会随人、模型、提示、任务阶段和成本变化。
3. **抽象判断力**：提出的共同性质是否真正解释对象、保留边界并能可靠外推。它取决于能力、领域理解、证据和验证过程，而不由是否主动抽象决定。
4. **抽象权威**：即使抽象正确，谁有权让它替换现有规则或约束未见场景。这继续由内容 owner 和任务授权决定，不能从智力或置信度推出。

用户提出“无 SOP 时几乎纯靠智力或理解程度”准确指出了结构缺失，但仍可进一步收窄：能力和理解是必要影响因素，却很难凭一次结果直接测量；没有过程约束时，人和 AI 都只能依赖各自已有模型进行归纳，也更难暴露遗漏。SOP 的价值不是替代判断，而是强制保留样本边界、检查反例、区分解释与授权，并让抽象接受可重复的挑战。

这意味着 `ai-ready-docs` 后续若形成动作，不应只防止 agent 擅自抽象，也不能假设人类确认就自动证明抽象正确。语义保真需要保护现有规则不被候选概括静默覆盖；调查或协作过程可以提出共同性质，但应把“谁提出”“谁确认”“覆盖了哪些样本”“能否外推”分开。当前仍只讨论原理，没有形成或实施该动作。

下一步需要讨论的是：**抽象错误的核心究竟是“覆盖不完整”，还是“把局部解释的适用域扩张成全局”；一个抽象是否可能完整解释全部已知规则，却仍然因为未知样本而无法获得外推权威？** 这个问题可以把抽象判断力从主体智力转化为更可检查的适用域与证据关系，而不是试图判断人或 AI 谁更聪明。

### 区分框架重构与框架内修补两种策略
- 形成时间: 2026-08-13T11:13:24+00:00

#### 形成时背景
上一轮把人和 AI 的差异概括为不同的抽象默认偏差。用户进一步澄清，这主要来自实践经验，真正值得保留的不是主体标签，而是两个常见小情景。第一种是在复杂问题前主动回避现有复杂度，希望通过重新抽象、重审问题和建立更简单对象来替代原有结构；抽象质量高时可能抓住本质，质量低时则只是逃避式简化。第二种是接受原有内容为主线，继续打补丁、逐步修复，而不重新打开问题框架。

用户由此联想到“进步”与“保守”的哲学类比：一方倾向打破现状并给出新方案，另一方倾向保留现状并渐进修补。人的情绪、认知负担或对深层目标冲突的感受，可能促使其重新审视问题；AI 没有同类主观情绪，因而可能对复杂内容表现出更高耐受，继续沿既有框架处理。但这一经验解释还需要与人类定势、现状偏好，以及 AI 多约束处理失败等反例共同检查。

#### 调查目的
本轮要把讨论对象从“两种人”或“人类与 AI”转为两种问题解决策略：框架重构与框架内修补；区分它们的触发条件、潜在价值和失败模式，并判断“AI 因没有情绪而更耐受复杂度”能够安全成立到什么程度。

本轮不把“进步/保守”当作政治阵营、固定人格或价值高低，不把重新设计天然视为进步，也不把渐进修补天然视为保守或低智力。

#### 调查范围与依据
本轮依据包括用户对逃避式抽象、优秀抽象、遵循式修补和复杂度耐受的经验模型，以及以下资料：[Why Good Thoughts Block Better Ones](https://pubmed.ncbi.nlm.nih.gov/18565505/) 对熟悉方案通过注意偏置阻碍更优解的 Einstellung 效应研究；[Investigating the Effect of Mental Set on Insight Problem Solving](https://pubmed.ncbi.nlm.nih.gov/18683624/) 对定势、表征改变与程序化关系的实验；[Measuring Cognitive Flexibility](https://pmc.ncbi.nlm.nih.gov/articles/PMC10910035/) 对认知灵活性概念与测量不统一的综述；以及 [LLM Self-Correction with DeCRIM](https://aclanthology.org/2024.findings-emnlp.458/) 对模型多约束失败和分解—批评—修订流程的实验。

资料于 2026-08-13 核对。它们支持人可能被既有方案固着，也支持当前 LLM 面对多项约束时会遗漏内容、可通过显式分解与迭代修订改善；它们没有直接测量人和 AI 的“复杂度耐受”，也没有证明缺乏情绪足以导致 AI 长期遵循既有框架。Git 基线仍为 `37e75747a29326dd9a6fc9ec911455aa412dcab2`；本轮仅追加调查报告并同步索引。

#### 调查结果与边界
当前最稳定的抽象不是两类主体，而是两种策略：

1. **框架内修补**：把当前目标、概念划分和实现主线视为基本有效，在其内部定位局部偏差、增加约束、修复例外并保持连续性。
2. **框架重构**：重新检查问题怎样被定义、现有抽象是否仍服务深层目标，并可能更换目标概念、责任边界或整体方案。

两种策略都可以理性，也都可以逃避。框架重构可能是因为发现深层目标与当前方案冲突，旧结构已经无法经济修复；也可能只是因为理解细节太累，用一个漂亮但未经验证的新抽象绕开复杂度。框架内修补可能是在现有结构基本正确时以最低风险持续改进；也可能是不愿承认主线错误，在累积补丁中延长局部最优。

因此，质量轴与策略轴必须分开：

| 策略 | 高质量形态 | 低质量形态 |
| --- | --- | --- |
| 框架重构 | 抓住更稳定的共同结构，降低整体复杂度并保留真实边界 | 逃避式抽象，以简单故事替代尚未理解的复杂性 |
| 框架内修补 | 在有效主线内做可验证、低风险的渐进改进 | 遵循式补丁，维护已经失效的框架并累积例外 |

“进步/保守”可以帮助理解改变幅度，却容易附带政治、道德和人格含义。更准确的轴是**是否重新打开问题框架**。同一个人在不同任务中会切换；同一个 AI 也会随提示、授权、训练和上下文切换。框架重构不自动更先进，修补也不自动更保守；关键是当前错误位于框架内部还是框架本身。

关于人类，人可能因复杂度负担、疲劳、厌烦、认知闭合或深层冲突感而触发重构，但也会因沉没投入、熟悉方案、现状偏好和 Einstellung 效应坚持既有框架。因此，情绪与认知动机既可能帮助跳出局部解，也可能造成逃避式重构或阻止重构，不能只把人放在“打破现状”一侧。

关于 AI，可以相对安全地说：当前模型没有证据表明体验了人类同类的厌烦、焦虑或认知闭合需要；指令遵循和上下文条件作用可能使它持续沿用户给出的主线生成。用户经验中 AI 对复杂内容更耐受、倾向逐项修补，因而具有合理候选机制。但“没有情绪”不等于无限复杂度耐受：上下文窗口、注意分配、多约束遵循、长链一致性和训练偏好都会产生处理限制；模型也可能在提示要求总结、重构或追求简洁时主动提出新抽象。

人与 AI 因此更适合互补，而不是被固定分工。人对深层目标冲突和现实后果拥有更多第一人称信号，可能更早提出“框架本身错了”；AI 可以持续追踪大量显式条件，帮助检验旧框架是否真的无法修复。但人提出的重构可能只是逃避，AI 的持续修补也可能只是机械延续。双方都需要对另一策略形成可见候选，而不是由某一方天然垄断重构或修补。

这也重新连接目标投影：发现当前结果与深层目标冲突，是重新打开框架的正当触发器之一；但深层目标本身不可完整读取，冲突感也可能被误判。重构应被视为候选方向，需要比较它能否解释旧问题、减少整体补丁、保留必要边界并产生可验证结果，而不是仅凭“更本质”或“更简单”获得权威。

下一步需要讨论的是：**怎样判断问题出在框架内部还是框架本身？** 如果每个新问题都能通过增加补丁暂时处理，何时补丁累积已经构成重构证据；反过来，一个新抽象怎样证明自己真的降低了整体复杂度，而不是把未解决细节隐藏到了名称、例外或实现层。这将比讨论“谁更进步、谁更保守”更直接地服务后续原理。

### 收回框架重构旁支并恢复正负描述主线
- 形成时间: 2026-08-13T11:20:49+00:00

#### 形成时背景
上一轮把用户关于人类逃避复杂度、AI 倾向沿原内容继续修补的经验观察扩展成了“框架重构与框架内修补”两种一般策略，并将下一问题推进到何时应该停止打补丁、重新打开框架。用户指出，这已经偏离本调查持续追踪的 `ai-ready-docs` 主线。补丁与抽象本身并不是用户已经深入思考或希望继续展开的新主题；它们只是解释人类与 AI 面对复杂内容时不同倾向的旁支类比。

用户重新给出的讨论脉络是：人类更倾向逃避复杂问题，并希望把大量内容抽象、简化成更少的描述；因此即使积累了大量正向或负向描述，也会持续寻找较少的共同表达。从习惯和效率看，正向描述更容易成为这种压缩后的表达方案。随后关于人类与 AI 复杂度倾向的内容，只是用户基于经验作出的主观感受，不应被自动升级为新的调查主线。

#### 调查目的
本轮要纠正调查推进方向，区分服务正负描述原理的必要解释与已经能够独立成题的旁支问题；把“框架重构/框架内修补”和“人类/AI 复杂度耐受”降回其形成时证据地位，并恢复对正向目标、负向边界及 AI 使用效果的讨论。

#### 调查结果与边界
首先确认本次偏移本身：上一轮把相邻报告留下的开放问题当成了自然主线，却没有重新检查主题的核心问题和用户使用类比的目的。这是一种过程上的过度遵循——局部上顺着既有文本继续推进，整体上却离开了当前调查要解释的对象。因而，“怎样判断应打补丁还是重构框架”从本主题的下一讨论事项中撤回。

前两轮仍有一项与主线直接相关的有限结果可以保留：人面对大量细节时，常有把它们压缩成较少概念的动机；这种压缩可能优秀，也可能过度。用户关于 AI 更能沿显式内容逐项工作的判断属于经验性主观观察，可以帮助解释双方讨论为何呈现不同节奏，但当前没有必要将其发展成一般人机理论。

与 `ai-ready-docs` 直接相关的因果链应收窄为：

`目标的既有正向认识 → 正向目标投影 → 负向边界修正曲解 → 多项修正显露共同性质 → 人倾向重新压缩成较少的正向描述`

这条链说明正向描述更常出现，可以同时来自习惯与效率：

1. **认知入口**：人通常先从自己已有的目标认识出发表达想要什么，而不是先构造完整非目标补集。
2. **压缩出口**：当局部规则增多时，人倾向为它们寻找一个共同对象；目标侧的正向概念通常更适合作为统一名称和主线。
3. **使用效率**：一个真正恢复共同性质的正向描述，可以让后续理解围绕目标组织；多个负向项则仍需分别识别对象、维持排除角色和恢复相互关系。

这不是说负向描述无法定义目标集合。第十三轮已经确认，在全集与补集可定义时，负向描述具有相同集合表达能力；补集简单时甚至可能更经济。这里讨论的是自然目标形成和文档维护中的默认路线，而不是形式表达能力。

也不能把人类压缩倾向直接写成 `ai-ready-docs` 的动作，要求 AI 看到多个负向项就主动生成一个正向本质。人类同样可能做出逃避式抽象，而 AI 的概括也可能超出原文证据。对 skill 原理真正有用的是认识到：正向共同性质往往是更低心智负担的当前目标表示；是否已经存在足够证据支持该性质，仍受语义保真和授权边界约束。

关于人类与 AI 的差异，本主题只保留如下边界化描述：用户经验上认为，人更容易因复杂度负担主动寻求抽象，AI 更容易沿现有显式内容继续调整；这可能影响正向压缩由谁先提出，但不是正向描述为何通常更适合作为目标主线的必要前提。即使暂不判断该差异，认知入口、压缩出口、对象角色绑定和关联邻域机制仍然可以独立成立。

讨论至此已经恢复到 `ai-ready` 的问题：文档应怎样同时保留一个便于恢复和使用的目标主线，以及那些不能被主线安全吸收的必要边界。下一步不再追问一般抽象哲学，而应讨论：**既然人最终常把多个修正重新组织成正向目标，AI-ready 文档是否应明确区分“目标主线”和“必要边界”；这种结构区分是否比要求逐句改成正向描述更准确？** 这会直接决定正负描述应如何组合，而不会扩张到另一个调查主题。
