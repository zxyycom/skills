## 形成时背景

上一轮留下的问题是，目标侧通常更容易描述究竟源于目标集合自身的低描述复杂度，还是源于人怎样形成目标。用户指出，答案已经隐含在此前分析中：人往往从已有认识出发提出一个新目标，再排除常见曲解和边界，而不是从全集开始逐项排除，直到偶然剩下一个目标。

即使目标确实通过连续排除逐步形成，一旦多个负向描述显露出共同方向，人也通常会把它们重新定义为一个正向目标。一个可命名、可复用的目标概念，比长期携带多个离散负向规则需要更少的心智负担。因此，正向描述的常见优势不仅是起始认知入口，也来自人会持续把修正历史压缩为新的正向认识。

## 调查目的

本轮要把人的目标形成过程描述为“正向投射、负向修正、正向再压缩”的循环，判断它怎样解释正向目标通常比多个负向描述更易使用和维护；同时区分真正的认知压缩与只给复杂规则换一个短名称。

本轮不主张所有负向边界最终都应被正向目标吸收，不把人的心智负担直接外推为 LLM 的内部计算成本，也不据此修改 skill。

## 调查范围与依据

本轮依据是用户对目标形成、常见曲解排除和负向规则正向重定义的直接分析，并与前十三轮关于动态目标、反馈显化、补集构造成本和角色绑定的结果进行概念整合。Git 基线仍为 `37e75747a29326dd9a6fc9ec911455aa412dcab2`；本轮没有新增外部材料或实验，只追加调查报告与同步派生索引。

“认知压缩”在这里指多个判断能够被一个共同性质、原型、目的或可复用概念解释，从而减少后续恢复和运用目标所需的独立条件数量。它不是信息论或算法复杂度的已测量指标，也不意味着短文本必然具有更低的真实理解成本。

## 调查结果与边界

当前更合适的目标形成模型是一个循环：

`已有认识 → 大致正向目标 → 候选与常见曲解 → 负向边界或反馈 → 恢复共同性质 → 更新后的正向目标`

人通常不会先枚举全部非目标。新目标从既有概念、用途、类比、愿望或问题情境中被投射出来，天然已经具有一个正向中心。负向描述随后承担局部修正：排除高概率曲解、不可违反边界、危险事件或已经出现的错误结果。它们帮助目标收敛，却通常不是目标从无到有的唯一来源。

多个负向修正若反复指向同一差异，就暴露出一个尚未命名的目标性质。例如连续出现“不要改写用户语气”“不要删掉保留意见”“不要把推测写成事实”，可能共同指向“保持现有语义与认识边界”。一旦这个共同性质被确认，正向命名能够把多个判断压缩成更稳定的目标参照，后续不必每次重新组合全部反例才能理解方向。

因此，“一个目标比多个负向描述更少”不只指字符数量，而是所需独立认知单元更少。一个真正有效的正向目标可以提供共同解释、预测新的未见场景，并让新的边界判断有归属；一串逐项排除通常只能处理已经列出的情况，使用者需要记住每项适用范围及它们之间的关系。正向再定义降低的是恢复、迁移和维护负担。

但命名本身不等于压缩。把十条规则命名为“高质量”而没有给出共同性质、判据或代表性结构，只是把复杂性隐藏在一个模糊标签后。真正的压缩要求该正向概念能够解释原有排除项为何属于同一目标，并对尚未列出的候选提供一定判断力；否则 agent 仍需回读全部负向规则才能行动。

负向边界也不应全部被吸收。安全、权限、隐私、不可逆动作和协议禁止项可能具有独立契约身份；它们存在的原因不是目标概念尚未压缩，而是违规事件本身需要可审计、可验证地被禁止。正向目标可以提供主方向，但不应以抽象概念替代这些高后果边界。

这个循环说明正向描述的优势主要来自人的认知组织方式，而不能简单归因于目标集合客观上总比补集简单。目标之所以显得更低复杂度，部分原因正是人会主动为反复出现的差异建立概念、形成原型并重新命名；无法被压缩或需要独立审计的部分则继续以边界存在。目标集合和表达它的概念是在这一过程中共同成形的。

对 LLM 而言，一个已被人类文化和训练语料稳定使用的正向概念也可能提供高密度关联结构，比临时拼接的多个负向项更容易形成一致输出方向；但本轮没有模型实验，不能把人的认知压缩直接等同于模型概率上的优势。前述对象角色绑定和关联邻域激活仍是独立候选机制。

这一认识也给“信息效率”找到更具体但更窄的位置：它不必比较正句与负句一次剪掉多少候选，而可以观察多个局部规则是否已经暴露出可复用的共同目标性质。把已有共同性质显化，可能减少重复、推理链和维护点；这仍然必须服从语义保真，不能由 agent 为追求压缩而发明原文没有支持的目标。

下一步需要讨论的是：**何时多个负向描述已经足以支持一个正向共同性质，何时这种提炼只是 agent 自行概括并改变了原有边界？** 这将直接连接语义保真与认知压缩：好的正向重定义应当能够解释并保留原有规则，但能解释旧例不一定证明它在未见场景中的外推也获得了授权。
